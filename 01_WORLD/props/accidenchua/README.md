# ACCIDENCHUA 採用ロゴ

2026-09-13採用。DをIDEのデバッグアイコン風の虫へ置き換える。黒背景版が正本。

## 配色

| 部分 | 採用版（ダーク） | ライトテーマ版を作る場合 |
| --- | --- | --- |
| 背景 | #000000 | #FFFFFF |
| 通常文字 | #FFFFFF | #000000 |
| 虫D | #5EFF00 | #5EFF00 |
| 虫Dの目 | #000000 | #000000 |

- 正本画像: [logo-dark.png](logo-dark.png)。

- 表記は ACCIDENCHUA。Dの虫の形状、触角、6本の脚、2つの目を維持する。
