# グリーン画面生成ガイド

## 発動条件

ユーザーがグリーン画面、クロマキー、後で画面を差し替えたい、差し替えやすく生成したい、と明示した場合だけ適用する。通常のWan動画でモニターが映るだけなら適用しない。

## Wanプロンプトへ入れる条件

- 表示面だけを単一の高彩度クロマキー緑にする。
- 緑は黒いベゼルの内側だけに置き、背景、人物、机、小道具へ出さない。
- 表示面の四隅とベゼルを全区間で見せる。
- 画面内へ文字、UI、アイコン、カーソル、タスクバー、模様を出さない。
- グラデーション、反射、映り込み、モアレ、ブルーム、影、色変動を避ける。
- 手、人物、端末、ケーブル等を画面へ重ねない。
- カメラ移動は小さく滑らかにし、急なパン、ズーム、激しいブレ、カットを避ける。
- 差し替え区間だけを作る場合は、すでに画面へ到着した状態から始める。

Wanは完全な単色指定でも照明ムラを生成し得る。完全一致を期待せず、高彩度の緑領域として分離できることを監査する。

## 参照素材

- 既存ショットの構図と動きを維持したい場合は`reference_video`を優先する。
- 最初の構図だけを厳密に固定したい単一ショットは`first_frame`を使う。
- 参照動画から文字や画面内容を複製せず、モニター形状、オフィス、画角、カメラ運動だけを参照すると明記する。
- Wanの入力方式、尺、課金、音声、単一生成ルールは`wan-video`へ従う。

## 生成後の合格条件

- 四隅が全対象フレームで見える。
- 最大の緑連結領域が表示面であり、背景の緑と接続していない。
- ベゼルが緑化・透明化していない。
- 遮蔽と画面外への欠けがない。
- `screen-replacement`の`green`方式で全フレーム検出できる。
