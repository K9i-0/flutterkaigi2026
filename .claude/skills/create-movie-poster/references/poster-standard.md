# 映画ポスター共通仕様

## 正本サイズ

| 項目 | 規格 |
|---|---|
| アスペクト比 | 縦2:3 |
| 推奨ピクセル | 1024×1536 |
| 形式 | PNG |
| カラーモード | RGB / RGBA |

解像度違いが必要な場合も2:3を維持する。正本は1024×1536で保存する。

## SNSクロップ

1024×1536の中央クロップは次の範囲になる。

| 用途 | 残る範囲 | 重要度 |
|---|---|---|
| 4:5フィード | x=0–1024、y=128–1408 | 必須対応 |
| 1:1サムネイル | x=0–1024、y=256–1280 | タイトルは可能な限り対応 |

- 重要文字の基本安全域を x=6–94%、y=8.33–91.67% とする。
- 主タイトル群の推奨域を x=8–92%、y=64–82% とする。
- タイトル直下の公開表記や短いサブコピーは y=84–89% に置く。
- 上段コピーは x=8–92% に収める。SNSでも必須なら y=8.33% より下に置く。
- 顔、仮面、決定的小道具は端から6%以上離す。
- クレジットブロックは必須情報ではない。追加する場合も4:5範囲内に収める。

安全域は文字のベースラインではなく、影、縁取り、アイコンを含む外接矩形で判定する。

## レイアウト原則

- ジャンルごとの画風、色、タイトル書体は統一しない。
- キャンバス、重要文字の安全域、納品形式だけを統一する。
- タイトルとタイトルアイコンは一体のグループとして中央揃えする。
- コピー、主役、タイトルの三段階が一目で読める視線誘導を作る。
- 余白を黒で埋めるだけの比率調整や、既存画像の縦横ストレッチを禁止する。

## 目視QA

- 指定されたタイトル、コピー、公開表記が完全一致する。
- 不要な英字、クレジット、透かし、ロゴがない。
- 人数、手足、小道具の数が意図どおりである。
- キャラクターのNG変更がない。
- 4:5プレビューで重要文字がすべて読める。
- 1:1プレビューで主タイトルが判別できる。
- サムネイル表示でも主役とタイトルのコントラストが保たれる。
