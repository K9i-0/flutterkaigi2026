# 映画ポスター共通仕様

## 正本サイズ

| 項目 | 規格 |
|---|---|
| アスペクト比 | 縦2:3 |
| 推奨ピクセル | 1024×1536 |
| 形式 | PNG |
| カラーモード | RGB / RGBA |

解像度違いが必要な場合も2:3を維持する。正本は1024×1536で保存する。

## SNSクロップ

1024×1536の中央クロップは次の範囲になる。

| 用途 | 残る範囲 | 重要度 |
|---|---|---|
| 4:5フィード | x=0–1024、y=128–1408 | 確認用。指定時のみ対応 |
| 1:1サムネイル | x=0–1024、y=256–1280 | 確認用。指定時のみ対応 |

- SNS対応をユーザーが求めた場合は、重要文字の目安を x=6–94%、y=8.33–91.67% とする。
- 主タイトル群の位置は作品の構図を優先する。固定の縦位置を設けない。
- 顔、仮面、決定的小道具も作品の演出を優先し、クロップ確認だけで自動的に移動しない。
- 4:5または1:1で欠けても、それだけを理由に画像編集を繰り返さない。
- ユーザーからSNS対応または位置修正の依頼があった場合に限り、影、縁取り、アイコンを含む外接矩形で安全域を判断する。

クロッププレビューは問題の可視化であり、配置合否を自動判定するものではない。

## レイアウト原則

- ジャンルごとの画風、色、タイトル書体は統一しない。
- キャンバスと納品形式だけを統一し、安全域は指定された用途に応じて適用する。
- タイトルとタイトルアイコンは一体のグループとして扱うが、中央揃えを必須にしない。
- コピー、主役、タイトルの三段階が一目で読める視線誘導を作る。
- 余白を黒で埋めるだけの比率調整や、既存画像の縦横ストレッチを禁止する。

## リポジトリ内の基準例

次の3点はいずれも1024×1536の2:3正本。構図やジャンル表現の参考にし、特定作品の画風を他作品へコピーしない。

## 目視QA

- 指定されたタイトル、コピー、公開表記が完全一致する。
- 不要な英字、クレジット、透かし、ロゴがない。
- 人数、手足、小道具の数が意図どおりである。
- キャラクターの人物同一性が維持され、その他の変更はユーザー指定と一致する。
- 実写のよーたん、福ちゃん、とーくん、おかやまんは、正典写真と同じ本人の顔として認識できる。
- 4:5と1:1のクロップ結果を確認し、欠ける要素をユーザーへ必要に応じて伝える。
- SNS対応が明示された場合だけ、指定クロップで必要な文字が読めることを合格条件にする。
- サムネイル表示でも主役とタイトルのコントラストが保たれる。

## 初回3案

- A/B/Cは同じ原典資料から独立して生成する。
- 構図、主役の距離、色調、タイトル処理などを変え、方向性を比較できる差を作る。
- 各案をブリーフの必須条件、ジャンル適合、キャラクター同一性、文字精度で比較する。実写4名の顔が別人化した案は比較対象から外す。
- 最も一致する案を推奨し、ユーザーの選択があれば必ず上書きする。
- 選定後も3案を編集の世代として連結しない。
