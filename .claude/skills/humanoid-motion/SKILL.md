# 人型モデルとモーション

既存の顔・体格を保ち、動作の自然さを2人それぞれで確認する。以下のパスはリポジトリルート基準。素材・実装の現状を先に確認し、プレビューだけの依頼で本編の採用動作を変更しない。

## 作業の入口

- 表示・比較・ボーン診断：[references/local-preview.md](references/local-preview.md)。既存確認ページを使い、同じ時刻・視点で比較する。
- リターゲット・ウェイト修正・本編採用：[references/retarget-and-adopt.md](references/retarget-and-adopt.md)。元入力、比較用VRM、ゲーム用派生GLBを区別する。
- 個別の変形実験の結果：`04_GAME_ASSETS/vrm/DEFORMATION_REVIEW.md`。過去に効かなかった処置を定番の解決策として繰り返さない。

## 判断の基準

ボーンの軌道が自然でも、初期姿勢・軸回りのねじれ・ウェイトによって肉や服は崩れる。「スキニングの変形崩れ」として切り分け、画像だけで関節位置のずれと断定しない。骨名が同じでもローカル回転の単純コピーは避け、元姿勢と体格差を考慮する。

形式検証とベイク前後の一致は変換の正しさの確認。自然な見た目は停止姿勢と連続再生で、移動速度・小道具追従は本編で確認する。結果は確認した範囲と残る問題を区別して伝える。

公開素材の条件はクリップごとに保持する。Mesh2Motion / Quaterniusの既存素材はCC0の手付けアニメーションで、モーションキャプチャとは呼ばない。既存Mixamo RunはCC0ではない。キャラクターモデルの利用条件も別。混在素材から書き出す場合は未参照バッファに他クリップを残さない。

2026-09-08時点の採用は福ちゃんが既存Run、そば屋が逃走・追跡版。最新の採用状態は `04_GAME_ASSETS/3d/hazard_adopted/manifest.json` と `21_SOBAYA_HAZARD_LAB/lib/game/game_motion_blend.dart` を正本として確認する。

## 関連する制作知見

キャラクターシートから回転動画・四面図を作って全身3D化する場合、またはそば屋v3の顔・リグ・手の向きを修正する場合は、[そば屋v3の制作知見](../../../04_GAME_ASSETS/3d/SOBAYA_V3_LESSONS.md)を参照する。8秒動画の実設定、フレーム選定、Imagegenによる投影テクスチャ修復、輪郭固定、ウェイト修正、手の表裏の誤判定と終盤の回転、画像検証の注意を記録している。

実写キャラの本人らしさ・顔の彫り・陰影を修正する場合は、[福ちゃんv3の浅い顔形状と陰影調整](../../../04_GAME_ASSETS/3d/FUKUCHAN_V3_LIKENESS_LESSONS.md)を参照する。採用frontを固定し、奥行きと材質を切り分け、承認形状をリグ・口パクへ引き継ぐ。数値はモデル・照明固有の実例であり共通の既定値にしない。
