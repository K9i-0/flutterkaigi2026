# Seedance 動画制作

**日本語で書く単一の秒刻みマスタープロンプト**、**用途別の参照画像による厳守**、**セリフを最優先する厳守モード**を標準方式にする。開始・終了キーフレームは必要な作品だけで使い、クリップごとの生成を必須にしない。

## 基準例

制作前に次を確認する。

- 日本語プロンプト、厳守モード、音声チェックリストの基準：`03_SCRIPTS/10_giant_takosan_shibuya/script.md`
- `03_SCRIPTS/08_giant_sobaya_enjo_anken/script.md`
- 同ディレクトリの `character_giant_sobaya_sheet.png`
- 同ディレクトリの `character_yametaro_liveaction_sheet.png`
- 同ディレクトリの `character_yametaro_enjo_anken_sheet.png`

`10_giant_takosan_shibuya`からは日本語化、厳守の優先順位、必須音声チェックリスト、入力画像の役割分離を採用する。各基準例の固有キャラクター、物語上の結末、旧安全制約はテンプレート化しない。現在の `01_WORLD/WORLD_BIBLE.md` と `02_CHARACTERS/*.md`を優先する。

## ワークフロー

1. 世界観、正史年表、登場キャラクター設定、基準例を読む。
2. ラン専用ディレクトリを作る。
3. 正確なセリフを確定し、必要発話時間を先に計算する。
4. キャラクターシートと、必要な環境・アクション・VFX・カメラ・構図シートを生成する。
5. 各入力画像の拘束対象を定義し、厳守の優先順位を確定する。
6. セリフ尺を起点に可変長のシーン構成を作り、`script.md`へ日本語の単一マスタープロンプトを書く。
7. 画像、時間配分、正史、キャラ、小道具、発音、必須音声の記載を監査する。

## 参照する原典

- 世界観と表現方針: `01_WORLD/WORLD_BIBLE.md`
- 正史: `01_WORLD/STORY_TIMELINE.md`
- キャラクター設定と元画像: `02_CHARACTERS/*.md`
- 過去の制作物: `03_SCRIPTS/`

キャラクター設定のNG変更を守る。正史を夢オチや後付けで無効化しない。ジャンル、感情、結末をコメディや乾杯に固定しない。

## 出力ディレクトリ

毎回 `03_SCRIPTS/<NN>_<slug>/` を新設し、成果物を同じ階層に置く。

- `<NN>`: 既存番号の最大値 + 1（2桁ゼロ埋め）
- `<slug>`: 小文字の英語をアンダースコアで結ぶ
- 必須: `script.md`、主要な登場形態ごとの `character_<name>_sheet.png`
- 任意: `character_<name>_<action>_sheet.png`、`clip1_start.png`、`clip1_end.png`

既存成果物はユーザーから修正を頼まれた場合を除いて変更しない。

## キャラクターシート

画像生成時は`imagegen`スキルを使用する。`02_CHARACTERS/<name>.md`の「画像ファイル」と設定を入力し、1枚の16:9シートで外見を固定する。シートは構図参照ではなく、identity/design referenceとして使う。

### Identity sheetの必須要素

- 左側の大きな全身ヒーローポーズ
- FRONT / SIDE / BACK の直立ターンアラウンド
- 顔または仮面のクローズアップ
- 表情差分。仮面キャラは変更可能な目・姿勢などだけを示す
- 衣装、履物、眼鏡、武器、楽器、容器など識別に重要なディテール
- 色パレット
- 巨大化など通常と異なる形態では身長・比較対象・小道具の縮尺

背景は明るい無地、照明と画角は比較しやすく統一する。複数キャラクターや別衣装を同じidentity sheetへ混ぜない。正面・側面・背面で髪型、体格、衣装、必須小道具を一致させる。

### 環境・アクション・VFX・カメラシートを追加する条件

街の地理、人物配置、独自の必殺技、変身、複雑な武器操作、破壊範囲、カメラ順、文字を形成するVFXなど、文章だけでは形がぶれやすい場合に追加する。

- FINISHの大きな完成像
- READY / IGNITION / RELEASEなど3段階以上の動作
- 手、足、武器の向きが分かるクローズアップ
- VFXの形、色、発生源、軌道、消失状態
- 街や室内の地理、モニターや建物の位置関係、破壊前後の連続性
- 必須レンズ、カメラ高、画面方向、移動経路、ショット順
- ラストなど重要構図の人物位置、前後関係、小道具位置
- 画面に出す正確な文字や記号

生成後は画像を実寸で開き、顔、前後の髪、手、衣装、NG変更、小道具、文字を目視確認する。不一致があればプロンプトで変更箇所だけを明示して再生成する。

## セリフ時間を先に確保する

均等なシーン分割を禁止する。セリフを決めてから、その発話に必要な長さに合わせてシーンを割り当てる。

1. 各セリフについて、正確な日本語、かな読み、話し方を確定する。
2. 次のスクリプトでモーラ数と推奨シーン秒数を計算する。

```bash
python3 .claude/skills/seedance/scripts/check_dialogue_timing.py \
  --text 'すまんやで、そば屋さん。こうするしかないんや' \
  --reading 'すまんやで、そばやさん。こうするしかないんや' \
  --style normal \
  --window 6.0
```

この台詞は基準例では8秒から12秒までの実質4秒しかなく、推奨6.0秒に足りない。キャラクターシートとプロンプト構造は基準にするが、この時間配分は再現しない。

漢字を含む場合は `--reading` へ実際の読みをかなで渡す。

```bash
python3 .claude/skills/seedance/scripts/check_dialogue_timing.py \
  --text '秘技・炎上案拳' \
  --reading 'ひぎ・えんじょうあんけん' \
  --style shout \
  --window 4.0
```

話速の基準は、通常4.5モーラ/秒、低くゆっくり3.5、技名など明瞭な叫び4.0、明示的な早口5.5とする。各セリフには発話時間に加えて、前後それぞれ最低0.4秒の無音・表情・口の静止時間を確保する。

- `--window`には、発話前0.4秒から発話後0.4秒までカメラと口元を安定させる**会話ビート全体の長さ**を渡す。実際の発話区間は、その内側に別途指定する。
- `--window`が失敗したシーンは、そのまま採用しない。
- セリフ開始をシーン後半まで遅らせる場合、シーン全体ではなく**安定した会話ビートの開始から終了まで**で再検証する。
- 発話中は安定したショットを保ち、大きなカメラ遷移、複雑な格闘、別人の発話を重ねない。
- 尺が足りなければ、シーンまたは総尺を延ばす。総尺上限がある場合は、動作、カット、エキストラ、VFXを先に簡略化する。ユーザー確定済みのセリフは自動で短縮せず、なお収まらない場合だけ尺延長またはセリフ変更をユーザーへ相談する。
- 「残り時間で急いで話す」「台詞を圧縮する」「言い換える」「反復する」指示は禁止する。

## `script.md`の構成

説明、見出し、映像プロンプトをすべて日本語で書く。例外として、ファイル名、モデル名、技術識別子、Hepburn romanization、English-speaker phonetics、IPAは必要に応じて英語表記のまま保持する。発話・表示する日本語はかぎ括弧内に一字一句正確に保持する。

1. `# <タイトル> — Seedance用<総尺>マスタープロンプト`
2. `## 参照画像`
3. `## 厳守方針と優先順位`
4. `## 最初のフレーム`
5. `## 最後のフレーム`
6. `## 小道具と状態の連続性`
7. `## 日本語セリフと発音の固定`
8. `## セリフ尺の監査`
9. `## Seedance動画プロンプト`
10. `## CapCut／Seedance入力設定`
11. `## 正史・物理・出力監査`

### 参照画像

画像ごとにファイル名、固定する特徴、用途、拘束範囲を日本語で明記する。シートの枠線、グリッド、見出し、矢印、注釈、ターンアラウンド配置は動画に出さない。

- キャラクターシート：顔、体格、衣装、色、身体構造、必須小道具、NG変更を厳守する。設定シート自体のコマ割りは動画構図として複製しない。
- 環境シート：地理、建築、照明、出入口、モニター位置、避難経路、破壊前後の状態を厳守する。
- アクション／VFXシート：発生源、動作順、軌道、方向、接触点、損傷範囲、色、消失状態を厳守する。
- カメラ／構図シート：指定されたレンズ、カメラ高、角度、移動、ショット順、人物位置、前後関係を厳守する。

ユーザーが明示的に自由度を求めない限り、すべての入力画像を、その画像に指定した役割について拘束力のある指示として扱う。「高品質化」「映画的」「創造性」は画像や台本を変える許可にしない。自由度を求められた場合も、変更可能な項目だけを列挙し、それ以外は厳守する。

### 厳守方針と優先順位

次の優先順位を`script.md`と動画プロンプト冒頭の両方へ書く。

1. 必須セリフと音声：指定話者、全文、回数、順番、発話区間を厳守する。
2. 秒単位の時間構成と物語の因果関係。
3. 参照画像の用途別拘束、キャラクター設定、正史、小道具と状態の連続性。
4. 画質、演出、装飾的VFX。

映像と音声が競合したら、カメラ移動、同時アクション、エキストラ、破壊VFXの順に簡略化し、必須セリフを守る。品質目標や作風参照は描画の仕上げだけに使い、画像、台本、セリフ、タイムコードを上書きさせない。

### 日本語セリフと発音の固定

各セリフに、話者、正確な日本語、かな読み、Hepburn、英語話者向け音写、IPA、声と感情を記載する。発音情報は無音の指示であり、発話、字幕、画面表示を禁止する。台詞の追加、翻訳、言い換え、反復、重なりも禁止する。

### セリフ尺の監査

表に `話者 / 正確なセリフ / モーラ / 発話速度 / 最低発話尺 / 指定発話区間 / 必要な演技尺 / 指定演技区間` を記載する。発話区間は最低発話尺以上、会話ビートは必要な演技尺以上にする。

### Seedance動画プロンプト

映像全体を日本語の1つのコードブロックにまとめる。冒頭に`【厳守モード】`と`【必須音声チェックリスト・絶対に省略しない】`を置く。チェックリストには全セリフの話者、正確な全文、開始・終了時刻を台本内と重複して記載し、各1回、順番厳守、追加音声禁止、映像より音声優先を明示する。

`【0.0〜5.5秒】`のような可変長ブロックで総尺を隙間・重複なく埋める。各ブロックに次を順番に書く。

- その区間の主目的を1つ
- レンズ、構図、安定したカメラ移動
- 前状態 → 動作 → 後状態
- セリフの正確な開始・終了時刻
- 区間終了時の画面状態と次の接続点

1区間へ複数の大技、長台詞、複雑なカメラを詰め込まない。会話区間は口元と表情を優先し、アクション区間と分ける。末尾に`【画質と演出】`、`【キャラクター固定】`、`【VFX固定】`、`【色と照明】`、`【カメラ固定】`、`【禁止事項】`、`【生成形式】`を日本語でまとめる。

必須セリフについて、省略、欠落、短縮、途中終了、言い換え、翻訳、反復、順序変更、重複、不明瞭化、置換、音楽や効果音によるマスキングを、冒頭チェックリストと末尾の禁止事項の両方で禁止する。発話区間のカメラを安定させ、大きな画面転換や複雑な同時アクションを入れない。

設定が未指定なら、最後に検証できた基準としてSeedance 2.5、最大30秒の単一プロンプト、480p、16:9を使う。ユーザー指定や利用可能なモデル設定があればそちらを優先する。

## 入力画像の扱い

キャラクターシートを外見・構造の厳守画像として渡す。環境、アクション、VFX、カメラ、構図の各シートも、指定した役割の厳守画像として追加する。単なる「参考」「創造的に改変可能」「より映画的なら変更可能」と書かない。開始・終了フレームは、構図や変化の両端を固定する必要がある場合だけ生成して入力表へ追加する。未生成ファイルを「入力する」と書かず、`任意、未生成`と明示する。

## 最終監査

- 全区間の時刻が総尺を過不足なく埋めている
- 全セリフが時間検証を通り、発話中の複雑な同時動作がない
- 動画プロンプト冒頭に全セリフの必須音声チェックリストがある
- 必須セリフの全文、話者、回数、順番、発話区間が台本とチェックリストで一致している
- 発話内容、読み、Hepburn、音写、IPAが一致している
- キャラクターシートと動画プロンプトの顔、衣装、体格、NG変更が一致している
- 環境、アクション、VFX、カメラ、構図の各画像について、拘束範囲が明記され、プロンプトが一致している
- 「創造性」や「品質向上」が、画像・セリフ・タイムコードを上書きする記述になっていない
- 小道具が前状態 → 動作 → 後状態で連続し、勝手に補充、消失、破損しない
- 正史と現在の`WORLD_BIBLE.md`に整合する
- 入力対応表に実在するファイルだけが記載されている
