# Seedance生成後監査

## 1. 監査素材を作る

動画全体と、必要ならアクション区間を指定する。

```bash
python3 .claude/skills/seedance/scripts/audit_seedance_video.py \
  03_SCRIPTS/<run>/generated.mp4 \
  --action-start 7.9 \
  --action-end 22.9
```

次を確認する。

- `metadata.json`: 総尺、解像度、FPS、映像・音声ストリーム
- `full_1fps.png`: 全体の順序、早すぎる転換、状態の突然置換
- `action_2fps.png`: 左右、視線、接触、反動、累積破壊
- `scene_cuts.txt`: シーン切り替え候補。指定時刻との差を比較する

シーン検出は明るさや動きでも反応する候補値であり、編集点の断定には使わない。コンタクトシートと動画を併せて判断する。

## 2. 絵コンテと照合する

各コマについて次を順に見る。

1. 指定人物が指定側にいる
2. 相手へ視線と胸が向いている
3. 予備動作の後に接触している
4. 接触点から正しい方向へ反動と破壊が起きる
5. 壊れた物と破片が以後のショットにも残る
6. 次のコマへ位置、小道具、背景状態が接続する

Seedanceが作った中間動作は、絵コンテの両端と因果を守る限り採用する。絵コンテにない二次的な破片やカメラの微動だけを理由に失敗としない。

## 3. 音声を人間が確認する

波形やスペクトログラムだけで、正確な日本語が発話されたと断定しない。動画を聴き、ユーザーの聴感報告を正本として次を確認する。

- 話者
- 一字一句の全文
- 発話回数と順番
- 指定語の発音
- 語尾の欠落
- 効果音や音楽によるマスキング

短いアクション掛け声が欠落しても、通常セリフの尺計算自体が誤りだったとは限らない。同じ掛け声が2回欠落したら、プロンプト反復ではなく後付け音声または短い別クリップへ切り替える。

## 4. 修正先を選ぶ

| 失敗 | 主な修正先 |
|---|---|
| 左右交換、明後日の方向への移動 | ブロッキング絵コンテ |
| 接触前に破壊、反動方向が逆 | ショット絵コンテの接触コマ |
| 終盤で突然ボロボロになる | 累積状態と各ビートの後状態 |
| 技や文字の形が違う | VFX・アクションシート |
| セリフが途中で切れる | 会話ビートの尺とカメラ安定 |
| 短い掛け声だけ欠落する | 後付け音声、短い別クリップ |
| 境界が約1秒以上ずれる | クリップ分割とCapCut編集 |
| 顔、衣装、体格が変わる | キャラクターシートと入力優先順位 |

失敗していない参照画像と時間区間は作り直さない。次回ランには採用する正本だけを入れ、失敗動画と没画像をSeedanceへ入力しない。
