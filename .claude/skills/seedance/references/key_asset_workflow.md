# Seedance向け本番用重要アセット設計

## 目的

画面内で読ませる、または形を厳密に再現させる小道具・ロゴ・画面を完成画質で用意する。Seedanceへ渡す画像自体を、意匠・文字・材質の正本として使う。

## 作る条件

次のいずれかに当てはまれば個別アセットを作る。

- 台詞やオチの意味が、チラシ、看板、画面、ラベルの文字に依存する
- タイトルロゴ、紋章、印章、宗教記号など、同じシルエットと配色を再現する必要がある
- 人物が手に持つ、読む、指す、破る、掲げる、画面へ大写しにする
- 文章だけでは、材質、印刷、発光、傷、折れ、透明感を同じ形で再現しにくい

背景の一般的な机、椅子、船具など、文章と環境シートだけで十分な物は増やさない。

## 画像の役割と命名

| 種別 | 命名例 | 正本にする要素 |
|---|---|---|
| 印刷物・小道具 | `prop_fde_recruitment_flyer_production.png` | 外形、紙質、印刷、全文、余白、折れ |
| ロゴ | `logo_manmonth_mystery_master.png` | 字形、階層、縁取り、配色、装飾、透明余白 |
| 画面 | `screen_job_listing_production.png` | UI、表示文字、色、状態 |
| 看板・標識 | `sign_village_entrance_production.png` | 材質、形、文字、経年変化 |

正面マスターは1ファイル1アセットとし、説明欄、指示文、比較案、ターンアラウンドを入れない。必要なら、映像で使う16:9背景込み版と透過・単体版を別ファイルにする。

## imagegenプロンプト

次を明記する。

1. 用途：Seedanceへ直接入力する本番用アセット
2. アセット種別と画面での使われ方
3. 正面、遠近、余白、背景または透過の指定
4. 材質、印刷方式、汚れ、発光、縁取り、解像感
5. 表示する文字を引用符付きで一行ずつ逐語指定
6. 禁止する文字、ロゴ、説明パネル、透かし、別案
7. 既存画像を直す場合、保持する要素と変更する要素を分離

既存作品を参照するパロディロゴでは、題名の階層、色域、時代感、ジャンル記号など必要な特徴を分析し、作品固有の字形やキャラクター図案をそのまま複製しない。パロディ側の題名とモチーフで新しい字形を作る。

## 文字と画質の監査

`view_image`で原寸確認し、次を一項目ずつ照合する。

- 指定した全行が正しい順番で一度ずつ存在する
- 漢字、かな、英数字、句読点、単位に誤りがない
- 禁止語、旧設定、透かし、署名、説明文、意味不明な疑似文字がない
- 小道具の端が切れず、正面形と余白が再利用しやすい
- 印刷物は紙、ロゴは縁取り・透過、画面は発光など、用途に必要な材質が読める
- サムネイルでも主要文字とシルエットが識別できる

不一致があれば該当アセットだけを再生成または編集する。誤字を抱えたままSeedanceへ渡さない。

## script.mdへの登録

参照画像表に、適用秒区間、厳守する文字・形・材質、映像への使い方を記載する。動画プロンプトでは「画像を参考に」ではなく、「この画像を意匠と全文の正本として自然に再現する」と書く。人物が持つ位置、左右の手、大きさ、向き、動かし方は対応する秒区間のテキストへ記載する。
