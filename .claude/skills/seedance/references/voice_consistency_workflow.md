# キャラクター音声の継続性

Irodori-TTSで生成したセリフWAVをSeedanceのボイスサンプルとして使い、シナリオをまたいで声を固定する。配役と参照WAVは`02_CHARACTERS/VOICE_CAST.md`を唯一の正本にする。

## 正典を固定する

- モデルID、参照WAV、既定seedを配役表どおりに使う。
- 感情や演技を変えても、話者identityを決める参照WAVとモデルIDは変えない。
- 参照WAV、モデル、固有後処理を変更するときは代表セリフを旧版と比較試聴し、配役表のSHA-256も更新する。
- 参照音声の本人同意と公開範囲を確認する。

## セリフごとのボイスサンプルを作る

1. 台本の日本語本文を確定し、漢字で読みが揺れる場合だけ発話用テキストをかなへ直す。台本の表示本文は変えない。
2. 配役表の参照WAVと既定seedで候補を作る。`--seconds`と`--duration-scale`は指定せず、v4.1-Smallの自動尺推定を使う。
3. 演技を調整するときはcaptionへ感情、距離感、抑揚、語尾を短く書く。話者identityは参照WAVに任せ、captionで年齢、性別、別の声質へ作り替えない。尺に収める目的で話速や固定秒数を強制しない。
4. 1〜2モーラ程度の短い相づちや掛け声は、自動尺が間延びする場合がある。固定秒数で補正せず、単独候補が不自然なら採用しない。同じ話者の自然な長めの採用WAVを声質サンプルとして再利用し、Seedanceへ正確な短い台詞を生成させる。
5. そば屋はIrodori-TTS出力を`sobaya_monsterize.sh`へ通した後のWAVを候補にする。
6. 前後の無音をトリムした各候補をユーザーへ提示し、採用テイクの確認を得る。別seedを使った場合も記録する。
7. 採用WAVだけを`clip<N>_line<M>_<character>.wav`としてラン専用ディレクトリへ置く。

```bash
IRODORI_TTS_DIR=/absolute/path/to/Irodori-TTS \
  .claude/skills/seedance/scripts/irodori_speak.sh \
  '大変驚いております' \
  03_SCRIPTS/<NN>_<slug>/clip1_line1_okayaman.wav \
  02_CHARACTERS/Okayaman_voice.wav \
  42 \
  '落ち着いた成人男性。驚きを抑えながら、自然な会話の間と抑揚で話す。'
```

Irodori-TTS本体は公式リポジトリを使う。macOSでは`tools/setup_irodori_tts.sh`を実行すると、既定で`.local/Irodori-TTS`へcloneし、`uv sync --extra cpu`でCPU/MPS環境を準備する。生成スクリプトはこの既定配置を自動検出するため、別の配置を使う場合だけ`IRODORI_TTS_DIR`を指定する。`main`のコードと固定チェックポイント`Aratako/Irodori-TTS-v4.1-Small`を使い、モデルIDを自動で別リリースへ変えない。

## Seedanceへ渡す

- 生成WAVは完成動画へ重ねる最終音声ではなく、声質・話し方・セリフ内容を固定するボイスサンプルとして`@Audio N`へ添付する。
- プロンプトで`@Audio N`と話者画像を一対一に結び、話者、正確な台詞、声・トーン・話し方をサンプルへ合わせることを明記する。
- 画面内の非話者は「話さない、口を閉じる」と明記する。原則として1クリップ1話者にする。
- 話者の口は発話中だけ動かし、発話終了後は閉じるよう指示する。
- セリフ入りクリップの尺はサンプルWAVの合計長＋約1秒を目安にし、無言の間が長い場合は別クリップへ分ける。

貼り付け用プロンプトでは次の意味を日本語で明示する。

```text
@Audio 1=<file>.wav。<人物>のボイスサンプル。声質、トーン、話し方だけを厳守し、BGM、雑音、別話者はコピーしない。Seedanceがこの声に合わせて実際の日本語台詞を生成する。
```

## 最終音声を決める

- Seedanceが生成したクリップ埋め込み音声を最終音声の正本にする。
- ボイスサンプルWAVをCapCutタイムラインへ重ねたり、埋め込み音声と差し替えたりしない。二重音声とリップシンクずれの原因になる。
- サンプルと生成発話の尺差は許容する。声が違う、台詞が不明瞭、口パクがずれる場合は、そのクリップだけ再生成する。
- 最初に話者を含む1クリップをパイロット生成し、声、話者割当、口パク開始・終了、二重音声がないことを確認してから残りを生成する。
- 全クリップを通しで聴き、同一人物の声質が各ボイスサンプルから逸脱していないことを確認する。
