# 窓際族物語・B案「窓際通信」

選択されたB案を作り込んだローカルサイト。生成りの紙面と深緑、作品写真が先に見える配置を軸に、トップから作品・人物・原作へ巡れるようにした。
本番のルート、DB、公開コンテンツは変更していない。

## 開く

| ページ | URL |
| --- | --- |
| トップ | http://localhost:4173/?view=paper |
| 動画一覧 | http://localhost:4173/?view=paper&page=movies |
| 登場人物 | http://localhost:4173/?view=paper&page=characters |
| そば屋 | http://localhost:4173/?view=paper&page=characters&character=sobaya |
| 世界観 | http://localhost:4173/?view=paper&page=world |
| 原作漫画 | http://localhost:4173/?view=paper&page=story&chapter=1 |
| ギャラリー | http://localhost:4173/?view=paper&page=gallery |

ルートURLもB案を表示する。前回の比較版は `/?compare=1&view=paper` で確認可能。通常表示は比較用のUIを出さず、旧比較版のコードとCSSも読み込まない。
同じネットワークのスマートフォンでは、Viteが表示するNetwork URLの4173番ポートで開く。

## 起動

`16_MADOGIWA_STUDIO/`で実行する。この環境は素材取得済み。

```sh
npm run dev:design
```

キャッシュの再作成にはcurlとffmpegを使用する。

```sh
npm run prepare:design
```

## 仕上げた内容

- 大きな映像、短い作品名・あらすじ。不要な大見出しや管理IDを出さない。
- 最初の一本、初めての方へ、新着、人物特集、原作・ゲーム、アートの順で紹介。
- 動画検索、ジャンルと出演者の組み合わせ絞り込み、0件時のリセット。
- 8人の独立した紹介ページ、個別プロフィールと口癖、出演作品、仲間との関係と共演動画。
- 推しの登録・解除・推しだけの一覧。localStorageに保存し、ログインは要求しない。
- キャラページURLのコピー、前後の人物、ブラウザの戻る・進む、直接URL対応。
- 世界観紹介ページと、原作14話の独立した読書ページ。話数選択・前後移動・画像拡大。
- 動画モーダル、連続して選べるおすすめ、再生終了・読み込み失敗の表示、出演人物への移動。
- そば屋の採用音声再生。動画を開いたら音声を停止し、音が重ならないようにする。
- 画像ギャラリーと拡大表示。ゲームセンターへの外部リンク。
- スマホメニュー、キーボード操作、ページ移動時の見出しフォーカス、reduced-motion対応。

## 素材とデータ

`episodes.json` は2026-09-12に公開APIから取得したスナップショット。再生動画のない項目と登録検証用コンテンツを画面から除外。
`journal-data.ts` は公開表示用の短い紹介、キャラクタープロフィール、ジャンル分類を保持する。人物の紹介は `02_CHARACTERS/*.md` の通常形を参照。
素材や本文の更新を本番には送信していない。動的APIとの接続・SSR・OGP統合は本番採用時の作業。

公開サムネイルと代表動画7本は `public/cache/` に保持。このキャッシュとビルド生成物はGit管理しない。
残りの動画は公式サイトから再生するためインターネット接続が必要。
`public/site` と `public/voice/sobaya.wav` は正本への相対symlink。
そば屋の音声は `03_SCRIPTS/59_sobaya_professional_window_side/sobaya_answer01_beer.wav`。

`editorial-professional.jpg` は採用動画の24秒、`editorial-trailer.jpg` は採用予告編の36秒から抽出。暗転や導入カットよりキャラの顔が伝わるフレームを選び、`prepare:design`で再現する。
この環境の予告編動画キャッシュは、Studio登録記録が指す `03_SCRIPTS/66_madogiwa_super_try_invasion/final_remotion_trailer_voice-v3.mp4` への相対symlink。

WebフォントはGoogle Fonts。取得できない場合はシステムフォントへフォールバック。酒場ヘッダーの提灯はThree.jsで描画する（詳細は下記）。

## 窓際酒場（04・2026-09-12）

初回の通常スタイルは窓際酒場。`/?theme=sakaba` で明示指定できる。
暖簾、和紙、朱色のお品書き、筆文字を全ページに適用。レイアウト・動画プレイヤー・ピックアップ・人物情報・原作などはB案と共有する。

- `sakaba.css`: 04のスタイル。HTMLの `data-theme` で限定し、既存B案に干渉しない。
- `site-theme.ts`: URLとlocalStorageによるスタイル選択。ヘッダーの着せ替えとフッターで04〜07／窓際通信を切り替えられる。
- 05 Excel / 06 地下労働 / 07 駄目エンジニアも実装済み（下記）。
- `source-assets/sakaba/`: imagegen原本と全文プロンプト。
- `public/themes/sakaba/`: 配信用テクスチャ、筆文字書体、OFL。

各スタイルはテーマ属性でCSSを限定し、ナビゲーション・フィルター・お気に入り・プレイヤーを共有する。

04最終確認: 型検査・lint・本番ビルド通過。1280px/390px/320pxの表示、320pxと390pxで横はみ出しなし、モバイルメニュー、人物詳細、ピックアップ16件の初期選択、スタイル変更と再読み込み保持を確認。メイン動画は `readyState=4`・再生時刻の進行を確認。スクロール後の漫画・人物・ゲーム素材の遅延読み込みも確認。ブラウザconsole errorなし。


## 暖簾とそば屋提灯（2026-09-12）

丸いブランドアイコンを外し、左側にそば屋の刷り絵を入れた立体提灯を吊った。ブランドリンクと提灯ボタンは独立しており、提灯を押してもページ移動しない。

- `sakaba-entrance.tsx`: 布と提灯。灯りのon/off、CSS静止版からWebGLへの切替。
- `sakaba-entrance.css`: 布ごとの縫い目・裾・ひだ・控えめな揺れと灯りの反射。スマホでは3枚の布、PCは5枚。本文の文字はHTMLのまま。
- `lantern-scene.ts`: Three.js 0.185.1、LatheGeometryの和紙胴・竹ひご・上下の塗り枠・吊り金具・曲面に沿う刷り絵。emissiveと暖色ライトで点灯。背景への淡い光はCSSで補助。
- Three.jsは酒場表示時に動的import。描画は最大30fps・DPR上限1.5、影マップやポストエフェクトなし。画面外・非表示タブで停止し、表示再開時に復帰。テーマ変更時はgeometry/material/texture/rendererとobserverを解放。
- `prefers-reduced-motion`では布と提灯の揺れを停止。WebGL初期化失敗・コンテキスト喪失時はCSS提灯に戻る。検証用 `/?theme=sakaba&lantern=static` でCSS版を確認できる。
- Node 24.20.0で型検査・lint・ビルド通過。Three.js動的チャンクはgzip約134KB（minify後約530KBのためViteの500KB警告あり）。顔素材は約41KB。

操作確認: PC、390px、320pxで提灯と布を目視。点灯/消灯と暖簾への光、メニュー開閉・動画一覧ピックアップ表示、画面外でフレーム数が増えないこと、誌面テーマへ変更するとcanvasが0個になり酒場へ戻すと1個になること、CSS静止版でも点灯操作できることを確認。320pxで横はみ出しなし。

### 赤提灯への変更

提灯はそば屋の顔柄から定番の赤い和紙へ変更。右列「窓際で」、左列「生きていく」の縦書き。`lantern-label.ts`が3Dと静止版で共有する文言の正本。部分フォント `public/themes/sakaba/lantern-lettering.ttf`（Yuji Syuku、同梱OFL適用）を読み込み、CanvasTextureに正確な文字を描いて曲面に貼る。旧顔素材は制作履歴として保持するが読み込まない。3Dの点灯・消灯・揺れ・画面外停止は継続。
