# たこさん 浮遊モーション

起動: リポジトリルートで `python3 -m http.server 8778 --bind 127.0.0.1`。
URL: http://127.0.0.1:8778/tools/preview_takosan_float.html
依存: 既存 `.local/vrm-validation/node_modules/three`。

公式サイト用最新版 `rig_radial_v5_clean/takosan.glb` を直接読み込む。
`takosan_float_motion.mjs` の `TakosanFloatMotion` が既存27骨のレスト回転を基に、6本×3関節の位相をずらして動かす。モデルの形状や既存クリップは変更しない。

- 浮遊: ゆっくり上下、速度0–3m/sに応じ最大約23度前傾。
- 無重力スイム: 触手の周期的な漕ぎと最大約38度の前傾。
- 速度とモード変更は指数補間。前傾を少し打ち消す頭部回転。
- その場表示は床を後方へ流し、円移動では半径1.4mの軌道で実移動。
- 停止・低速・高速、連続速度調整、自動加減速、正面・側面・斜め、骨表示、一時停止。

リアルタイム手続きアニメーション。GLBへの焼き込みやゲーム本編への採用はまだ行っていない。
検証: Node構文検査、Chromeでモデル描画・低速浮遊・高速スイム・側面表示を確認。ブラウザ警告/エラーなし。

## 触手の比較候補（2026-09-19）

A ゆらゆら / B 波打つ / C 一斉に漕ぐ / D 3本ずつ交互 / E 先端くるくる。
体の移動スタイルとは独立して切り替え、0〜1.5倍の振幅調整と体の揺れ停止で比較できる。

初版の触手名の照合には不具合があった。GLTFLoaderが `Tentacle1.Base` を `Tentacle1Base` に変換するため、初版は触手へ回転を適用できていなかった。区切り記号なしにも対応し、18関節が見つからなければ明示的にエラーにする。初版の目視確認だけでは触手の駆動を検証できていなかった。

回帰確認: リポジトリルートで `node tools/validate_takosan_float.mjs`。
正本GLBをGLTFLoaderで読み込み（検証時のみ画像・材質を除外）、体を固定して5候補すべての18関節の回転変化とスキニング後の頂点変位を確認。0.75秒間の最大頂点変位は約0.13〜0.27m。Chromeで18/18関節の検出、C/Bの触手変形・候補切替・体固定を確認し、警告/エラーなし。
