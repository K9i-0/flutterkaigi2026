## 映像仕様

32秒、2622×1206、60fps。simctl標準録画の回転メタデータを反映し、リサイズせず使用する。録画中は他の生成・変換処理を止める。ゲーム内FPS表示をオンにして収録。アプリは高精細描画（fullResolution=true、内部renderScale=1.0、MSAA、影3カスケード）で再収録。debugビルドの撮影であり性能測定ではない。

プレイの導入 → キャラクター選択で3人の難易度を紹介 → 夜のプレイ → ギャラリーの赤坂（昼／夜） → キャッチと合格条件 → タイトル画面で「ゆめみ採用試験に、あなたも挑戦しよう！」。タイトルを最後まで保持し、発話の後に余韻を置く。

枠・ヘッダーなし。字幕は720p換算25pxの通常ウェイト1行。表示サイズだけ解像度へ比例させる。ゲーム・ギャラリー内UIは収録のまま。
