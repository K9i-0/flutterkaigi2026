**そば屋ハザード — ステルス／ホラー実装仕様（2026-09-08）**

承認されたプランを本編 `lib/game_main.dart` に実装した。以下は現在のソースの仕様と、完成度を判断するために残る確認をまとめる。数値は本作の初期調整値で、参考作品からの流用ではない。統合テスト・ネイティブ操作・配布ビルドの最終記録は末尾へ追記する。

目標は、発見中にはそば屋が迫って判断を急がされ、視界を切った後には足音を聞きながら隠れ場所を選び直す体験。最初の角で止まるだけでは危険だが、静かに隠れ直す判断が生還につながるようにする。村・農場は観察・誘導・背後破壊で抜けられる構成にし、銃は失敗時の立て直しや物資回収に使える。

2. **視界、聴覚、記憶を分けた**

   建物の壁・床に加え、箱・樽、地形側で追加した幹や遮蔽物を視界判定へ含める。箱・樽は実際の高さだけを遮り、頭や体が上に出ていれば隠れ切れない。破壊済みの箱と開いた門は遮蔽から外す。敵の視界表示も同じ遮蔽物の判定を使う。

   目視なら福ちゃんの正確な位置と時刻を覚える。音だけなら音の種類、時刻、確度とおおよその場所を記憶する。明瞭な近い音は0.75m、遠い音は1.8m、遮蔽越しは3.2mを基準にした領域で推定する。同じ領域の足音を繰り返しても、ランダム誤差の平均によって停止位置へ収束しない。推定地点は歩ける経路へ合わせる。

   聴取の基本半径は忍び足0.7m、歩行4m、ダッシュ9m、ハンドガン22m、ショットガン34m。壁と階層差で弱まり、移動音は実際の移動距離から発生する。壁へ押しつけているだけでは足音を増やさない。窓・梯子・着地・箱破壊も発生地点を持つ。

   無音で隠れ直している福ちゃんの現在位置は、捜索先の選定にも仲間への伝言にも使わない。連絡は近くの一体へ元の目視時刻を保って渡し、受け手から再伝言させない。同一時刻の古い連絡だけで捜索を延ばさない。HUDの敵方向は現在目視か最後の目視地点に基づき、見えない敵の現在位置を表示しない。

3. **発見中の強さと、見失った後の捜索**

   | 状態 | 実装した挙動 |
   |---|---|
   | 通常 | 向きと持ち場を保ち、配置された巡回路を歩いて立ち止まる |
   | 疑い | 視界内の姿で疑いが蓄積する。正面3m未満は約0.28秒、遠い忍び足や視界端は約1.43秒が初回発見の目安 |
   | 発見・追跡 | 通常そば屋は標準2.5m/s。近い敵が追跡・迂回・監視を分担し、旋回しながら接近する |
   | 見失い直後 | 最後に見た場所へ最大1.8秒追い込む。福ちゃんの現在位置へ目標を追従させない |
   | 捜索 | 最終確認地点、近い建物角、過去の進行方向から最大6候補を選び順に調べる。到達不能や確認済みの候補に留まり続けない |
   | 帰還 | 追跡を終え、視認を続けながら元の持ち場へ戻る。帰還の表示は最長8秒、帰路の移動は到着まで続ける |

   福ちゃんは歩行1.25m/s、ダッシュ2.8m/s、忍び足0.62m/s。見えている敵から歩いて離れ続けることは難しく、遮蔽まで走ってから静かに移る使い分けが必要になる。近接攻撃は攻撃開始と打点で実際の視線を確認する。見失った相手へ壁越しの攻撃を始めない。

   迂回先は既知の位置・方向・地形から決める。周囲の敵を全て同時に各出口へ割り当てる仕様にはしていない。帰路が閉じた門などで切られた場合は、到達可能な範囲の中で持ち場に近い地点を選び、捜索地点を新しい持ち場にしない。

   巨大そば屋は通常敵の捜索解除・ビール足止めの対象外。既存のボス戦が始まった後は遮蔽で一瞬見えなくても追跡の演出を維持し、通常敵の解除ゲージを適用しない。

4. **追跡解除と表示の約束**

   | 手がかり | 通常そば屋の基準時間 |
   |---|---|
   | 目視を失った後 | 追い込み1.8秒＋捜索13〜15秒、合計14.8〜16.8秒 |
   | 銃声を伴う捜索 | 追い込み1.8秒＋捜索19〜21秒、合計20.8〜22.8秒 |
   | 新しい弱い足音 | 一回最大0.65秒延長、一回の捜索で合計4秒まで |
   | 新しい走行音 | 一回1秒延長。走り続けると新しい手がかりを与え続ける |
   | 再目視・新しい銃声 | 再目視なら追跡へ戻り、新しい銃声なら長い捜索を始める |

   基準時間は新しい手がかりがない場合の初期値。捜索地点への到着を待たずに時計が進む。距離を離すだけの早期解除条件を通常敵から外し、近くでも視界を切って静かに隠れ続ければ解除できる。捜索中に隠れ場所を確認されれば再発見される。

   `state.stealthFeedback` は `phase / remaining / duration / suspicion / bearing / reason` を返し、HUD・BGM・画面周辺エフェクトで共有する。誰かが目視追跡していれば「発見中」を優先。捜索中は参加中の通常敵のうち最も長い残り時間を表示する。「足音を聞かれた」「新しい銃声」「近くのそば屋が呼びかけた」などの理由も出す。

   ミニマップは目視した敵だけを記録する。現在見えている敵は塗りつぶしと簡易視界、見失った敵は最後に見た位置の中抜きの点。追跡は赤、捜索は橙、帰還は灰緑、その他は黄。移動音の円は直近の発音半径の目安であり、壁越しの実聴取を保証する円ではない。

5. **ビール投げと村・農場の変更**

   PCは **4 → Q／右マウスで構え → Space**。スマホは **「武器」でビールへ →「構え」→「投げる」**。構えている間は放物線と着地点を表示し、実投擲も同じ衝突判定で進む。壁への投擲はそこで止まり、一度だけ着地音を出す。構え中は立ち止まる。装備・移動の常設操作は増やさない。

   一投でビール1杯を消費する。補給所で払うビールと同じ所持数なので、誘導に使うか弾・ハーブの購入へ残すかを選ぶ。0杯では投げられず、空撃ちによるリロードも行わない。空のビール装備から銃へ戻せる。

   着地は基本8mの `beer_lure` を一度発する。聞こえる範囲の担当一体が調べに行き、それ以外の未警戒敵は音の方向を少し見る。未警戒なら到着後4秒、警戒・帰還中なら約1.1秒の確認時間。目視で追っている敵と巨大そば屋は福ちゃんを優先する。捜索中の投擲は敵の確認方向を変えるが、追跡解除を即座に与える道具ではない。

   村入口に2杯、道中にも固定ビールを追加。村は建物裏・納屋の鍵へ向かう隠密経路と、二階のショットガンを取る寄り道を分ける。農場は見張り・巡回の組合せを読み、裏口と高い遮蔽物を使って進む構成へ変更した。村・農場の最高難度の全敵撃破必須条件を外し、山道の最終章条件は維持する。

   未発見の通常そば屋へ背後から約1.6m以内まで近づくと、E／「破壊」でそば屋が持つビールを壊して撃破できる。壊した敵から拾得用ビールは出ない。通常ショットガンは一体ずつの攻撃と全難易度での通常敵ヘッドショット一発を維持し、大きな銃声が危険を招く。

   ビールの飛行位置・時間・消費数・投擲間隔、敵の捜索記憶・残り時間をチェックポイントへ保存する。投擲直後の保存再開で間隔を飛ばして連投する不具合を回帰テストで修正した。旧セーブでは追加された固定物資を一度だけ補い、取得済みIDを残して重複させない。

6. **音楽、足音、画面の演出**

   | 公開状態 | BGMと効果音 | 画面 |
   |---|---|---|
   | 通常 | 地域の環境音と探索「閉店後」 | 通常HUD |
   | 疑い | 持続音を薄く加える。発見アクセントは鳴らさない | 黄色い発見ゲージ |
   | 発見・追跡 | 一回の発見アクセント、160 BPMの追跡「ラストオーダー・追い込み」。中音域の刻みと低音 | 赤い発見表示、画面周辺の薄い脈動 |
   | 捜索 | 追跡の打楽器を引き、無拍子の新曲「戸口の向こう」を小さく残す | 橙の解除ゲージと残り秒数 |
   | 帰還 | 数秒かけて探索と環境音へ戻す | 帰還表示。派手な成功演出は行わない |

   追跡音楽は見失い後0.65秒だけ保持し、約0.38秒の時定数で音量を下げる。短い状態往復で曲を再始動させない。追跡→捜索→再発見は一回の遭遇として発見アクセントを重ねず、通常・帰還が3秒続いてから次の遭遇音を受け付ける。ポーズ中は音楽の切替時計も止まる。

   未発見の敵が近いだけでは音楽を変えない。敵の足音は実移動量から発音し、距離・遮蔽・高さで減衰する。靴底・擦れ・ジョッキの薄い共鳴、ビール投擲の衣擦れ、着地のガラス・液体は新しい非言語DSP音。正典の人物の声は変更しておらず、別人の呼吸・発話は生成していない。

   捜索曲と効果音は `tools/build_hazard_search_score.py`、`tools/build_hazard_stealth_foley.py` から再生成できる。採用正本は `04_GAME_ASSETS/audio/hazard/`。マニフェストにseed・波形仕様・ハッシュを記録し、ゲームの相対symlinkから参照する。既存の探索・追跡曲も無音中から連続再生する。

   設定の **「緊張感の画面演出」**（`threatEffects`）は0〜100%、初期70%。画面周辺の色・脈動だけの強度で、0%でも発見・捜索HUDとBGMは残る。BGM・効果音・環境音・台詞は個別の音量設定を使う。照準の中央やタッチボタンを揺れ・ぼかしで覆わない。

7. **検証と実プレイでの調整**

   `game_beer_throw_test.dart` は消費・空・停止・動作制限、3照準高×4フレーム刻みの予測と着地、壁で一回の誘導音、飛行中の保存復元、連投間隔、旧セーブの新規物資、箱の破壊前後の遮蔽を検査する。`game_horror_soundscape_test.dart` は捜索時の打楽器退場、遭遇音の重複防止、停止と再開、近接情報だけでは反応しない音楽、追加PCMを確認する。AI側のテストは壁越しの無音移動・情報源・有限の捜索・帰還・誘導分担を扱う。

   実装の合格だけで面白さを完成と判断しない。村・農場の同じ開始条件で「走り続ける」「最初の角で停止」「遮蔽後に忍び足で別の陰へ」「ビールで進路変更」「ショットガンで退路を開く」を比較し、再発見・被弾・解除時間・消費を確認する。通常操作と正しい発音・遮蔽を使い、敵の無効化や無敵による結果を攻略成立の証拠にしない。

   初見の人間による村・農場の通し難易度、長時間の緊張と休息の配分、スマートフォン実機の操作感・継続性能、物理スピーカーでの聞きやすさは、個別テストやシミュレーター確認とは分けて評価する。大きな音の聞こえ方と画面効果の好みも、数値だけでは決定しない。

通常テスト324件が通過（任意の全配置攻略監査1件は別実行）。追加の攻略・比較監査2件、ビール回帰10件、静的解析も通過。Macの連続描画では無傷の隠れ直し・14.8秒での追跡解除・持ち場への帰還・音楽5状態を確認。iPhone 17 Proシミュレーターの縦横画面で投擲と消費・操作領域を確認した。実機スマホの操作感・長時間性能は未検証。
