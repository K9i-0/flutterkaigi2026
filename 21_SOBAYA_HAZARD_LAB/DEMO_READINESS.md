# 体験版の完成確認

目標は「PS2／原作バイオ4を基準にした、ハイクオリティなそば屋ハザード体験版」。現行実装に合わせて完成条件を縮めず、未確認の項目は未完了として残す。まずMac版を検証基準にする。iPhoneを同時対象にするかはユーザーへ確認中。

| 要件 | 現在の根拠 | 判定と次の作業 |
| --- | --- | --- |
| 非ボクセルの福ちゃんを三人称で操作 | 正典画像由来のGLB、Mixamo歩行／走行、実機の移動・照準・回避・蹴り | 実装済み。開始・停止や段差の動作は仕上げ余地あり |
| そば屋・たこさん・やめ太郎の人物同一性 | `04_GAME_ASSETS/3d/characters/` の各正本と実機の会話・戦闘 | 4人を組み込み済み。口の動きと発話の同期は未実装 |
| 原作序盤を参照した基本マップとアイテム | 村・農場・山道、屋内・階段・塔、武器・弾・ハーブ・鍵 | 配置と役割を参照した新規制作。厳密な全寸法の1:1複製ではない。塔の梯子は連続した登降・敵の追跡・途中保存を実装し、実機確認済み。窓越え・掴みは未実装 |
| 無流血・敵消失・ビール1個 | 戦闘／チェックポイントのテスト、`qa/group-encounter-20260906.json` | 20体の個別ドロップを実描画の自動経路で確認 |
| 壁の窓際族画像を収集して鑑賞 | 12枚の正典画像、全収集監査、ギャラリーのスクロール／拡大 | 実装・検証済み |
| 体験版として完結する流れ | 導入→村→農場→山道→最終戦→エンディング、保存・補給・交換 | 全収集の既知経路で約7分32秒。これは初見の尺ではない。初見15〜25分の体験評価が必要 |
| 音声と音による演出 | 正典の発話25本、たこさんの反応6箇所、区画環境音と緊張時の音楽 | 再生制御・素材・ASR照合済み。人による聴感と声の本人らしさは未承認 |
| Flutter Sceneの軽量化 | 共有モデル、圧縮テクスチャ、可視判定、静的／動的影、近接ジョッキ制限、停止画面の連続描画抑制 | 音声付き9条件をprofile計測済み。標準85%では計測窓内の16.7ms超過なし、100%の村ではRaster超過あり。別のiOS Simulatorが描画中のため単独条件と長時間の検証が必要 |
| 通常の起動・再開・保存・終了 | debug起動、保存互換、区画往復・再開テスト | 通常Releaseで導入・射撃・持ち物・記録を操作確認。音声修正版のローカルMac ZIPを作成し、同梱素材・署名・ZIP整合性は合格。最終パッケージは実行プロセスを確認したがUI取得エラーのため画面未確認。長時間安定性も未完了（`qa/mac-preview-20260906.json`） |

完成宣言前には、上記の未完了事項を解決またはユーザーの対象範囲に照らして明確に扱い、採用した最終ビルドで通し確認する。古いベンチマーク、経路を知る自動ドライバー、ASRの成功だけで、初見体験・音声の自然さ・安定FPSを合格にしない。
