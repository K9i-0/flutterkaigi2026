# そば屋のオフィスクラッシュ ～無限フロア大整理～

窓際族のそば屋を操作し、図面にない「備品循環棟」を攻略する
3Dアクションハクスラ＋ローグライトです。

タコ部屋脱走時にできた人型の大穴の先で、謎のレギュレーション管理システムが暴走。
歩き出したオフィス備品を大型ビールジョッキで資材へ戻し、
8つのランダムビルド対応フロアを片付けます。

## ゲーム内容

- 通常戦、エリート戦、45秒クラッシュタイム、2種類のボスを含む全8フロア
- 回転アーロンチュア、ホチキスガニ、キャビネットゴーレム、会議机ムカデなどの暴走備品
- 金の複合機・零式、最終ボス `REGULATION CORE`
- ジョッキ本体、取っ手、ジョッキ底、ビール、おつまみなど12種類の戦利品
- 「生」「大生」「特大生」「店主秘蔵」の4レアリティ
- 泡の連鎖破壊、キンキン冷却、乾杯コンボ、焼き鳥回復などのビルド
- PERFECT SMASH、MULTI BREAK、MEGA SMASH、COMBO FREEZE
- ダッシュ回避、ボスの広範囲パルス、HPと回復アイテム
- PCとスマートフォンの両方に対応

## 永続記録

SitesのD1データベースを使用し、匿名プレイヤー単位で以下を保存します。

- 自己ベスト、最高到達階、総ラン数、総備品整理数、完全制覇数
- ラン履歴と獲得ビルド
- 王冠キャップ
- ジョッキ鍛造、最大HP、移動速度の永続強化
- 全プレイヤー集計と上位スコアボード

ブラウザ内ストレージを正本にせず、ゲームデータはサーバー側へ記録します。

## 操作

- PC: `WASD` / 矢印キーで移動、`Space`でスマッシュ、`Shift`でダッシュ
- スマホ: 左の仮想スティックで移動、右のSMASH / DASHボタン
- `P` / `Esc`: 一時停止

## 開発

```bash
npm install
npm run dev
npm test
```

Three.js、React、vinext、Cloudflare D1、Drizzleで構成されています。
