# そば屋のビールダッシュ

ジョッキtoジョッキで、本日開店！

そば屋を左右に動かし、赤坂の3レーンへ散らばったビールを集める
45秒の3Dランナーゲームです。正史第10話でそば屋が6個のジョッキを
抱えて走った出来事を、ゲーム固有の「6ジョッキ・チェイン」にしています。

## 遊び方

- そば屋は自動で前進する
- PC: `A` / `D` または左右矢印
- スマホ: 左右ボタン、画面左右のタップ、横スワイプ
- ビールを6杯集めると3秒間の「ジョッキtoジョッキ」が発動
- 発動中は近くのビールを引き寄せ、提供数が2倍
- 障害物に当たってもゲームオーバーにはならず、1杯失って少し減速
- 45秒後の提供数でC・B・A・Sランクを判定
- `P` / `Esc` または右上ボタンで一時停止

## エンディング

どのランクでも立ち飲み処は笑顔で開店します。
リザルトでは、正典写真を使った**実写のおかやまん**が大型スクリーン越しに登場。
提供数に応じた講評を行います。Sランクは72杯以上です。

## キャラクターと正典アセット

- プレイヤー: そば屋（白い仮面・大型ビールジョッキを維持）
- スタート: とーくん（アロハ・帽子・ウクレレを維持）
- 沿道: 福ちゃん（おしゃれ服・ギュンギュンポーズを維持）
- ゴール: たこさん（黒ローブ・白い顔・触手・人間の腕2本を維持）
- リザルト: 窓際王おかやまん（実写・穏やかな笑顔・スクリーン越し）

`public/models/*.glb` は
`../04_GAME_ASSETS/voxel/models/*.glb` への相対symlinkです。
GLBをゲーム内へコピーしたり、手作業で編集したりしません。
おかやまんの写真も `02_CHARACTERS/Okayaman.jpg` をsymlink参照します。

## カットシーン

タイトルの開始操作後に `videos/opening.mp4` を再生できる構成です。
動画がまだ配置されていない場合は自動でスキップし、そのままゲームが始まります。
完成動画を追加する場合は、正典置き場
`04_GAME_ASSETS/videos/sobaya-beer-run/opening.mp4` から
`public/videos/opening.mp4` へ相対symlinkを張ります。

## 開発

```bash
npm ci
npm run dev
npm test
npm run build:sites
```

Vite + TypeScript + Three.jsで構成されています。
ビールと障害物のコースは、全レーンが同時に塞がらない検証済みパターンを
シード付きで組み替えます。通常の`build`はGitHub Pages向け、
`build:sites`はSites公開向けの出力を作ります。
