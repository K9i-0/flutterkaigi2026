# そば屋のビールダッシュ

ジョッキtoジョッキで、本日開店！

そば屋を左右に動かし、赤坂の3レーンへ散らばったビールを集めながら
立ち飲み処まで458mを走る3Dタイムアタックです。正史第10話でそば屋が
6個のジョッキを抱えて走った出来事を、任意のタイミングで発動する
「ジョッキtoジョッキ」にしています。

## 遊び方

- そば屋はゴールまで自動で前進する
- PC: `A` / `D` または左右矢印で移動
- スマホ: 左右ボタン、画面左右のタップ、横スワイプで移動
- ビールを10杯集めるごとに速度が8%上がる（最大1.4倍）
- 障害物に当たると2秒間、速度が0.72倍になる
- ビールを6杯ため、`F` / `Space` または中央のFEVERボタンで
  4秒間の「ジョッキtoジョッキ」を任意発動できる
- フィーバー中は近くのビールを引き寄せ、提供数が2倍
- 障害物すれすれを通ると「ギリギリ快適！」で短時間加速
- `P` / `Esc` または右上ボタンで一時停止

## コースの変化

- 赤坂オフィス街 → 窓際BBQ通り → レギュレーション区 →
  WANTED BONUS ROUTE → 立ち飲み処前、と景色と看板が変化
- やめたろう区間の金ビールは3杯分。ただし障害物の間を左右に切り返す
  リスク・リワードの高いルート
- ゴール前50mは障害物なしの「乾杯ラッシュ」

## マドギワメンバーの支援

道沿いには全メンバーが登場し、通過時に固有の支援が発動します。

- とーくん: ウクレレの「ALOHA BOOST」で3秒加速
- よーたん: ギターの一撃で前方の障害物を1列消去
- 福ちゃん: 「ギュンギュンGUARD」で接触を1回無効化
- おかやまん: 中間地点の大型スクリーンに実写でリモート出演
- ゆめみん: 「BONK!」で減速を解除し、短時間加速
- やめたろう: WANTED金ビール区間を案内
- たこさん: 触手パワーで5秒間、3レーンのビールを引き寄せる

各ボクセルモデルはキャラクター設定のNG変更要素を維持しています。
おかやまんだけは意図的に正典写真を使い、穏やかな笑顔と
スクリーン越しの出演スタイルを守っています。

## ゴールと記録

ゴール時に `分:秒.百分の一秒` でタイムを表示します。端末内には次の3記録を
別々に保存します。

- 最速ゴールタイム
- 1プレイの最多提供数
- ノーヒット最速タイム

リザルトではタイム、提供数、最高速度、最大チェイン、フィーバー回数、
ニアミス回数、接触回数を表示。提供数によってC・B・A・Sランクを判定し、
実写のおかやまんが大型スクリーン越しに講評します。

## キャラクターと正典アセット

`public/models/*.glb` は
`../04_GAME_ASSETS/voxel/models/*.glb` への相対symlinkです。
GLBをゲーム内へコピーしたり、手作業で編集したりしません。
おかやまんの写真も `02_CHARACTERS/Okayaman.jpg` をsymlink参照します。

## カットシーン

タイトルの開始操作後に `videos/opening.mp4` を再生できる構成です。
動画がまだ配置されていない場合は自動でスキップし、そのままゲームが始まります。
完成動画を追加する場合は、正典置き場
`04_GAME_ASSETS/videos/sobaya-beer-run/opening.mp4` から
`public/videos/opening.mp4` へ相対symlinkを張ります。

## 開発

```bash
npm ci
npm run dev
npm test
npm run build:sites
```

Vite + TypeScript + Three.jsで構成されています。ビールと障害物のコースは、
全レーンが同時に塞がらない検証済みパターンをシード付きで組み替えます。
通常の`build`はGitHub Pages向け、`build:sites`はSites公開向けです。
