# ゆめみ採用試験用のおだてつ

元の `../rig_v1_20261014/cto_odatetsu_rig.glb` を保持したゲーム専用派生物。
20,348,912 → 14,148,156 bytes（30.5%減）。ゲームは相対symlinkで参照する。

- 三角形32,346・頂点37,130・1材質・54骨は変更なし。
- 頂点、面、UV、法線、骨ウェイト、バインド姿勢、材質を数値一致で検証。
- 4096×4096のPNGは可逆再圧縮のみ。復号RGBA画素の一致を検証。
- 使用するIdle / Walk / Runの3クリップを値・時刻・チャンネルごと保持。
  他の17クリップは元モデルに残し、ゲームへの同梱からだけ除外。
- glTF検証はエラー0。非rootスキンの警告1件は元モデルにも存在する。

顔・髪・首・手を固定した身体の簡略化も試したが、32,346 → 31,938三角形
（約1.3%減）にとどまったため不採用。候補は`.local/recruit-optimization/`へ保持。
残存頂点の全属性、保護対象18,917面の維持を確認した候補の数値は
`optimization.json`に記録している。簡略化の属性誤差指標は表面距離の保証ではない。

GLB容量の減少はGPUテクスチャメモリやFPSの30.5%改善を意味しない。
形状と画素は同じなので、主に配布・読み込みデータと未使用アニメーションの整理。

再生成（リポジトリルート）:

```sh
npm install --prefix .local/vrm-validation --no-save --package-lock=false three@0.185.1 gltf-validator
uv run --with pillow --with numpy python app/tool/optimize_odatetsu.py
```

モデル比較: 今のゲームでそば屋は127,034三角形・8プリミティブ、
福ギュンは37,865三角形・10プリミティブ、おだてつは32,346三角形・1プリミティブ。
そば屋・福ギュンは以前の最適化を基にした`hazard_rebuild/locomotion_v1`を使用中。
`hazard_adopted/mobile_20260919`にはさらに軽いモデルもあるが、歩行素材が異なるため
今回の変更で単純に差し替えてはいない。
