# そば屋ハザード — 再設計版

キャラクターと「ステルス要素のあるシューティング」を核にした新実装。既存版のマップ・ゲーム制御をコピーせず、Madogiwa Engineを利用する。

最初の区画「夜間搬入口」は配置・操作検証用の仮マップ。福ちゃんを操作して、巡回するそば屋を避けるか撃退し、制御盤で搬出口を開けて脱出する。通常移動は足音が届き、隠密移動は足音を抑える。射撃は周囲を警戒させる。視界を遮る箱は移動・射撃も遮る。

## 起動

```sh
cd 24_SOBAYA_HAZARD
mise exec -- flutter run -d macos
```

WASD移動、ドラッグまたはQ/E視点、C隠密切替、Spaceまたはクリック射撃、R装填、F制御盤操作、Esc停止、Nやり直し。起動時は停止状態から再開する。Mac操作が対象で、iPhoneの移動タッチUIは未実装。

## 構成

- `../packages/madogiwa_engine`: 共有の衝突・認知記憶・再生時計。
- `lib/game.dart`: この作品の巡回・射撃・目的・ダメージ。
- `lib/rendering.dart`: モデルとカメラ。ベイク済みシーンのZ変換を境界で補正。
- `assets/yard.json`: 描画生成と衝突で共有する区画定義。
- `tools/build_yard.py`: Blenderで仮マップを生成。
- `assets/models/{fukuchan,sobaya}.glb`: 共通資産置き場への相対symlink。

旧版の歩行系クリップは使用しない。独立制作したIdle/Walk/Runのみを派生モデルへ収録。登場人物の身体形状は維持する。モデル・動作はゲーム資産でありエンジンへ同梱しない。

## AI検証

Dart MCPで起動しMarionetteへ接続する。

- `madogiwa.inspectShooter`: ロード状態、体力・弾数・目的、各敵の認知記憶、描画済みランドマークの座標。
- `madogiwa.shooterAction`: `action=reset|step|fire|interact|reload|pause|resume`。
- stepは `seconds=0..20`, `forward/right=-1..1`, `yaw=ラジアン`, `sneak=true` を受け取り、通常のゲーム処理を60Hzで進めて止める。位置の瞬間移動や強制勝利を行わない。
- 診断停止は画面の一時停止パネルと独立。通常操作へ戻すにはresume。

## 初版の到達点と残件

Mac本編で移動→追跡→2発で1体撃破→制御盤→出口の通常入力シーケンスが完了。`qa/first-route.json` が状態記録。これは入力の決定論的実行で、通常速度でのプレイ動画評価や性能測定ではない。

仮マップ・仮戦闘表現であり、旧版より完成度が高いとはまだ評価しない。銃のモデルと構え・反動・命中演技、近接攻撃演技、音声・効果音、敵の経路探索、遮蔽物越しのカメラ改善、隠密ルートの難度調整、タッチ操作を今後実装する。倒れた敵は現状非表示になる。レーダーは検証用に敵位置を常時表示する。

次の区切りは武器と射撃の見た目・音を備え、この1区画で撃つ／隠れる判断に手応えを作ること。区画を増やす前にここを改善する。

## 初版の検証（2026-09-29）

- エンジン22件・ゲーム5件のテスト成功。両方の静的解析で指摘なし。
- Mac debug実画面とMarionetteで上記ルートの脱出を確認。最終人物資産でも同じ状態記録に一致。
- macOS releaseビルド成功。iOS releaseは署名なしビルド成功（実機動作・タッチ操作は未検証）。
- 派生GLBはIdle/Walk/Runのみ。ゲームの人物モデル参照は共通資産へのsymlinkを確認。
