# 体験版の完成確認

目標は「PS2／原作バイオ4を基準にした、ハイクオリティなそば屋ハザード体験版」。現行実装に合わせて完成条件を縮めず、未確認の項目は未完了として残す。まずMac版を検証基準にする。iPhoneを同時対象にするかはユーザーへ確認中。

| 要件 | 現在の根拠 | 判定と次の作業 |
| --- | --- | --- |
| 非ボクセルの福ちゃんを三人称で操作 | 正典画像由来のGLB、Mixamo歩行／走行、実機の移動・照準・回避・蹴り | 実装済み。開始・停止や段差の動作は仕上げ余地あり |
| そば屋・たこさん・やめ太郎の人物同一性 | `04_GAME_ASSETS/3d/characters/` の各正本と実機の会話・戦闘 | 4人を組み込み済み。口の動きと発話の同期は未実装 |
| 原作序盤を参照した基本マップとアイテム | 村・農場・山道、屋内・階段・塔、武器・弾・ハーブ・鍵 | 配置と役割を参照した新規制作。厳密な全寸法の1:1複製ではない。塔の梯子は連続した登降・敵の追跡・途中保存を実装し、実機確認済み。6か所の窓越え・敵追跡を実装し、実機確認済み。窓越えの片手支持と脚運びを改訂し、GLB再読込97姿勢で膝を含む2cm超の頂点干渉なし。改訂モデルで福ちゃんの往復・敵の順次通過を実機確認。そば屋の腰・裾のウェイトを修正し、尖った伸びと背面の隙間を改善。11クリップ・1167姿勢と実機の敵追跡を確認（`qa/sobaya-garment-20260906.json`）。掌の隙間と大きな姿勢での布の伸縮は仕上げ対象。正面の掴み・抵抗・長押し脱出を追加。実機で被弾を挟む長押し脱出、97テスト、追加5クリップのGLB再読込263姿勢を確認（`qa/grapple-20260906.json`）。新規モーションは手付けIKで、指の握り込み・布の干渉・全身の反応は仕上げ対象 |
| 無流血・敵消失・ビール1個 | 戦闘／チェックポイントのテスト、`qa/group-encounter-20260906.json` | 20体の個別ドロップを実描画の自動経路で確認 |
| 壁の窓際族画像を収集して鑑賞 | 12枚の正典画像、全収集監査、ギャラリーのスクロール／拡大 | 実装・検証済み |
| 体験版として完結する流れ | 導入→村→農場→山道→最終戦→エンディング、保存・補給・交換 | 窓・衣服修正後の規則検査は初期0枚から全12枚、実描画の既知経路は20体撃破・20ドロップ回収からクリアまで約7分41秒。実描画側は既収集12枚を引き継ぐ（`qa/campaign-traversal-20260906.json`）。初見15〜25分の体験評価が必要 |
| 音声と音による演出 | 正典の発話25本、たこさんの反応6箇所、区画環境音と緊張時の音楽 | 再生制御・素材・ASR照合済み。人による聴感と声の本人らしさは未承認 |
| Flutter Sceneの軽量化 | 共有モデル、圧縮テクスチャ、可視判定、静的／動的影、近接ジョッキ制限、停止画面の連続描画抑制 | 掴み追加前の11条件をprofile計測済み。全条件の240フレーム内でUI／Rasterの16.7ms超過なし（`benchmarks/game-traversal-20260906.json`）。標準85%を維持。別のiOS Simulatorが起動中で、単独条件と長時間の検証は未完了 |
| 通常の起動・再開・保存・終了 | debug起動、保存互換、区画往復・再開テスト | 旧Releaseで導入・射撃・持ち物・記録を操作確認。梯子・窓越え・衣服修正を含む `e7726a9` のMac ZIPを作成し、同梱素材・署名・ZIP整合性は合格。このZIPに掴みは未収録。更新版の実行プロセスを確認したがUI取得エラーのため配布版の画面は未確認。長時間安定性も未完了（`qa/mac-traversal-preview-20260906.json`） |

完成宣言前には、上記の未完了事項を解決またはユーザーの対象範囲に照らして明確に扱い、採用した最終ビルドで通し確認する。古いベンチマーク、経路を知る自動ドライバー、ASRの成功だけで、初見体験・音声の自然さ・安定FPSを合格にしない。
