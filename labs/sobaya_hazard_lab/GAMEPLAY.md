# そば屋ハザード — 村・農場・山道の体験版制作

福ちゃんで村→農場→山道を探索し、そば屋を撃退して脱出する3区画のゲーム。区画間の往復・補給・任意収集・途中保存を実装した制作中の体験版。PS2／原作バイオ4相当の仕上げと、初見15〜25分の体験評価は進行中。既知の経路を使う実描画の自動通し監査は完了しているが、初見プレイヤーの評価とは区別する。

## 起動

```sh
cd 21_SOBAYA_HAZARD_LAB
mise exec -- flutter pub get
mise exec -- flutter run -d macos -t lib/game_main.dart
```

Flutter 3.47.2 / Dart 3.13.2 / flutter_scene 0.23.0。global Flutterに合わせた既存mise設定を使用。従来のモデル検証室は `-t lib/main.dart` で起動する。

## 遊び方

- WASD／矢印で移動、Shiftで走る（歩行1.25m/s・走行2.8m/s）。ドラッグした方向へ視点・照準を向ける。横方向が逆になる処理を修正済み。マウスとトラックパッドで共通。
- 右マウスボタン長押し／Qで構える。左ボタン／Spaceで発砲、Rで装填。構え中は立ち止まる。
- Eで拾う・調べる・話す・木箱を壊す・はしごを使う。1／2で武器切替、Hでハーブ回復。
- 正面のそば屋が掴む予備動作を見せたら回避する。掴まれた場合はEまたは画面の脱出ゲージを長押しして振りほどく。連打は不要。拘束中もEscで停止・保存できる。
- Xで方向入力への回避（無入力なら後退）。頭を撃ってひるませたそば屋に近づき、Fで蹴る。回避は壁を通り抜けない。
- 村入口のやめ太郎にEで話しかける。Eで台詞を進め、ボタンで話題を選ぶ。各周回で弾10発を一度だけ受け取れる。Escで会話を終える。
- Tabで10×6のアタッシュケース。ドラッグで配置、クリックで装備・使用・ハーブ調合。
- Mで現在区画の全体マップ。門・出口・仲間・現在地を確認する。
- Cで収集した画像を鑑賞。クリックで拡大する。Escで一時停止。タイトル／一時停止の「設定」から難易度3段階、音量・消音、視点感度0.5〜2倍、画質3段階を変更できる。設定はセーブの読み込みと独立して保存する。
- 導入・農場初到着・最終戦開始・脱出後に3D会話シーン。E／Spaceで次へ、Escで停止／再開、スキップボタンで探索へ戻る。イベント中は戦闘と探索時間を止め、背景化でも進まない。
- そば屋を倒すと流血せず消失し、ビールが1個出現する。ビールは、入口の家の西側にいるたこさんの補給所で使用する。弾10発=2杯、グリーンハーブ=3杯、ショットガン弾5発=3杯。在庫制で、ケースに入らない取引ではビールを消費しない。
- 二階建ての家にショットガン、北側の納屋に紋章の鍵。門を開けてその先へ進むと農場へ。農場の東の門は鍵不要。山道の廃屋前の強敵を撃退し、東の門を開けると脱出リザルトへ進む。
- 壁の画像は村6枚・農場3枚・山道3枚の計12枚。収集記録は進行と別にローカル保存し、ゲーム再起動・再挑戦でも保持する。
- 農場の青いメダリオン7個を撃つとビール3杯を追加獲得（この体験版独自の報酬）。進行には必須でない。
- 新規開始、案内役・補給所での会話終了、ショットガン／鍵の取得、門の開放・区画到着・メダリオン破壊・強敵撃退で進行を自動保存する。Escから手動保存も可能。タイトルの「続きから」と死亡画面から最後のチェックポイントへ戻れる。体力・弾・ケース配置・撃退済みの敵・拾得物・会話報酬を復元する。区画を戻っても敵や拾得物は復活しない。ビール・在庫・所持品は全区画共通。旧村1区画セーブも読み込める。

## 構成と現在の範囲

村は5軒の家、屋内探索、階段、見張り塔、広場、農場側の出口。村の敵は8体で、開始時から全員を配置する。ハンドガン／ショットガン、弾薬、3色のハーブ、鍵、木箱・樽、ビール、収集画像を実装。壁は移動・射撃・拾得・敵経路で参照する。

農場は3軒の小屋＋二階建て納屋・囲い・井戸・たこさん、山道は曲がる通路・トンネル・廃屋・やめ太郎。各6体、計20体のそば屋。山道の1体は1.2倍の体格・HP350の最終戦。近距離では0.85秒の構えからジョッキの一撃、中距離では1.15秒の構えから方向固定の突進。横へ走る／Xで避け、突進後1.8秒（壁に衝突すると2.5秒）の隙を狙う。体力半分以下では1.25秒の構えから周囲2.6mへの叩きつけも使うので距離を取る。攻撃中も銃弾は効くが、毎弾ひるませ続けることはできない。画面左上に体力と予備動作の案内を表示。

福ちゃんは正典写真→Imagegen正面／背面→Tripo P2→Blender。そば屋は検証済みrig_v3。歩行・走行はMixamo由来、両手の銃構えは武器別のIKポーズ。建物・小道具はBlender生成。石壁と地面はbuilt-in Imagegenの専用テクスチャ。[設計と参照資料](GAME_DESIGN.md)、[福ちゃん正本](../04_GAME_ASSETS/3d/characters/fukuchan/README.md)、[村正本](../04_GAME_ASSETS/3d/environments/pueblo/README.md)。

福ちゃんは装填2種・被弾・回避・蹴りを含む10クリップ。構えに上下の照準と反動を加算。これらの追加動作はBlender制作。敵は視界／近距離／銃声で気づき、攻撃前に向きを固定する。同時被弾は短い無敵時間で抑える。[やめ太郎の正本](../04_GAME_ASSETS/3d/characters/yametaro/README.md)は会話・手振りで村入口に登場。

正面の掴み・抵抗・長押し脱出は追加済み（後述）。福ちゃん・やめ太郎は音声の強弱に合わせた口の同期を追加済み。音素別の口形と実時間の足IKは未実装。見張り塔は手付けの登攀モーションと連続した登降に対応。屋内では屋根を非表示にする。スマートフォン実機の操作・性能は未検証。

## 自動操作拡張（debugのみ）

接続と一括検査の手順は [MCP_DEBUGGING.md](MCP_DEBUGGING.md) を参照。

- `madogiwa.debugSession`: ネイティブPID、準備・前面状態、実行中の検査を返す。
- `madogiwa.runGameProbe`: `name=conversation`。周回をリセットし、実フレームと音声で2人の口の同期・停止再開を検査。終了時は会話を停止する。

- `madogiwa.inspectHazardGame`: 状態、コレクション、骨格クリップ、直近FrameTiming。
- `madogiwa.openGameScenario`: `name=combat|stagger|npc|merchant|pickup|collection|gate|stairs|death|farm|farmGate|mountain|mountainGate|introEvent|farmEvent|bossEvent|endingEvent`。その周回をリセットし、収集記録は保持。
- `madogiwa.gameAction`: `action=interact|reload|fire|fireAtEnemy|step|move|aim|pause|evade|kick|pose`。`step`は`seconds=0..10`、`move`はワールド方向`x,z`と`seconds`で60Hz移動。`pose`は`clip`と`seconds=0..3`で静止ポーズ。`openGameScenario`で解除する。通常プレイには影響しない検証用。

たこさんは[Blenderで直接制作した正本](../04_GAME_ASSETS/3d/characters/takosan/README.md)。腕2本・丸い手・触手6本に専用リグとIdle / Talk / Wave。生成APIの追加消費なし。

## 会話シーン・設定・敵の小道具

`game_events.dart`に4イベント・計15ショットを定義。台詞の実測尺に応じて表示時間を延長する。実モデルを同じFlutter Sceneで撮影するカメラ、字幕、既存のTalk / Idle / MugAttackを使用する。スキップも既読扱いで、農場へ戻るたびには再生しない。脱出後の3人の会話から、探索時間・命中率・撃退数・ビール・収集数・現在の難易度を表示するリザルトへ進む。福ちゃん・やめ太郎・そば屋は正典の声、たこさんはオリジナルの非言語反応音を再生する。

難易度は敵HPを変えず、被ダメージと接近速度を変える。「気軽に探索」は0.65倍／0.85倍、「標準」は1倍、「緊張感重視」は1.25倍／1.15倍。途中変更可能。画質は65%／85%／100%。

全敵の`PropSocket.R`へ既存のジョッキを`Grip`基準で装備。MugAttackで修正済みの手指姿勢をFlutter SceneのAnimationPlayerから一度サンプルし、持ち歩く間の8個の右指関節へ適用する。4m未満で最も近い1個はガラス・液体の詳細表現、それ以外は軽量材質。屈折の描画パスが群集で増えすぎないよう制限する。撃退時は敵と一緒に消え、拾得用ビール1個へ移行する。そば屋の歩行同期にはそば屋用の元速度1.007474632m/sを使用する。

実機ではE／Esc／スキップ、導入と脱出後の各人物、農場のたこさん、最終戦のそば屋とジョッキを確認。設定は実ドロップダウンとスライダーで変更し、hot restart後も保持した。[検証記録](qa/events-settings-20260906.json)。全体を通常操作で通す監査と最終profile測定は引き続き必要。

## 最終戦の検証（2026-09-06）

47テストと静的解析を通過。最終戦を単独にした山道の実機シミュレーションで、横走りによる突進回避と反撃の隙を確認。通常の弾数と入力経路を使った自動戦闘でも撃破できた。全区画の通しプレイの証明ではない。詳細は `qa/boss-combat-20260906.json`。検証用 `bossCombat` は停止状態から始まり、`gameAction simulate` の x/y入力・sprint・evadeで通常のゲーム時間を進め、結果を停止して確認する。`previewState` は停止中の戦闘姿勢をメニューなしで表示するだけで、保存を無効化する。通常へ戻すにはシナリオを再起動する。

## 通し進行の自動監査

```sh
dart run tool/audit_campaign.dart evidence/campaign-direct.json
dart run tool/audit_campaign.dart evidence/campaign-collection.json --complete
```

プロジェクト直下で実行。前者は補給と鍵・門から脱出まで、後者は全12枚・7メダリオン・20体・ビール回収と交換・両武器も検査する。通常の入力経路と60Hzゲーム時間を使い、位置や敵や体力をテスト都合で書き換えない。経路と正確な照準を知る自動操作であり、実画面の操作性や人間の初見時間を証明しない。詳細は `qa/campaign-audit-20260906.json`。

敵・ビール出現・木箱・門の音は距離（高低差を含む）と遮蔽物で小さくなる。自分の銃声・装填音・UI音は距離減衰しない。左右方向の定位は未実装。台詞音声と3区画の環境音・緊張時の音楽は追加済み。近／遠／壁越しの実機再生開始記録は `qa/audio-distance-20260906.json`。


## 描画付き通し監査・カメラ・接触影（2026-09-06）

壁際でカメラが壁の裏へ押し出される問題を修正。肩の横移動と後方のカメラ位置を半径12cmの余裕付きで遮蔽物に当て、極端に近い場合は自分のモデルで画面が塞がらないようにする。村と農場の二階床にも描画と一致する厚み16cmの遮蔽を追加し、弾とカメラが床を抜けないようにした。階段開口は通れる。上下視点を広げ、高所の青メダリオンも通常の画面中央の照準で狙える。

足元には頂点の透明度でぼかす接触影を追加。福ちゃん・敵8枠・NPC2枠を1つのInstancedMeshにまとめ、追加テクスチャや画面全体の後処理は使わない。影は簡易の楕円で、地形へ投影する汎用デカールではない。全体マップとミニマップは領域外の岩壁がUIへはみ出さないようにクリップする。

`madogiwa.auditCampaign` は `action=start|inspect|stop`、`complete=true` で全収集を含む。startは周回を最初から開始する。SceneViewの実フレームでゲームを進め、カメラ相対の移動入力と通常の `fire()` を使う。モーダル画面・イベント・背景化中は自動操作も待機する。照準と経路は既知の自動操作なので、人間の初見難易度や所要時間の検証とは区別する。

描画付き監査は全3区画→20体撃退→画像12枚→エンディング→リザルトまで到達。初回は回収中の追加戦闘で出たビールを自動操作が1個見落とし、全回収の最終条件で不合格となった。ゲーム内のドロップは存在した。手順を毎回再走査へ直し、シミュレーションでは20+3−4=19の台帳と全条件が通過した。修正後の実機再検証も全条件で成功し、各敵1個の回収と最終ビール19個が一致した（ゲーム内探索時間7分39秒、既知の経路と自動照準。再検証時のギャラリーは前周回分を保持）。[カメラ・通し監査記録](qa/camera-native-campaign-20260906.json)。54テストと静的解析を通過。

[M4での現行3区画profile計測](benchmarks/game-three-regions-20260906.json) は1280×840論理px／DPR 2、7条件・各240フレーム。UI P95 4.662〜5.154ms、Flutter Raster P95 0.462〜0.584ms。1回の短い測定であり、GPU実行時間、表示FPS、最も重い画角、長時間安定性、モバイル性能を保証しない。接触影の有無による差は小さく、この結果から速度差の因果関係は主張しない。ベンチマーク用の大きな体力値はチェックポイントに保存しない。


## 背景の素材と生活感（2026-09-06）

3区画の家に窓台・四分割の窓枠・雨戸・軒・ランタン、室内の食器・棚・戸棚を追加。木材・瓦・漆喰はbuilt-in Imagegenの専用素材へ更新した。遠景の円すい状の木は、透過素材を3枚交差させた1本6三角面の樹木へ置き換え、農場の外周と山道の崖上にも配置。alphaMode MASK／cutoff 0.45、空間ごとのメッシュで可視判定する。遠景用の表現で、プレイ領域の木や遮蔽物を板で代用する用途には使わない。

室内床を歩行面Y=0へ合わせ、足が22cm埋まっていた表示を修正。床付近の補給品を高さ0.28mへ下げ、既存の小さな浮遊表示を保つ。古いセーブも正本の補給品高さを使うが、拾得済み状態と敵／木箱のドロップ位置は維持する。55テスト・静的解析・修正後の全収集シミュレーションが成功。3区画の実画面でも材質、樹木の透過、室内の接地を確認した。

詳細と再現用の視点は [背景の検証記録](qa/environment-detail-20260906.json)。debug専用 `gameAction viewpoint` は `x,z,yaw` と任意 `y,pitch` で通常のゲームカメラを配置し、敵と保存を無効化して静止画を確認する。実機通しプレイの証拠とは区別する。正本素材と最終プロンプトは [共有テクスチャ](../04_GAME_ASSETS/3d/environments/pueblo/textures/) に保存。

## 停止画面の描画と再開（2026-09-06）

タイトル・一時停止・設定・持ち物・画像図鑑などの静止画面では、最初の描画を保持して連続更新を止める。会話・探索・戦闘では通常どおり動かす。`RepaintBoundary`でUIの描き直しを分離し、Flutterの`TickerMode`でSceneViewの既存タイマーを休止する。flutter_scene 0.23.0は`SingleTickerProviderStateMixin`でタイマーを作るため、`autoTick`を反復切り替えてタイマーを作り直す方法を使わない。

描画再開の最初の時間差を0へ戻し、停止中の経過時間が骨格へ一度に加算されるのを防ぐ。音声と環境音も次の描画を待たず停止させる。初回はwarm-up後に1フレーム描画してから静止させ、タイトル背景が空にならないようにする。検証拡張の`rendering`には前面状態、連続更新の有無、累積更新回数、ゲーム時間、骨格の再生時刻が含まれる。

実測値と再開の確認は[停止・再開の記録](qa/idle-rendering-20260906.json)を参照。停止中のプロセスCPU削減であり、プレイ中のGPU性能やFPS改善とは区別する。全体の完成確認は[体験版の完成確認](DEMO_READINESS.md)。
