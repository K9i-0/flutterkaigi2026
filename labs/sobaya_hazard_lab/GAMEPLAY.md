# そば屋ハザード — 村・農場・山道の体験版制作

福ちゃんで村→農場→山道を探索し、そば屋を撃退して脱出する3区画のゲーム。区画間の往復・補給・任意収集・途中保存を実装した制作中の体験版。PS2／原作バイオ4相当の仕上げ、初見15〜25分の尺、通常操作での通しプレイ監査は未完了。

## 起動

```sh
cd 21_SOBAYA_HAZARD_LAB
mise exec -- flutter pub get
mise exec -- flutter run -d macos -t lib/game_main.dart
```

Flutter 3.47.2 / Dart 3.13.2 / flutter_scene 0.23.0。global Flutterに合わせた既存mise設定を使用。従来のモデル検証室は `-t lib/main.dart` で起動する。

## 遊び方

- WASD／矢印で移動、Shiftで走る（歩行1.25m/s・走行2.8m/s）。ドラッグで視点を回す。
- 右マウスボタン長押し／Qで構える。左ボタン／Spaceで発砲、Rで装填。構え中は立ち止まる。
- Eで拾う・調べる・話す・木箱を壊す・はしごを使う。1／2で武器切替、Hでハーブ回復。
- Xで方向入力への回避（無入力なら後退）。頭を撃ってひるませたそば屋に近づき、Fで蹴る。回避は壁を通り抜けない。
- 村入口のやめ太郎にEで話しかける。Eで台詞を進め、ボタンで話題を選ぶ。各周回で弾10発を一度だけ受け取れる。Escで会話を終える。
- Tabで10×6のアタッシュケース。ドラッグで配置、クリックで装備・使用・ハーブ調合。
- Mで現在区画の全体マップ。門・出口・仲間・現在地を確認する。
- Cで収集した画像を鑑賞。クリックで拡大する。Escで一時停止・画質・音の切替。
- そば屋を倒すと流血せず消失し、ビールが1個出現する。ビールは、入口の家の西側にいるたこさんの補給所で使用する。弾10発=2杯、グリーンハーブ=3杯、ショットガン弾5発=3杯。在庫制で、ケースに入らない取引ではビールを消費しない。
- 二階建ての家にショットガン、北側の納屋に紋章の鍵。門を開けてその先へ進むと農場へ。農場の東の門は鍵不要。山道の廃屋前の強敵を撃退し、東の門を開けると脱出リザルトへ進む。
- 壁の画像は村6枚・農場3枚・山道3枚の計12枚。収集記録は進行と別にローカル保存し、ゲーム再起動・再挑戦でも保持する。
- 農場の青いメダリオン7個を撃つとビール3杯を追加獲得（この体験版独自の報酬）。進行には必須でない。
- 新規開始、案内役・補給所での会話終了、ショットガン／鍵の取得、門の開放・区画到着・メダリオン破壊・強敵撃退で進行を自動保存する。Escから手動保存も可能。タイトルの「続きから」と死亡画面から最後のチェックポイントへ戻れる。体力・弾・ケース配置・撃退済みの敵・拾得物・会話報酬を復元する。区画を戻っても敵や拾得物は復活しない。ビール・在庫・所持品は全区画共通。旧村1区画セーブも読み込める。

## 構成と現在の範囲

村は5軒の家、屋内探索、階段、見張り塔、広場、農場側の出口。村の敵は8体、開始4体で撃退に応じて追加される。ハンドガン／ショットガン、弾薬、3色のハーブ、鍵、木箱・樽、ビール、収集画像を実装。壁は移動・射撃・拾得・敵経路で参照する。

農場は3軒の小屋＋二階建て納屋・囲い・井戸・たこさん、山道は曲がる通路・トンネル・廃屋・やめ太郎。各6体、計20体のそば屋。山道の1体は1.2倍の体格・HP350・1.15秒の予備動作を持つ最終戦。通常の歩行や回避で避け、振り終わりの2.2秒を狙える。

福ちゃんは正典写真→Imagegen正面／背面→Tripo P2→Blender。そば屋は検証済みrig_v3。歩行・走行はMixamo由来、両手の銃構えは武器別のIKポーズ。建物・小道具はBlender生成。石壁と地面はbuilt-in Imagegenの専用テクスチャ。[設計と参照資料](GAME_DESIGN.md)、[福ちゃん正本](../04_GAME_ASSETS/3d/characters/fukuchan/README.md)、[村正本](../04_GAME_ASSETS/3d/environments/pueblo/README.md)。

福ちゃんは装填2種・被弾・回避・蹴りを含む10クリップ。構えに上下の照準と反動を加算。これらの追加動作はBlender制作。敵は視界／近距離／銃声で気づき、攻撃前に向きを固定する。同時被弾は短い無敵時間で抑える。[やめ太郎の正本](../04_GAME_ASSETS/3d/characters/yametaro/README.md)は会話・手振りで村入口に登場。

まだ実装していないもの: 窓越え・掴み・本格的な導入／章イベント／エンディング、難易度・感度設定、指の個別把持、実時間の足IK。見張り塔のはしごは位置遷移。屋内では屋根を非表示にする。スマートフォン実機の操作・性能は未検証。

## 自動操作拡張（debugのみ）

- `madogiwa.inspectHazardGame`: 状態、コレクション、骨格クリップ、直近FrameTiming。
- `madogiwa.openGameScenario`: `name=combat|stagger|npc|merchant|pickup|collection|gate|stairs|death|farm|farmGate|mountain|mountainGate`。その周回をリセットし、収集記録は保持。
- `madogiwa.gameAction`: `action=interact|reload|fire|fireAtEnemy|step|move|aim|pause|evade|kick|pose`。`step`は`seconds=0..10`、`move`はワールド方向`x,z`と`seconds`で60Hz移動。`pose`は`clip`と`seconds=0..3`で静止ポーズ。`openGameScenario`で解除する。通常プレイには影響しない検証用。

たこさんは[Blenderで直接制作した正本](../04_GAME_ASSETS/3d/characters/takosan/README.md)。腕2本・丸い手・触手6本に専用リグとIdle / Talk / Wave。生成APIの追加消費なし。
