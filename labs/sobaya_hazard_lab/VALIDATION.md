# 初回検証 — 2026-09-05

そば屋GLBをFlutter Scene上で表示し、移動・壁停止・12体配置まで確認した。検証用アプリとして使用可能。リグ／歩行アニメーション／敵AI／本編の戦闘・探索は未実装。

## 環境

- MacBook Air、Apple M4、32GB、macOS 26.6.2 (25G83)
- Flutter 3.47.2 / Dart 3.13.2 / flutter_scene 0.23.0
- Impeller MetalSDF。テクスチャ圧縮対応ログでbc / etc2 / astcを確認
- ウィンドウ内容1280×840論理px。3D領域924×691、DPR 2
- 原型21,068三角面／1材質／4K PBR／未リグ。モデル読み込み628ms（最終profile起動）

Dart MCPで起動、MarionetteでUI操作・状態検査・スクリーンショットを取得。profileはカスタムextensionを有効化せず、アプリ内自動計測とCUAで画面を確認した。初回のアセット探索漏れとインポート後の前方向を修正済み。Dart MCPからの停止で残った旧debugプロセスを終了して最終profileを採取した。自動前面化の警告はCUAのRaiseで解消し、最終画面はモデル観察に戻した。

## profile測定

カメラ位置を固定し、全ケースで原型を緩やかに移動・回転。設定変更後30フレームを除き、8〜8.5秒後の直近240フレームを採取した。値はP95、単位ms。

| ケース | UI / Dart | Raster |
| --- | ---: | ---: |
| 1体・影ON・100% | 2.435 | 1.857 |
| 4体・影ON・100% | 2.476 | 1.863 |
| 8体・影ON・100% | 2.369 | 1.690 |
| 12体・影ON・100% | 2.356 | 1.700 |
| 12体・影OFF・100% | 2.142 | 2.157 |
| 12体・影ON・50% | 2.429 | 2.206 |
| 12体・影ON・100%・AO ON | 2.868 | 2.340 |

通常の3D描画は1848×1382px、50%では924×691px。AOは有効時のみ半解像度で計算する。[設定・採取日時を含むJSON](validation/profile_macos_m4_20260905.json)を保存した。

この条件ではUI／Rasterは16.7msを下回るが、実fps・GPU実行時間・入力遅延を測ったものではない。影OFFや半解像度で明確な改善は確認できず、OSのスケジューリング等のばらつきもあるため最適化効果を断定しない。他のデスクトップ負荷・電源・温度は厳密に統制していない。
