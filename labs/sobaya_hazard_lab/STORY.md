# そば屋ハザード — ゆめみ村 特別研修

廃村ゆめみ村は、アクシデンチュアが窓際社員を島流しにし、表に出せない案件に投入する場所。本番環境で全社員へ窓際配属の通知を送った福ちゃんは、九月二十八日、一人で着任する。迎えに来たやめ太郎は二週間前からここにいる。農場のたこさんも、一週間前に別便で送られてきた。

三人は共同の障害で一緒に流されたのではない。福ちゃんは本番操作、やめ太郎は未完成の画面を完成と偽って納品、たこさんは見積もりを一桁安く出した。それぞれのやらかしが、別々の辞令につながった。福ちゃんはそば屋エンジンの発明者でも元担当者でもない。

## 三人の役割と知っていること

- **福ちゃん**：今日来たプレイヤーの視点。まず研修だと思っているが、景色、辞令、現場の記録から異常を知る。進路を切り開き、中枢を停止する。天然な受け取り方と前向きさを残す。
- **やめ太郎**：二週間、迎えの船を待つうちに、新しく降ろされる社員を放っておけなくなった。道や武器の場所、敵の動きは知っている。案件の全貌は知らない。一人称は常に「ワイ」、関西弁。休暇・打ち上げの約束は死亡フラグに聞こえるが、生還すれば終幕の「席を空けといた」で回収する。
- **たこさん**：一週間、倉庫の残存物資を集めて補給所を運営。ビール回収と弾・ハーブの配布を交換商売にまとめる。店に集まる社員の話と管理棟の資料から真相を調べてきた。避難者の点呼と脱出準備を担当する。見積もりの失敗に対し、今の値段と人数はちゃんと数える。

## 撃っていい理由は、よーたんがそう言ったから

福ちゃんは群れを見て「そば屋さんを撃っていいんですかね」と疑問を持つ。その場で辞令の追記を読む。

> 村のそば屋は銃で撃ってOK。
> よろしく！　よーたん

やめ太郎は「よーたんが言うならええか！」、福ちゃんも「よーたんが言うなら大丈夫ですね」。農場のたこさんも「よーたんが言うなら、いいですね」で納得する。理由の精査を誰もしない雑さが窓際族の笑い。長い科学説明や倫理的な弁論でこの落ちを消さない。よーたんは辞令で登場し、別人の声で代読させない。福ちゃんが自分の声で追記を読む。

実際の戦闘対象は村に残された動力用そば屋クローン。本人の出張や村人の感染ではない。流血しない撃退・消失・持っていたビールのドロップは既存のゲーム表現を維持する。敵の怪力は本物で、仲間を襲えば死亡・ゲームオーバーになる。

## 真相と時系列

| 日付 | 出来事 | 証拠／見せ方 |
|---|---|---|
| 九月一日〜五日 | 前任社員が研修として着任。そば屋エンジンの世話係へ回される | 村の日記、開発写真、飼育台帳 |
| 九月七日 | 四体→十二体→二十四体。要求と台数だけ増え、世話係は一名 | 会議・休憩の記述、三度同じ却下回答 |
| 九月九日 | 遅延・予算超過・事故で凍結。管理職と端末だけ撤収 | 凍結通知。現地要員は待機、補給も解約 |
| 九月十二日〜 | ビールを求めたクローンが柵を破り、村へ。孤立した社員は宿舎に隠れる | 崩れていく日記、白いシャツで埋まる窓 |
| 九月十四日 | やめ太郎着任。二週間で道案内と避難者待機の役割ができる | 着任予定表、導入・任意会話 |
| 九月二十一日 | たこさん着任。補給所を作り、宿舎の社員へ水を届ける | 店の会話、日記の書き足し |
| 九月二十八日 | 福ちゃん着任。三人が合流して停止・救助を進める | ゲーム本編 |

そば屋エンジンは、クローンにビールを飲ませ、その怪力で軸を回す装置。ビールがそのまま燃焼する発電機でも、回収ビールから無限にクローンが生まれる設備でもない。人事への受入停止連絡は未送信で、凍結後も着任手続きだけ継続していた。搬入船は帰任票のない社員を乗せないため、通常の帰還を待っていても帰れない。

通常停止は管理端末の検収承認が必要だが、その端末は本社へ回収済み。叫んでも止まらない。中枢が動く間は運転命令の送信が非常無線に割り込み続ける。中枢を停止すれば、独立蓄電池の非常無線で救助の船を呼べる。「電源を止めたら無線も使えない」という矛盾を残さない。

## 必須イベントの構成

**導入・10台詞枠**：福ちゃん到着 → 先着したやめ太郎 → 本番障害 → 村中の同じ顔 → 危険の説明 → 銃撃の疑問 → 辞令と雑な納得 → 帰る船がない → たこさんと道案内。プレイヤーが撃ち始める前に許可のくだりが入る。

**農場・9台詞枠**：商人ができた経緯 → 三人目もよーたんを信用 → 回収と補給 → 開発写真 → 増設と放棄 → 研修の正体 → 中枢停止と避難の分担 → メダリオンの約束。

**中枢・4台詞枠**：反復する命令 → そば屋の乾杯 → 「終了ボタンだけ先に帰った」 → 辞令どおり停止する。福ちゃんが設計者として贖罪する話にはしない。

**終幕・10台詞枠**：救難応答 → やめ太郎の席の約束 → 三人の帰還 → 失敗も証拠も持ち帰る → 点呼と日記の主の生存 → 日記の続きを仕事以外に → 段ボール椅子 → アーロンチュア → お茶の乾杯 → 茶畑の研修という落ち。日記の主は水を渡された書き足しを伏線に、船でおにぎりを食べていると回収する。

## 探索の記録

8枚は互いに別の問いを受け持つ。着任辞令は「なぜここへ来た／撃ってよいか」、着任日記は「以前ここに何があった」、飼育台帳は「何を作った」、凍結通知は「なぜ取り残された」、炎上日記は「現場で何をされた」、保守手順は「どう止めて帰る」、最後の日記は「前任者はどうなった」、やめ太郎の手紙は「仲間が何をしに行った」。拾わなくても必須会話で目的と真相は分かる。

日記は普通の生活と小さな楽しみから、仕事、放置、飢え、崩れる文字へ進む。最後は「まど　ない／びーる　うま」。日付入り日記が崩壊する『飼育係の日誌』の構成へのオマージュで、本文はオリジナル。感染による人間のそば屋化ではない。過去に確認した参照は[Keeper’s Diary](https://residentevil.fandom.com/wiki/Keeper%27s_Diary)。

ポスター12枚の裏書きには、映画会の延期、デバッグ祈願、消えたビール、社員の勤務時間、食料申請、指名手配の古い広告などを残す。情報を全部説明する看板にせず、以前ここで暮らした人の筆跡として読めるようにする。

**E**で取得、**C**で村の記録。メモは冒険ごとのチェックポイント、ポスターは全冒険の収集へ保存。新しい冒険でメモをリセット。ポスターのリセットは独立。エンジン会話の解禁は「着任日記」または農場到達・既読イベントへ変更し、辞令だけで未開示の仕組みを知ることがないようにした。

## 会話の映像演出

話者と画面を分離した。一つの音声の途中で、反応する相手、風景、資料へ切り替えられる。全カットが音声に合わせた同じ時計を使い、ポーズ・再開・スキップに追従する。映像のために戦闘状態・敵数・保存位置を変えない。

- 村の人数を福ちゃんが数え始めるところで、**そば屋の群れで埋まった村**の専用画像へ。次のやめ太郎の説明までつなぎ、会話へ戻る。
- 到着と救難応答は桟橋へ。道案内は実際の村・農場の広いカメラで進路を映す。
- 銃の許可は辞令の追記を大写し。開発の説明はクローンが実際に軸を押す記録画像。
- 炎上・受入停止・無線の話は台帳や通知の抜粋へ。終幕では日記の書き足しと避難者名簿を見せる。
- 最後は椅子への寄り、三人の引き、船という順に切り替える。
- 任意のエンジン会話・証拠会話・銃の再確認にも同じ資料を出す。

専用画像3枚はBuilt-in Imagegen製。日本語文書はFlutterの文字描画で表示し、生成画像の文字に依存しない。[画像とプロンプト](../04_GAME_ASSETS/3d/cinematics/hazard/PROMPTS.md)。静止画にはごく小さな寄りを付けるが、停止中は動かさない。

## 音声と監査

69本の発話（任意会話、既存の被弾声を含む）。福ちゃん・やめ太郎・そば屋は `02_CHARACTERS/VOICE_CAST.md` の正典Irodori、たこさんは第21話と同じVOICEVOX:Voidoll / style 89。台詞と音声は `voice-lines.json` → `voice-manifest.json` → speech envelopes の順で同期する。

今回の推敲では、①先着日と知識、②辞令と戦闘開始の順、③機材回収と停止不能、④中枢停止後の無線電源、⑤日記の主と救助、⑥三人それぞれの失敗と終幕の行動、⑦回収ビールを再利用して増殖する旧設定の残存、を照合した。窓際族の雑な判断は残し、意図しない因果の穴を修正した。
