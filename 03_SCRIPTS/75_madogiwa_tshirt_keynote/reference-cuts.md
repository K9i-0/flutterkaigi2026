# 福ちゃん・やめ太郎：Large参照音声カット比較

## 結果

今回の末尾カットだけでは、短文の崩れが解消したとは言えない。福ちゃんは別の完結文でも短文が崩れた。やめ太郎は別参照の「腕です」seed7だけ本文どおりのASRになったが、seed42では崩れた。

ASRによる補助検査であり、実際の試聴・声質・異音の有無は未確認。すべて試聴候補で、正典参照と既定モデルは変更していない。

## 条件

- A: 正典参照全長。福ちゃん9秒、やめ太郎7秒。
- B: 元音源のPCMをそのまま切り出し。福ちゃん0–5.16秒、やめ太郎0–6.25秒。音量調整やノイズ除去は行わない。
- C: 福ちゃんは会社紹介0–4.84秒、やめ太郎は自己紹介0–6.02秒。発話本文・元の収録区間も変わるため、「文の完結性だけ」の効果とは分離できない。
- やめ太郎Bは「渡り歩いて」と続く会話で、カットだけでは完結文にならない。
- 切り出し位置は時刻付きASRと音量の谷を参考に選択。耳での境界確認は未実施。
- Large、FP32/MPS、発表会caption、本文CFG3、尺倍率1、同じ末尾・無音トリム。福ちゃんseed100、やめ太郎seed7。「腕です」は両者ともseed42を追加。
- やめ太郎の通常会話用のcaptionなし・CFG5・尺倍率0.70は混ぜず、参照だけを変える。

## 試聴順

各台詞ごとに A現在 → Bカット → C別参照。台詞順は「腕です」「完璧です」「今日という日を、私はずっと待っていました」「腕です（seed42）」。1秒の間、台詞セット間は2秒の間。通しWAVに同一のラウドネス処理を適用。
