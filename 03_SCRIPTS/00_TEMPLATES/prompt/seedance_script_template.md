## 厳守方針と優先順位

1. 必須セリフと音声。
2. CUT番号、秒単位の時間構成、物語の因果関係。
3. 用途別参照画像。外見はキャラクターシート、動作は絵コンテ、地理は環境シート、重要小道具・ロゴの意匠と全文は本番用重要アセットを正本とする。
4. 画質、演出、装飾的VFX。
