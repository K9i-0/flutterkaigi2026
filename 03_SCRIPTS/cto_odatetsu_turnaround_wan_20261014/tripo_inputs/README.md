# CTOおだてつ Tripo用4方向入力

flutterkaigi2026専用。mainへマージしない。

| ファイル | 由来 | 方向 |
|---|---|---|
| front.png | Wan動画 0.5秒の無加工抽出 | 正面 |
| profile_facing_right.png | Wan動画 3.5秒の無加工抽出 | 画面右向き側面 |
| back.png | Wan動画 6.5秒の無加工抽出 | 背面 |
| profile_facing_left.png | 上記3枚を参照した内蔵Imagegen | 画面左向き側面（推定補完） |

左右の名称は画面内の顔の向き。Tripo APIのleft/rightスロットへ投入する際はそのAPIの定義と照合する。
動画は一周せず約半周だった。ユーザーの「左右の側面は大きな違いがない」という指定を基に不足側面を補完。Wanの追加課金・再生成は行っていない。

## 検証と制限
- 4枚を目視し、人物同一性、全身、下ろしたフード、服の丈、髪の大まかな輪郭を確認。
- 元動画3枚は1080×1920。補完画像はImagegen出力の原寸を保持。個別のトリミング・引き伸ばしは行わず、全身の相対占有率を揃えるよう生成。
- 厳密な校正投影ではない。腕、手指、皺、髪の房に差がある。Tripo生成後に形状を監査する。
- 靴のAに重線・余分な形状がある。文字参照と独自のAを基準に3Dテクスチャを仕上げる。胸文字も最終モデルで再確認する。
- 左向き側面は映像の実フレームではなく生成補完である。元動画が360度に成功したことを示す資料としては扱わない。
- Tripoへの送信は未実施。
