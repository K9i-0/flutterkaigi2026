## 完成版

`final_remotion_prison_break_v2.mp4`：854×480、30fps、映像33秒・990フレーム、H.264/AAC。生成本編30秒＋Remotion商品カード3秒。

冒頭は76話 `final_remotion_revision04.mp4` の10.000–11.150秒から抽出した `line_beer_ep76.wav` を0.600秒に配置。元の不明瞭な発話は0.300–1.967秒の置換で除去。採用音声のPCMは抽出元と一致し、声質・速度・音程・音量は無加工。後半の飲酒シーンは台詞を追加していない。

英語の生成音声へ日本語字幕を同期。「roadhouse」は「居酒屋」と訳し、動機は不明のまま。実際の字幕時刻は `remotion/src/edit-manifest.json` が正本。

生成入力はキャラクター画像・商品画像の2枚。参照音声はWanへ送信されていない。採用した76話の実音声はRemotionで後付け。未採用のIrodori候補音声は使用していない。生成映像のTシャツ公開は約25秒から。

検証：TypeScript型検査、全編デコード、990フレーム、字幕・商品カードの静止画確認、採用WAVのPCM一致、冒頭ASR「ビール」。ASRは補助確認であり実聴ではない。履歴は `production-history_v2.md`、音声処理は `audio-edit.json`、完成記録は `production-result_v2.json`。

## v3 完成編集（現行版）

出力：`final_remotion_prison_break_v3.mp4`、composition `MadogiwaPrisonBreakV3`。本編30秒＋商品カード3秒、854×480/30fps。

0–11秒はv2を維持。11–25秒は新しい12秒追跡素材を使用し、爆発映像のみスローにして14秒へ編集。終端の煙がさらに薄くなる部分を除外。音声は爆発音の区間だけ伸ばし、英語台詞は元の速度を維持。25–30秒は旧素材25–30秒の完成したTシャツ姿から開始し、囚人服が消える過程を省略。30–33秒は既存商品カード。冒頭11秒のPCMと76話「ビール」は前版と一致。

追跡素材の黒帯をcrop=854:394:0:42で除去し、アスペクト比を保って中央クロップ。人物・字幕・機体の重要箇所を静止画確認。機種形状のずれは生成素材由来で残る。爆煙はバイクを隠すが画面全体が完全不透明になるわけではない。生成済み素材を使う今回のユーザー指示に従って編集。

編集再現：`python3 prepare_edit_v3.py` → `cd remotion && npm run render`。旧編集音声がない場合はv2 manifestを使う`finish_audio.py`で先に作成する。実聴は未実施。
