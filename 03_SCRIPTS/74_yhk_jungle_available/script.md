# YHKドキュメンタリー『密林のアベイラブル』

## 現行方針

2026-09-23改稿。30秒のWan一括生成案を廃止し、73と同じ既存GLB＋Three.js＋Remotion方式へ変更。旧案は `archive/wan_30s/` に保存。本作の尺は演技と台詞に従う。導入込みで約3分半を目安とし、以下の時間は編集の目安であり固定の発話制限ではない。480p・16:9を維持。

背景はImagegenで制作した密林画像を大きな壁面に貼る。人物、地面、窓枠、祭壇、献上ビールは3D。背景壁の前で正典モデルを動かし、光、構図、編集で本格的な観察ドキュメンタリーにする。

## 核

孤島の密林に、建物のないアルミサッシが一枚ある。マドギワ族はそこを聖地とし、「アベイラブル」と唱えながら何かを待っている。ビールを携えた取材班が、その信仰を少しずつ知っていく。彼らの正体は、島流しにされた元アクシデンチュア社員だった。

島流しを「長期オンサイト」と呼び、本社から返ってこないアサインを待つ。笑いの中心は、窓を神として信じる生活の中に、以前の会社の言葉だけが残っていること。人物自身は真面目で、取材側も嘲笑しない。結末はツッコミで切らず、明日も続く祈りを見送る。

## 配役・演出

- そば屋：族長。正典の白い仮面、グレー肌、筋肉質の体格。仮面は最後まで外れず、表情は首、姿勢、手、声で表す。
- 福ちゃん：窓を拭く族人。正典の3Dモデルを維持。窓を丁寧に拭く手付きから、信仰が生活になっていることを見せる。
- やめ太郎：YHK取材班。73のGLBを継承。聞き手として抑制し、滑稽さを指摘するツッコミ役にしない。
- 語り：取材役のやめ太郎本人。正典の声で、落ち着いたドキュメンタリーの語りを担当。発見、取材成立、正体の確認を補い、会話を言い換えて説明し続けない。
- 現場台詞と語りは正典Irodori音声。そば屋は専用後処理を適用。環境音はFelix BlumeのCC0実録を使用し、新しい非メンバー音声や環境音をローカル合成しない。旧セット確認映像だけは無音。

## 完成脚本

### 序章．密林の奥へ — 目安 0:00–0:25

人物も窓も映さず、風景の静止画とナレーションで舞台と取材の目的を伝える。3枚程度の画像をゆっくり寄せる。地名・人口・調査年など未設定の数字を足さない。

| 目安 | 画像・編集 | 語り |
| --- | --- | --- |
| 0:00–0:09 | 霧に覆われた孤島の密林。冒頭2秒は鳥と葉擦れだけ。ゆっくり寄る。 | 「深いジャングルの奥地に、ひっそりと暮らす少数民族、マドギワ族。」 |
| 0:09–0:17 | 光の届きにくい獣道。低い目線で奥へ進むような緩いパン。人物の姿はまだ見せない。 | 「彼らは、ある身近なものを、神として崇めているという。」 |
| 0:17–0:25 | 葉に遮られた森の奥。小さく「YHK取材班」。最後に葉の隙間から銀色の直線だけが見える。 | 「今回、私たちYHKの取材班は、彼らとの初めての接触に成功した。」 |

「初めての接触」は今回のYHK取材班にとって初めてという意味。人類初・世界初・外界との交流皆無とは言わない。取材後にまとめた語りとして接触成功を予告し、この後にその経緯を見せる。ビールや元社員の正体はここでは明かさない。

序章画像の制作仕様：Imagegenで①霧の密林の遠景、②森の獣道、③葉越しの密林を用意し、Remotionで約1.00→1.04倍の緩い寄りや小さなパンを付ける。全カットに人物・文字・窓を描き込まない。最後の銀色の直線だけ3Dセット側の窓枠へ接続する。序章専用の3画像と語りを制作済み。`backgrounds/intro_*.png` と `line_n01`〜`line_n03` を使用。

### 1．密林の窓 — 目安 0:25–0:35

葉越しの銀色の直線から、初めて3Dセットへ。カメラが開けた場所を捉えると、壁のないアルミサッシと、その前で祈るそば屋・福ちゃんが見える。

二人「アベイラブル……アベイラブル……」

ここでは語りを重ねず、視聴者に「窓だったのか」と気づく時間を渡す。窓の向こうにも、同じ密林が続いている。

明朝体の題字『密林のアベイラブル』。副題「窓に祈る マドギワ族」。右上に小さなYHK。題字のために別の長いタイトル画面を挟まず、祈りの画に重ねる。

### 2．取材の条件 — 目安 0:35–1:00

やめ太郎が一歩近づく。そば屋が手のひらを小さく上げ、止める。カメラも止まる。二人の間に沈黙。

やめ太郎「お話、聞かせてもらえますか。」

そば屋は答えず、取材班の荷物へ視線を落とす。やめ太郎が缶ビールを一本、両手で差し出す。

そば屋「まず、こちらの期待値を合わせたい。」

一拍。缶を見る。

そば屋「何本あります？」

やめ太郎が箱を足元に置く。そば屋は中を確かめ、少し肩の力を抜く。横の腰掛けを手で示す。笑顔の大げさなリアクションはしない。

語り「ビール一箱を献上し、ようやく、取材を許された。」

人物紹介「マドギワ族 族長／そば屋」。まだ会社名も元社員も出さない。

### 3．窓のある場所 — 目安 1:00–1:25

福ちゃんが古い布でサッシを磨いている。傷のある窓枠だけが、妙に清潔だ。そば屋とやめ太郎の会話へ。

やめ太郎「建物がないのに、窓だけあるんですね。」

そば屋「建物は、必要ありません。窓があれば、ここが窓際です。」

やめ太郎は一度窓を見て、言葉を選ぶ。

やめ太郎「向こうには、何があるんですか。」

そば屋「可能性です。」

窓越しの密林を5秒見せる。何も起こらない。説明ナレーションやオチの効果音を入れない。

### 4．アベイラブル — 目安 1:25–1:50

福ちゃんが磨く手を止め、窓へ向き直る。そば屋も立ち、両手を合わせる。やめ太郎は少し後ろに下がる。

二人「アベイラブル……アベイラブル……」

祈りが終わっても、3秒ほど静止。やめ太郎が小声で尋ねる。

やめ太郎「どういう意味の言葉なんですか。」

そば屋「いつでも、お受けできます、という意味です。」

やめ太郎「何を、お受けするんですか。」

そば屋「アサインです。」

祈りの意味はそば屋の答えで伝わるため、ここに説明を繰り返すナレーションは入れない。

ここでは用語辞典のような説明テロップを置かない。祈りと口調の落差で伝える。

### 5．返事のない窓 — 目安 1:50–2:15

窓の鍵、そば屋の手、待つ二人。取材の時間が流れていることを見せる。

やめ太郎「返事は、来るんですか。」

そば屋「今のところ、確認できていません。」

やめ太郎「どのくらい、待ってるんですか。」

そば屋は窓を見る。答える前に、息をつく程度の間。

そば屋「三年ほど、アベイラブルでして。」

カメラはすぐに切り替えない。福ちゃんはまた、同じ窓を拭き始める。

### 6．社員証 — 目安 2:15–2:40

拭くために身体をかがめた福ちゃんの胸で、古い社員証が揺れる。ここで初めて、会社名が読み取れる。

社員証のインサートは正確な文字を別の3D小道具として作る。「ACCIDENCHUA」。既存の身体テクスチャは書き換えない。

社員証を読める長さで保持。カメラが二人へ戻る。

語り「彼らは、島流しにされた、元アクシデンチュア社員だった。」

薄い資料テロップ「元アクシデンチュア社員」。

そば屋「長期オンサイトです。」

やめ太郎「ああ、それは失礼しました。」

そば屋は訂正が済んだので静かにうなずく。カメラもそれ以上追及しない。

### 7．ネクストアクション — 目安 2:40–3:05

取材の終わり。やめ太郎が帳面を閉じる。ビール箱は祭壇の横へ置かれている。

やめ太郎「これから、どうするんですか。」

そば屋「ネクストアクションは、引き続き待機です。」

やめ太郎「帰りたいとは、思わない？」

そば屋は窓を眺める。今度は返答を急がない。

そば屋「呼ばれたら、いつでも。」

さっきまでのコンサル口調より、少しだけ柔らかい声。福ちゃんがきれいになった窓を見上げる。

### 8．明日も、窓際で — 目安 3:05–3:30

光が少し落ち、夕方の密林。二人は再び窓へ向かう。取材班は画面から離れ、カメラだけが遠くに残る。

語り「今日も、窓の向こうから返事はなかった。」

3秒の間。二人は待っている。

語り「それでも、明日の朝、彼らはここに立つ。」

遠くから「アベイラブル……」。銀色の窓と、小さく見える二人を6〜8秒保持。ゆっくり暗転。

「制作・著作　YHK」。最後までギャグの効果音や大きなツッコミ字幕を入れない。

## 撮影・セット設計

1. Imagegen背景：`backgrounds/jungle_wall_day_v1.png`。密林のみ。人物や窓は描き込まず、3Dの自由度を維持する。採用画像は組み込み前に目視確認済み。
2. 3Dセット：大きな背景壁＋接地用床。壁の端は全ショットで画角外。幹・石・低い前景の葉で床との境界を隠す。背景の地平と3D床の接続を確認する。
3. 独立したアルミサッシ：枠、レール、支持杭、薄いガラスを実メッシュで作る。人物の手や顔を窓越しに見せられる。
4. モデル：73と同じそば屋v3／やめ太郎nose-v3、正典福ちゃん。手や肩の動きは既存クリップを基礎に、小さな首振り・呼吸・手の動きを付ける。GLB本体・顔・ウェイトは改変しない。
5. カメラ：基本は固定。緩い寄りと短い横移動に限定し、平面背景の横視差不足を露呈する周回を避ける。芝居は秒ごとのカットではなく5〜12秒の観察単位。
6. 小道具：ビール箱、缶、布、腰掛け、社員証。献上の成立を箱の設置と族長の招く手で明確にする。
7. 日中〜夕暮れ：同じ地形を保つ。照明・色調を穏やかに変え、必要なら同一背景の夕暮れ版をImagegenで制作する。
8. 480p文字：明朝題字、25px前後の会話字幕、控えめな人物紹介。ナレーション全字幕化や常設解説帯は避ける。

## 本編制作記録（2026-09-23）

- Composition：`YhkDocumentary`。854×480、24fps、5145フレーム、214.375秒（約3分34秒）。
- 冒頭25秒はImagegenによる島・獣道・葉越しの3枚。人物と窓は25秒以降に初登場。カメラ・字幕はRemotionで再現。
- 31音声。そば屋は `Sobaya_voice.wav` / seed 42 / monsterize。取材・語りは `Yametaro_voice.wav` / seed 7。モデルは `Aratako/Irodori-TTS-v4.1-Small`、尺の固定や速度変更なし。全caption、SHA-256、実測長は `audio-generation.json`。
- 音声の極短文で余計な発話が出たため、「何を、お受けするんですか」「ああ、それは失礼しました」へ自然な短文として改稿。末尾の余計な発話は `audio-tail-edits.json` の区間で除去。台詞を壊す時間圧縮はしない。
- 冒頭の「ああ」など弱い間投詞、固有名詞の漢字、語尾についてASRは誤認識があり得る。自動照合は発音や声質の聴感合格ではない。
- `edit-manifest.json` がタイミング正本。字幕と口の開きは採用WAVの開始フレーム・音量包絡に従う。やめ太郎は既存SpeechOpenモーフによる簡易口パク。そば屋の仮面は固定し、口を変形させない。
- そば屋の祈り、取材を止める手、迎える手、視線、頷き。福ちゃんの窓拭きと布、身体へ追従する社員証。やめ太郎の缶を差し出す手。正典GLBの顔・頂点・ウェイトは変更しない。
- 窓は立体の枠と薄いガラス。森はImagegen画像を貼った壁。床は専用Imagegen画像。植物メッシュで接続部を補い、寄り・引き・小道具インサートで撮影。
- 環境音はCC0の既存実録素材。出典・ライセンスは `audio_sources/README.md`、ハッシュは `asset-provenance-3d.json`。セリフ中は低く、沈黙中は少し上げる。
- 中間動画：`remotion/out/documentary-master.mp4`。最終出力：`final_remotion_documentary.mp4`。音声のみ -16 LUFS / true peak -1.5 dBTPの設定で整音、映像は再圧縮せずコピー。
- 未使用の旧Wan設定は送信していない。生成動画APIの従量課金なし。GitHub公開pushは前回の承認待ちを維持し、今回の制作依頼を公開承認に読み替えない。
