# 密林のアベイラブル

制作・著作：YHK。架空民族マドギワ族の30秒ドキュメンタリー。

## 制作仕様

- 480P、16:9、30秒、一つのWan 3.0タスク。編集暫定854×480 / 30fps / 900frames。生成後に実寸・fpsへ合わせる。
- 本物の孤島の密林。建物も壁もない場所にアルミサッシを運び込み、窓を信仰する。
- 正体は島流しにされた元アクシデンチュア社員。会社名は終盤の編集テロップで初めて明かす。
- そば屋以外は匿名の成人元社員３人。そば屋は正典の白い仮面・グレー肌・筋肉質の体格を維持。
- 上質な公共放送の観察ドキュメンタリー。自然光、湿度、微細な手持ち、静かな取材。ナレーターも人物も真剣。
- 音は全編Wan生成。低めの落ち着いた男性ナレーター、別の声の記者、正典参照によるそば屋。虫・鳥・葉擦れ。BGMなし。
- そば屋の仮面は硬いまま常時装着、記者は画面外、群衆は背面。可視口元の同期対象がないため `audio_sync_strategy=no_visible_speech`。音声はWan埋め込みを保持。
- `postproduction=remotion`、`visual_preset=yhk_observational_documentary_v1`。ユーザーのYHKドキュメンタリー指定に従う。

## 採用台本（秒は目安）

| 区間 | 映像 | 発話 |
| --- | --- | --- |
| 0–6秒 | 密林の窓を囲んで祈る。番組タイトル | 一同「アベイラブル……アベイラブル……」。語り「密林に暮らす、マドギワ族。彼らは窓に祈りを捧げる。」 |
| 6–13秒 | 族長へビールを献上 | 記者「お話を伺えますか？」。そば屋「まず、こちらの期待値を合わせたい。何本あります？」 |
| 13–21秒 | 一箱のビール。族長がうなずき席を勧め、取材成立 | 記者「何を祈っているんですか？」。そば屋「アサインです。三年ほど、アベイラブルでして。」 |
| 21–30秒 | 古びた社員証の寄り、族長の胸上へ戻る | 語り「彼らの正体は、島流しにされた元社員だった。」。そば屋「長期オンサイトです。」 |
