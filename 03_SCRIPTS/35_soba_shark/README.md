# そばシャーク

Seedance 2.5向け15秒Z級サメ映画予告の制作ラン。

「そば」は麺そのものではなく、赤坂の路地にある小さなそば屋（店舗）を指す。

白い仮面のそば屋本人がしょぼいサメ着ぐるみを着た「そばシャーク」となり、
空ジョッキを持ったまま満杯ビールをエサにした竹かご罠へ誘い込まれて捕まる。

## 映画ポスター

- 本番画像：`poster_soba_shark_2_production.png`
- 位置づけ：バカ映画なのに続編まで作られた「そばシャーク2」
- コピー：「ビールを求め奴が帰ってくる」
- タイトル：「そばシャーク2」。「2」だけ赤で大きく強調
- 公開表記：「近日公開」
- 画角：縦2:3（1024×1536）
- SNS安全域：タイトルロゴ一式を下端から離した中央寄りの下段に置き、中央4:5クロップでも欠けない構図

## ロゴ

- 正本：`logo_soba_shark_master.png`
- 構成：白い正面サメ頭部アイコン＋白い「そばシャーク」の文字のみ
- アイコン：大きく開いた黒い口の中央に、白いそば屋の仮面
- 背景：無地の黒
- 禁止：追加文字、赤色、提灯、暖簾、質感、影、グラデーション

## 続編ロゴ
