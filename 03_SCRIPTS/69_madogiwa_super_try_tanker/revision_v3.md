# 第69話 v3 — チェイス延長・飲みで終わる版

ユーザーの追加修正：最後のセリフをなくし、飲んでいるところで生成終了。その分カーチェイスを増やす。

- 0–2.7秒：爆走接近、「ビール！」。
- 2.7–5.5秒：車輪すれすれの追走、ローリーの回避、バイク軍団の追撃。
- 5.5–8秒：全身が見える空中ジャンプ、手すりへ飛びつく。
- 8–10秒：支持して一撃、派手な噴流、全車停止。
- 10–12秒：肩から手が連続して見える画角で注ぐ。
- 12–15秒：豪快に飲み続ける。ジョッキを下ろさず、飲んでいる途中で本編終了。最後のセリフ・乾杯ポーズなし。

走行方向固定、徒歩人物なし、余分な腕なしを継承。主役は飛びついた後ずっと車体ステップ、軍団はバイク上。15秒・480P＋既存商品コール5秒。画像・声・seedは継承。v2は送信後の追加修正のため結果を保存し、今回の採用候補はv3。
