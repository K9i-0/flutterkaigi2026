# よーたん対そば屋 — Seedance 2.5生成動画監査

## 対象

- 動画：`yotan_vs_sobaya_seedance25_30s.mp4`
- 実測：30.042秒、854×480、24fps、H.264、AAC stereo 32kHz
- シーン切り替え候補：3.000秒の1件
- 監査画像：`yotan_vs_sobaya_seedance25_30s_audit/full_1fps.png`、`action_0_15_2fps.png`、`action_15_30_2fps.png`

## 結論

不合格。キャラクター同一性と大まかな左右は保たれたが、矢印付きクレイ絵コンテの視覚情報が完成映像へ強く転写され、実写バトルではなく「高精細なクレイ絵コンテを動かした映像」になった。Seedance 2.5へ高品質な材質、照明、VFX、編集リズムを生成させる自由領域が不足している。

原因は主にプロンプトの文章量ではなく、入力画像の役割設計にある。矢印付きクレイ絵コンテ8枚とブロッキング1枚を厳守画像として同時入力したため、「映像へコピーしない」という否定文より、画像内の人物造形、室内材質、赤い図解VFX、青いカメラ経路が強い正例として解釈された。

## ユーザーFBとの照合

### クレイが詳細すぎる

FBどおり。絵コンテには髪型、サングラス、仮面、筋肉、衣服、ギター、ジョッキ、スピーカー、床亀裂、室内照明まで具体的に描かれている。モデルはキャラクターシートで肉付けするのではなく、この完成度の高いクレイ画をベース映像として採用した。

動画では、人物の外見はキャラクターシートへ近づいた一方、室内、照明、身体の硬さ、ポーズ間の補間はクレイ絵コンテのままである。特に14〜18秒付近の跳躍は、実写スタントの爆発的な加速ではなく、クレイ人形がポーズ間を浮遊する動きに見える。

### 衝撃エフェクトが安っぽい

FBどおり。図解として描いた赤いバーストと同心円が、そのまま完成VFXとして転写されている。

- 約7秒：ギターボディ接触点に赤い星形バースト
- 約12〜13秒：床衝撃に赤い同心円
- 約17秒：空中接触に赤い図解バースト
- 約19〜21秒：ギター付近から赤い同心円
- 約25秒：最終接触に赤い星形バースト

本来の物理表現である床粉塵、床材のたわみ、スピーカーコーンの振幅、衣服の圧力反応、空気屈折、露出変化、カメラの微小反動より、赤い線画の説明記号が優先された。

### Seedance 2.5の性能を使えていない

同意。次の設計が生成能力を抑制した。

1. 8枚のCUT絵コンテとブロッキングをすべて厳守画像にした。
2. 絵コンテに人物、衣装、髪、背景、VFX、カメラ矢印まで描いた。
3. 30秒一括で8つのアクションビートを要求した。
4. 実写仕上げより、位置・接触・状態の厳守を高い優先順位にした。
5. 出力を480pに固定した。

結果としてモデルは、新しい映画的映像を構築するより、入力画像を安全に動画化する方向へ寄った。

## 次回の入力設計

### 1. 絵コンテを二層化する

**制作確認用・Seedanceへアップロードしない**

- 矢印付きブロッキング
- START / CONTACT / END
- 左右、接触点、カメラ側、累積状態

**Seedanceへアップロードする**

- キャラクターシート2枚
- 必要なら実写仕上げの環境・開始・終了キーフレーム
- 矢印、クレイ人形、赤い図解VFXを一切含まない

矢印付き絵コンテは人間とプロンプト作成者の正本として残すが、動画モデルへの標準入力から外す。

### 2. 内部用クレイをさらに抽象化する

クレイ絵コンテは髪、顔、仮面の模様、衣服、靴、指、ギター表面、ジョッキ材質を描かない。頭＝球、胴体＝箱、手足＝円柱、武器＝単純ブロックまで落とす。人物識別は体格差と単色だけにする。

ただし、この超抽象クレイも原則としてSeedanceへアップロードしない。

### 3. 30秒一括を3クリップへ分ける

- Clip A：対峙→ジョッキ横薙ぎ→ギターボディ反撃
- Clip B：床振動→空中打撃→スピーカー音圧
- Clip C：音圧突破→武器衝突→左右分離

各クリップは1つの攻防シークエンスへ集中させ、CapCutで接続する。これによりCUT-08の省略と、ポーズ間の長いモーフィングを防ぐ。

### 4. VFXを物理現象で指定する

- 打撃：接触部位の短い変形、微細な破片、露出の瞬間変化、短いカメラ反動
- 床振動：床材のたわみ、接触点から走る微細亀裂、粉塵の波、固定物の共振
- 音圧：4基のスピーカーコーンの振幅、空気屈折、衣服と髪の圧力反応、床粉塵の移動

赤い星、同心円、可視ビーム、漫画線、グラフィックリングを禁止する。

### 5. 画質の自由度を上げる

実写材質、照明、レンズ、空気感を拘束する入力画像は、クレイではなく本番ルックの環境またはキーフレームにする。利用可能なら480pより高い生成解像度を選ぶ。ただし、今回の根本原因は解像度より入力画像の過拘束である。

## 次回に引き継がないもの

- 今回の生成動画
- 矢印付きクレイ絵コンテをSeedance入力として使う設定
- 赤いバースト・同心円を含むVFX表現
- 30秒一括の8ビート構成

キャラクターシート、左右関係、ジョッキと強化ギターの基本設計、床接触とスピーカー発生源という因果だけを引き継ぐ。
