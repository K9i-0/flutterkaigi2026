# imagegen 最終プロンプトセット

組み込み imagegen で生成した正本画像の再生成用プロンプト要約。各CUTの正確な位置、時刻、State OUTは `storyboard_cuts.yaml` を優先する。

## 共通プロンプト

```text
Use case: illustration-story
Asset type: Seedance用アクションクレイ絵コンテ、16:9
Input images:
- character_yotan_battle_guitar_sheet.png = よーたん本人と強化ギターのidentity/equipment source
- character_sobaya_basic_sheet.png = そば屋本人、白い仮面、大型ビールジョッキのidentity source
- blocking_battle_arena_sheet.png = 左右、4基の固定スピーカー、客席側カメラ、床損傷のcontinuity source
Style/medium: Blenderアニメーションプレビズ用クレイレンダー。滑らかな無地マット材質、単純な人形と基本形状、柔らかなスタジオ光
Composition: よーたんは画面左で右向き、そば屋は画面右で左向き。カメラは客席側のアクション軸を越えない
Motion overlays:
- シアン実線 = 人物の腰・胸を基準にした重心移動
- オレンジ弧 = ジョッキまたはギターボディの攻撃軌道
- 赤バースト／同心円 = 接触、床振動、スピーカー音圧の発生源
- 青破線＋灰色カメラ代理 = カメラ移動。フレーム外周だけ
1コマは原則2本、最大3本。矢印は身体、武器、接触点を隠さない
Avoid: 写実的顔、髪や衣装の細部、完成コンセプトアート、文字、数字、ラベル、キャプション、UI、透かし、左右交換、武器の複製・消失
```

## 強化ギター装備シート

```text
Referenceのよーたん本人の顔、金髪、サングラス、細身体形、黒レザーのロック服を完全に維持する。通常演奏できる黒いシングルカット型エレキギターのネック内部とボディ外周を耐衝撃素材で補強する。薄いブラッシュドガンメタル保護帯と黒鋼インパクトプレート。左に全身、中央にFRONT / SIDE / BACK、右にギター正面・背面・側面、ネックを両手で持ってボディを打撃に使う構え、通常演奏姿勢。刃、棘、銃、斧、別武器、壊れたギターを描かない。
```

## ブロッキングシート

```text
同じライブ兼立ち飲みフロアの俯瞰4コマ。各コマで上左、上右、中左、中右の同じ座標に黒いスピーカーを正確に4基置く。よーたんは常に左、そば屋は常に右。無傷→靴跡と放射亀裂→4基のスピーカー音圧とそば屋の右滑走→中央接触と左右分離、の累積状態。下端外周に客席側カメラの青破線。文字・凡例なし。
```

## CUT差分

| CUT | 画像へ描く主差分 |
|---|---|
| CUT-01 | 24mm低角度の1コマ。距離5mの対峙、ギター、ジョッキ、4基スピーカー、下端の青破線ドリー |
| CUT-02 | 横3コマ。ジョッキ右腰後方→左の頭部高さへオレンジ横薙ぎ、よーたんはシアン左下ダック、非接触で赤なし |
| CUT-03 | 横3コマ。ネックを両手保持、ギターボディが左下→右上へ進み脇腹へ一度接触、赤バースト、そば屋はシアン右滑走 |
| CUT-04 | 真上寄り横3コマ。ジョッキ頭上→右足元の床へオレンジ垂直軌道、接触点から赤同心円、よーたんはシアン左後方跳躍 |
| CUT-05 | 横3コマ。よーたんのシアン空中弧、ギターボディのオレンジ弧、中央上部でジョッキ側面へ接触し右外へ受け流す |
| CUT-06 | 横3コマ。通常演奏位置で一度ストラム。その直後だけ、同じ4基のスピーカー前面から赤い音圧がそば屋へ収束。ギターからビームを出さない |
| CUT-07 | 横3コマ。そば屋は右→中央左へシアン直進、ジョッキはオレンジ斜め振り下ろし、ギターボディ補強縁で防御 |
| CUT-08 | 横3コマ。ジョッキ底と大きなギターボディ外周の一点接触。ネックとヘッドは左上へ逃がす。中央赤バースト後、よーたん左・そば屋右へシアン反発 |

## 最終修正で固定した不変条件

- CUT-07のそば屋の身体矢印は、画面右から中央左へ向ける。
- CUT-07・08でよーたんはギターネックを両手保持し、ジョッキが触れるのは大きなギターボディ補強外周だけ。
- CUT-08のネックとヘッドストックは接触点から左上へ離す。
- 矢印、カメラ代理、赤バースト、クレイ材質は完成動画へコピーしない。
