# よーたん対そば屋 — 激しいアクション検証計画

## 検証目的

クレイレンダー絵コンテへ方向別の矢印を加えることで、Seedanceが「誰が、どちらへ、何を振り、どこへ接触し、カメラがどう動くか」を保持できるか検証する。完成映像に矢印やクレイ材質が混入しないことも同時に確認する。

## 矢印の読み方

| オーバーレイ | 拘束する内容 | 完成映像での扱い |
|---|---|---|
| シアン実線 | 人物の腰・胸を基準にした重心移動 | 人物だけが移動し、線は出さない |
| オレンジ弧 | ジョッキ、ギターボディなど攻撃部位の軌道 | 武器だけが軌道を通り、線は出さない |
| 赤バースト／同心円 | 接触、床振動、スピーカー音圧の発生源と力の方向 | 物理反応とVFXだけを出し、図解は出さない |
| 青破線＋灰色カメラ | カメラのドリー、クレーン、オービット | カメラだけを動かし、図解は出さない |

## 今回の仮説

1. 身体移動と武器軌道を別色にすると、回避方向と攻撃方向の取り違えが減る。
2. 接触点を赤で一点固定すると、「当たる前に相手が飛ぶ」「別の場所が壊れる」失敗が減る。
3. カメラ矢印をフレーム外周へ分離すると、人物の移動として誤解されにくい。
4. 接触の前後0.2秒だけカメラを安定させると、激しい移動中も打撃が読める。
5. スピーカー4基を発生源として赤い音圧を描くと、ギターから直接ビームが出る誤生成が減る。

## 生成前チェック

- [ ] 各画像は1 CUTだけを示す。複雑な接触だけSTART / CONTACT / ENDの3コマ。
- [ ] 1コマの矢印は原則2本、最大3本。
- [ ] 矢印が顔、武器、手、接触点を隠していない。
- [ ] よーたんは左、そば屋は右。真上ショットでも左右を維持。
- [ ] ギターは通常演奏可能な強化エレキギター。刃、棘、銃、別武器へ変えない。
- [ ] そば屋の白い仮面、大型ビールジョッキを保持。
- [ ] 床亀裂と滑走跡がCUT-04以降で消えていない。

## 生成後スコア

各項目を0〜2点で採点する。0＝失敗、1＝一部成功、2＝完全成功。合計20点中16点以上を合格とする。

| 項目 | 0点 | 1点 | 2点 |
|---|---|---|---|
| 左右固定 | 入れ替わる | 一瞬曖昧 | 全編固定 |
| 攻撃軌道 | 逆・別方向 | 概ね一致 | 全接触一致 |
| 接触因果 | 接触前に反応 | 一部曖昧 | 全て接触後に反応 |
| 回避方向 | 攻撃側へ移動 | 奥行きが曖昧 | 指定方向へ明確 |
| ギター持ち方 | ボディを持つ | 片手が崩れる | ネック保持を維持 |
| 床振動 | 別の発生源 | 広がりが曖昧 | ジョッキ接地点から放射 |
| 爆音圧 | ギターからビーム | 発生源が混在 | 4基のスピーカーから発生 |
| カメラ | 軸越え・人物消失 | 一部過剰 | 激しいが接触は読める |
| 累積状態 | 損傷が消える | 一部残る | 全て連続 |
| 図解混入 | 矢印が映る | 図解風VFXが残る | 矢印・クレイ表現なし |

## 再生成の切り分け

- 左右、接触、軌道の失敗：該当CUTの絵コンテだけを修正する。
- カメラが速すぎる：接触前後の安定区間を0.2秒から0.35秒へ増やす。
- 爆音圧の発生源が混ざる：CUT-06だけを短い別クリップに分ける。
- 30秒一括で順序が崩れる：CUT-01〜03、CUT-04〜06、CUT-07〜08の3クリップに分割し、CapCutで連結する。
- 矢印が映像へ混入する：入力表と禁止事項だけを強化し、矢印画像自体は増やさない。
