# ビールの記憶 — Remotion + Three.js アニメ回想版 v3

現在のそば屋がやめ太郎に、かつてのビール具現化修業を語る。二人の会話と、そば屋だけが登場する過去の回想を交互に描く。ユーザー添付の漫画がネタの出発点。動画生成AIは使わず、既存GLBとフレーム駆動の演技・撮影・編集で制作。

## 構成

1. 現在。そば屋とやめ太郎の二人カットから語り手の寄りへ。
2. 白い短いフラッシュを挟み、暖色の過去へ。ジョッキを観察し、写生するそば屋。やめ太郎は回想に登場しない。
3. 床のビールに四つん這いで覆いかぶさり、犬のように舐める。全身→口元の寄り。語りは現在のそば屋の回想ナレーション。発話後も42フレームの間を取り、異様さを見せる。
4. 現在のやめ太郎へカット。「念能力というかアルコール依存症やん」。
5. 回想へ戻り、禁ビール→幻覚→本物の具現化。
6. 現在へ。「ワイも給料で、それやりたいわ」「まず、実際の給料を用意しろ」。

セリフ正本: `remotion/src/dialogue.json`。タイミング正本: `remotion/src/edit-manifest.json`。そば屋は全カットで正典の仮面を装着したまま。舌は仮面の既存の口元から出る小道具。

## アニメ風の演出

- 元の顔・テクスチャ・頂点色を保持したMeshToonMaterialと3段階の陰影。
- 人物の演技は24fpsの2コマ打ち（12姿勢/秒）。カメラは24fps。
- 現在は寒色の店内、過去は暖色と紫がかった周辺色の一人の部屋。
- 名前札と章タイトルの常設表示を撤去。レターボックス、控えめな字幕、回想導入「あの頃――」、舐める場面の「ぺろ…」を後付け。
- 観察、写生、四つん這いの全身、舌と泡の接触へ専用カメラ。

## 音声末尾の修正

`audio-tail-edits.json`が再生成後のカット仕様。採用WAV自体へ反映済み。元の未カット音声とASR確認データは`voice_candidates/tail_audit/`（Git対象外）へ保存。

- line04: 約3.9秒から台本外の追加発話を検出。3.88秒まで保持し、末尾15msフェード＋100ms無音。採用長3.98秒。
- line08: 最後の「わ」後、2.478秒からの無音を根拠に2.60秒まで保持。末尾15msフェード。後続の孤立音を除去。
- ローカルWhisper-smallで元音声を予告テキストなしでトークン時刻付き認識。line04の原本では「やん」の後に追加発話が認識され、編集後は追加発話が消えた。短尺ASRは「依存症やん」の字面を誤認識するため、発音の正しさの保証には使わない。
- これは既存音声の編集。別話者・別TTSによる置換なし。字幕の台詞は維持。

## 素材・演技

正本パスとSHA-256: `asset-provenance.json`。

- 非ボクセル版そば屋v3、やめ太郎nose-v3、ジョッキv2。
- 基準クリップ上の12種類の演技: `04_GAME_ASSETS/3d/motions/skit_v1/motions.ts`。
- 四つん這い: 同フォルダの`flashback-motion.ts`。バインド姿勢から解析的2ボーンIKで手・足を配置、肘と膝のpoleを固定。骨長を維持。頭の上下動と、頭へ追従する舌を同期。
- モデル本体、顔、ウェイト、ゲームの採用モーションは変更しない。
- やめ太郎の口は既存SpeechOpenを音声RMSへ連動する簡易口パク。

## 再現

```sh
python3 03_SCRIPTS/73_beer_materialization_3d/generate_audio.py
python3 03_SCRIPTS/73_beer_materialization_3d/prepare.py
cd 03_SCRIPTS/73_beer_materialization_3d/remotion
npm ci
npm run typecheck
npm run studio
npm run render
```

採用WAVがあれば音声生成はスキップ。素材は正本GLBと採用WAVをpublicへhardlinkし、異なる実体の古いリンクは張り直す。ローカルのHiragino Sansを使用。Remotion/@remotionは4.0.526固定。

- Composition: `BeerTraining`
- 出力: `final_remotion_anime_v3.mp4`
- 1280×720、24fps、1273フレーム（53.041667秒）。
- 旧版: `final_remotion_3d.mp4`、`final_remotion_3d_v2.mp4`を保持。

## 検証記録

- TypeScript型チェック、字幕区間・RMS長・公開音声hardlink一致・編集後WAV尺の検証: 合格。
- 最終MP4: H.264 1280×720 / 24fps / 1273フレーム / 53.041667秒。AAC 48kHz（パディング込み53.098667秒）。映像・音声を終端までデコードしエラーなし。
- 最終動画から12カットを抽出し、導入二人カット、現在と回想の色分け、一人の回想、全身の四つん這い、口元と舌、現在へ戻る肌色・字幕を確認。`remotion/out/final-anime-v3-sheet.jpg`。
- 四つん這いに姿勢を変えた後の頭部誤カリングを検出し、人物メッシュのfrustum cullingを無効化。単独静止画だけでなく350〜630フレームを連続レンダーして再確認。
- セル材質へ変更時に失われたやめ太郎の頂点色を引き継ぎ、白くなった側頭部・頬・鼻を修正。
- 四つん這いの骨長、手足の位置、口元とジョッキの接触を今回のモデル・カメラで確認。別モデルや自由視点での汎用的な保証ではない。
- 音声末尾はユーザーの指摘と時刻付きASR・無音区間を根拠にカット。通し試聴による声質・発音・微細な口パクの監査とは区別する。
