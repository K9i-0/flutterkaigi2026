# たこさん実写擬態能力テスト — 福ちゃん

## 目的

Wan 3.0が、標準の窓際トイジオラマ3D版たこさんから、実在人物の正典写真を基準にした実写福ちゃんへの連続擬態を表現できるか検証する。

1. 小さい通常たこさんが全身を螺旋状に捩り、配色を変えず福ちゃんの170cm・細身の人型輪郭へ成長・変形する。
2. 福ちゃんの輪郭と顔形状を固定したまま、足元から頭頂へ体色と材質が変わり、完全な実写の福ちゃんになる。

完成尺は8秒。無台詞、固定カラメ、全身ワンショットとし、カット、煙、フラッシュ、画面外で変身を隠さない。

## 体格差とカメラ

- 開始たこさん: 画面高42〜45%。足元の接地点は画面高約90%。
- 完成福ちゃん: 画面高78〜84%。170cmの細身。
- カメラ、レンズ、床位置、背景は8秒間固定。ズーム、ドリー、クロップ、リフレームを禁止。
- 開始たこさんが成人サイズに拡大される、または開始と完成が同じ画面高になる場合は失格。

## Hard constraints

- 全編で正確に1体の同一個体だけ。入れ替わり、クローン、二重露光、複数人物なし。
- 色・肌・写実材質は4.8秒より前に出さない。形状変化中は全身がたこさんの黒・グラファイト・淡い白だけ。
- 3.8〜4.8秒はImage 3の中間形を1秒間明確に保持する。
- 4.8秒以降は輪郭、体格、顔形状、髪形、衣装形状、ポーズを変えず、色と材質だけを変える。
- 完成形の顔は正典福ちゃん本人。類似の別の日本人男性、別の髪型、顔の年齢変化、顔の性別変化なし。
- カット、フラッシュ、暗転、煙、粒子、障害物、画面外逃避で変形を隠さない。
- 切断、血、傷、皮膚の脱落、露出組織、触手残骸、余分な腕・手・脚・指なし。
- 名札、ランヤード、Tシャツの文字を可読に生成しない。字幕、ロゴ、透かし、UI、台詞、発声、BGMなし。
