# CM文字演出（Remotion後付け）

`production-plan.json` の `graphics` を文字・仮フレーム割りの正本とする。背景画像へ広告文字を焼き込まない。段ボールの文字、冊子の表紙、ポスター、缶のラベルは実物の意匠として保持する。

- 全セリフを字幕化せず、商品名・特徴・体験・付属品を各場面で大きく見せる。白文字＋濃い縁取り／影を基本とし、価格のみ強く色を変える。
- 価格場面は通常価格1,490円→創刊号特別価格399円。同じ位置で12フレームの切替を行い、399円を大きく静止保持。通常価格はユーザー指定の1,490円。価格を追加で読み上げる変更はしない。
- 右下は白い検索窓に「チュア　窓際族」、隣に「検索」ボタン。全体として「チュア　窓際族で検索」を示す。見せる文言はユーザー指定のまま。タイトル登場からエンドまで維持する案。
- 1280×720基準で右48px・下36px、幅380px・高さ48px。価格は右中段、商品説明は左下、検索窓とは重ねない。画像生成の段階でこの領域を空ける。
- 本の表紙にある399円は物理的な印刷のため残す。大きな後付け価格演出とは別レイヤーとして扱う。
- 音声生成後に「創刊号は399円」の発話と価格の切替点を合わせ、最終フレーム割りを確定。タイトル／価格／検索窓の各開始・終了で静止画監査を行う。

## 検索窓の見た目（ユーザー参照画像反映）
- 元CMと同じ「検索語＋検索ボタン」の横並び。文字列は「チュア　窓際族」と「検索」。
- 現代的な白い角丸入力欄、細いグレー枠、控えめな影、左に虫眼鏡。検索ボタンは濃紺のフラット塗り。立体的なベベルや強い光沢は使わない。
- 角丸12px、文字25pxを1280×720基準とする。広告動画内のグラフィックで、入力カーソルやタップ動作は付けない。
