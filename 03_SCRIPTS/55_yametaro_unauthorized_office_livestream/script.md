# やめチャンネル — オフィス無断生配信

## 制作仕様

- 形式: 無職やめ太郎が自撮り棒付きスマートフォンを片手に、勤務中のオフィスを無断で生配信する30秒のオフィスコメディ
- 映像生成: `wan3.0-video`、480P、16:9、30秒の単一タスク
- 完成編集: Remotion 4.0.518
- `postproduction=remotion`
- `visual_preset=yame_channel_live_v1`
- 配信プラットフォーム: `YumeTube Live`。YouTubeを下敷きにした架空のパロディサービス
- チャンネル名: `やめチャンネル`
- 映像の見せ方: 第三者カメラで無断配信の危うさを見せるショットと、スマートフォンの実際の配信映像を交互に使う。配信UIとコメントは配信映像区間だけに後付けする。
- 温度感: 明るい昼のオフィス。笑い声や派手な漫画VFXを使わず、配信者の軽さと周囲の焦りの落差で笑わせる。

## 配役と人物同一性

- 無職やめ太郎: `character_yametaro_basic_sheet.png`と同一人物。紫色ワイシャツ、丸メガネ。片手に自撮り棒付きスマートフォンを持ち、許可を取らず配信している。第三者ショットでは自撮り棒とスマートフォンを常に一組だけ見せる。
- そば屋: `character_sobaya_basic_sheet.png`と同一人物。白い仮面、ニュートラルなグレー肌、筋肉質な体格。全登場フレームで仮面を正しく装着し、外す、ずらす、透過する、素顔化することを禁止する。机の大型透明ジョッキ一個には琥珀色の液体と泡が入っている。
- 福ちゃん: `character_fukuchan_basic_sheet.png`と同一人物。今回は笑顔ではなく、タコさんと並んでモニターを真剣に見つめる。最後に焦ってやめ太郎のスマートフォンへ手を伸ばす。
- タコさん: `character_takosan_basic_sheet.png`と同一キャラクター。黒いフード付きローブ、白い顔、黒い丸目、下半身の触手、人間型の腕二本、白く丸い手。台詞なし。

## Wan生成時の音声方式

- `audio_source=wan3`
- `audio_sync_strategy=wan_generated_lip_sync`
- `reference_audio_usage=voice_timbre_only`
- `parameters.audio=true`
- やめ太郎、そば屋、福ちゃんの今回の日本語台詞と口・顎・頬の動きをWan 3.0へ同時生成させる。Wan埋め込み音声を基本の同期源とする。
- 発音、欠落、反復、言い換え、余計な語句がある場合だけ、`VOICE_CAST.md`準拠のIrodori音声から問題の意味単位を部分修復し、可視口元を再監査する。正常区間は全面差し替えしない。
- そば屋は白い仮面で口元が見えないが、声はWanへ生成させる。生成後に声質または発音の修復が必要な場合、Irodori出力へ`sobaya_monsterize.sh`を適用する。
- BGMなし。小さなオフィス空調、足音、キーボード、ジョッキを掲げる小さな接触音、最後に手がスマホへ触れる音だけ。笑い声、拍手、デジタルグリッチ、追加の話者は禁止する。
- 生成後のユーザー監査によりWan台詞は最終採用せず、完成版は後述の「全台詞Irodori差し替え」を正本とする。

### やめ太郎ハイテンション採用音声

- 無断生配信でテンションが上がったお調子者の演技として、Irodori-TTSのseed `100`を採用した。
- モデルと話者同一性は正典どおり`Aratako/Irodori-TTS-v4.1-Small`＋`02_CHARACTERS/Yametaro_voice.wav`。ハイテンションcaption、全文、ハッシュを含む再現情報は`yametaro_voice_selection.md`を正本とする。
- 採用全文は`yametaro_high_energy_seed100_full.wav`。Wanには独立した一文「じゃーん、彼が窓際族のエース、そば屋やで！」を無音境界で切り出した`voice_ref_yametaro_seed100_3_869s.wav`だけをvoice-timbre参照として渡す。
- 不採用seed `7`、`42`、`2026`、`550030`の候補音声と聴き比べ用プレイリストは削除済み。
