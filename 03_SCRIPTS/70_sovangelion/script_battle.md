2026-09-22。ユーザー承認の約3分シナリオを、Remotion + Three.js + Imagegenで制作した拡張版。従来の70話リメイクと出力は保持し、同じRemotionプロジェクトへ`SovangelionBattle` compositionを追加。

## 映像の分担

- そば屋: 正典の非ボクセルGLBを巨大役として使用。セル材質へ変換、スキニングの誤カリングを無効化。仮面・肌・顔・モデル本体を維持。
- やめ太郎: nose-v3。窓際席の机・段ボール椅子・PCをThree.jsで構成し、座り姿勢と手の動きを追加。口は既存SpeechOpenを音声RMSで駆動する簡易口パク。
- たこさん: そば屋ハザードの採用モデル `04_GAME_ASSETS/3d/characters/takosan/rig_sheet_v2/takosan.glb`。ゲームの参照先と一致する27ボーンの非ボクセルモデルを使用。元の6本触手をIKと伸長で動かし、攻撃・拘束を演出。モデルファイルは無変更で、胸へ赤いコアを追加。
- よーたん・福ちゃん: 正典 `04_GAME_ASSETS/voxel/models/` のGLBを通信室へ配置。頭のうなずき、腕の身振りを発話に合わせて動かす。モデル固有の顔を維持し、口パクは行わない。
- Imagegen新規3枚: 夜の街、コア破壊、腹の窓が明るい終幕。採用画像は`battle_assets/`。実送信プロンプトは`prompt_imagegen_battle_*.txt`、生成元・SHAは`battle-image-generation.json`。
- ドックも3D化し、巨大そば屋・やめ太郎・ボクセル福ちゃんを配置。発進と戦闘も3D。勤怠・承認待ち・操縦権限変更・日報の文字はRemotionで正確に描画。

動作・接触はフレーム直接評価。基準クリップの歩行・走り・被弾・ジャブ・ジョッキ保持・ジョッキ攻撃に、座り姿勢・手のIK・拘束姿勢を追加した。物理エンジンによる戦闘ではなく、カットに合わせた手続き型アニメーション。今回のモデルと撮影条件向けの演出であり、汎用モーションとしてゲームへ採用していない。

## 音声

- エンジン: Irodori-TTS `Aratako/Irodori-TTS-v4.1-Small`。`tools/irodori_speak.sh`、自動尺、時間伸縮なし。
- 参照: `02_CHARACTERS/VOICE_CAST.md`指定のSobaya / Yametaro / Fukuchan / Yotan正典WAV。
- 既定seed: そば屋42、やめ太郎7、福ちゃん100、よーたん100。採用時に変更したseed・caption・読みは各行のJSONへ保存。
- そば屋のみ`tools/sobaya_monsterize.sh`。完成採用WAVは`battle_lineNN_*.wav`。
- 効果音と小さなドック環境音は、既存70話のWan生成音声の発話のない冒頭から編集。新規のWan課金・別音声生成サービス・合成効果音は使用していない。
- 採用効果音は`battle_fx_*.wav`。元動画と切出位置は`prepare_battle.py`に保存。rumble: 初回0–0.85秒、beam: 初回1.05–2.35秒、impact: 初回2.8–4.4秒、dock: リメイク0–1.5秒。25msの頭フェードと90msの末尾フェード、48kHz stereo。
- 本番レンダーは採用WAVを使用。`generate_battle_audio.py`は既存の採用WAVをスキップする。

### 余分な発話の修正

Whisper-smallの全文照合でline02・line12に台本外の末尾を検出。line02は修正版でも追加発話があったため、時刻付き認識（本文0–1.26秒、追加1.68秒以降）を根拠に1.43秒まで保持し、15msフェードを適用。`battle-audio-tail-edits.json`で再生成に反映。

line12は読み・seed・captionを調整し、「何も押してへんで」までの採用テイクへ差し替えた。line09と10も明瞭さを調整。同じ正典話者を維持。候補原本は`voice_candidates/battle/`に残し、Git対象外。

ASR記録は`battle-audio-audit.json`。同音語の誤表記（勤怠、申請、ワイ、日報など）があるため、ASR一致を発音・演技・声質の保証とはしない。今回の自動照合とデコード確認は、聴覚による通し試聴・音素単位リップシンク監査とは区別する。

## 再現

```sh
python3 03_SCRIPTS/70_sovangelion/generate_battle_audio.py
python3 03_SCRIPTS/70_sovangelion/prepare_battle.py
cd 03_SCRIPTS/70_sovangelion/remotion
npm ci
npm run typecheck
npm run render:battle
```

依存関係は既存70・73話と同じRemotion 4.0.526。素材は正典からpublicへhardlinkする。`public/battle/`は再構成可能なためGit対象外。採用台詞・効果音・入力画像・コード・lockfileを追跡する。日本語フォントはローカルのHiragino Sans。

- Composition: `SovangelionBattle`
- 最新出力: `final_remotion_battle_v2.mp4`（初版 `final_remotion_battle.mp4` は保持）
- 確認版: `remotion/out/battle-review.mp4`（640×360）、`fight-final-review.mp4`（720pの拘束〜決着）

## 検証

- TypeScript型チェック合格。
- 全編確認版からカットを抽出し、人物、字幕、通信画面、窓際席、出撃、戦闘、決着を確認。
- たこさんの見切れを検出してサイズと角度を修正。ジャブの左手の最大伸長時刻を基準クリップから測り、敵の反応と効果音を合わせた。
- 拘束〜決着の600フレームを連続レンダーし、触手、空のジョッキ、振り下ろしから決め絵への切替、人物の仮面とカリングを確認。
- 聴覚による通し試聴と精密な音素同期は未監査。通信相手はボクセルの身振り、3Dのやめ太郎は簡易口パク。

- 全43カットの中央フレームを最終動画から抽出して確認。冒頭のたこさんの向き、発進と終幕の見切れを追加修正。
- 字幕15本は重なりなし。全43カットの開始・終了が連続し、RMSのフレーム数と音声hardlink一致、正典GLBのSHA一致を検証。
- 音声ピークは-1.2dBFS（最終と同じ音声ミックスの測定）。映像の再出力で音声内容は変更していない。

最終MP4検証: H.264 1280×720、24fps、4320フレーム、映像180.000000秒。AAC 48kHz、パディング込み180.053333秒。終端までデコードしてエラーなし。最終SHAと詳細は`battle-render-record.json`。
