## 2. 実施したセルフレビューと改善内容

1. **話者同一性の強化（マルチリファレンス結合）**:
   - `infer.py` の `--ref-wavs` 機能を活用し、同じ話者の複数の短尺参照音声（自己紹介・業務トーク・エピソードトーク）を結合エンコード。
   - やめ太郎の独特なハスキー中低音と関西イントネーション、福ちゃんの明るいハイトーンが大幅に向上。
2. **音質・滑らかさの向上（Sampling Steps 40 → 50）**:
   - 拡散モデルのサンプリングステップ数を50へ引き上げ、母音の伸びや子音の摩擦音・破裂音の歪みを解消。
3. **CFG（Classifier-Free Guidance）スケールの精密調整**:
   - `--cfg-scale-speaker`: 5.0 → 6.0〜6.5（話者の声質をより強く保持）
   - `--cfg-scale-text`: 3.0 → 3.5（日本語発音の滑舌・明瞭度を向上）
   - `--cfg-scale-caption`: 3.0 → 4.0〜4.5（感情表現・脱力感・緊迫感を強調）
4. **表記（句読点・間）のチューニング**:
   - 「そば屋、最近、人が〜」「えっ、何がですか？」「えぇ……どういう構造なんや……」など、息継ぎや間の配置を最適化。
