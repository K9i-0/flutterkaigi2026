## 生成タスク

- タスク：通常生成を2回行い、15秒クリップAと15秒クリップBをCapCutでハードカット結合する。
- 設定の正本：CapCut／Seedance生成画面。
- 選択済み設定：Seedance 2.0、各15秒、480p、16:9。
- 自動継承：なし。2本とも同じモデル、解像度、比率、画調を手動で選ぶ。
- 総尺：30秒。Long Video、既存動画編集、延長、始終端、複数キーフレームは使わない。
- 媒体：添付オフィス画像とキャラクターシートに合わせたフォトリアルな実写調オフィスコメディ。
- 画像方針：シーン別開始画像、終了画像、絵コンテ、アクション図は作らない。入力は3人の基本キャラクターシート、極度乾燥の缶、小道具のないオフィス画像だけに限定する。

## 厳守方針と優先順位

1. 5本の日本語セリフを指定話者、全文、順番、時刻で一度ずつ明瞭に入れ、そば屋には発話させない。
2. そば屋、福ちゃん、よーたんを各基本シートと同一人物に固定し、クリップ間で顔、髪、体格、衣装、装備を変えない。
3. 停止前のタイピング、電源断、よーたんの到着、カバー開放、消耗缶Aの取り外し、新品缶Bの装填、カバー閉鎖、再起動という因果を守る。
4. クリップA末尾とクリップB冒頭の人物位置、姿勢、カメラ側、机上物を連続させる。
5. 缶A、缶B、背面カバー、机上の大型ジョッキ、ギターを複製・消失・混同させない。
6. 画質、カメラ移動、背景の動き、装飾的演出。

音声と映像が競合したら、カメラ移動、背景の動き、手振りの順に簡略化し、必須セリフとビール交換の接触順を守る。

## シーン地理と開始配置

- 舞台：`environment_open_plan_office_production.jpg`のようなアクシデンチュア株式会社の一般オフィス。昼。明るく清潔で整理され、左右に白い机列、中央に幅広い通路、大窓から白い拡散光が入る。
- 使用席：画面右側の同じ机列に隣接する2席。奥側がそば屋、手前側が福ちゃん。2人とも机へ向いて横並びに座り、各自のモニターとキーボードを使う。
- カメラ側：中央通路側から2人の顔と手元を読む前方3/4を基本にする。停止後だけ同じ中央通路側から背面3/4へ切り、そば屋の背中、福ちゃんの横顔、奥から来るよーたんを同時に見せる。軸を越えず、そば屋は常に画面左寄り、福ちゃんは画面右寄り。
- 机上固定物：そば屋のモニター1台、キーボード1台、マウス1個、大型の透明ガラス製ビールジョッキ1個。ジョッキは机の左奥、モニターから離れた安全な位置に直立し、琥珀色のビールが半分入ったまま。福ちゃん側にはモニター、キーボード、マウスだけ。
- 背面カバー：そば屋の白Tシャツの背面中央、肩甲骨の間に、縦15cm×横9cmほどの白い硬質樹脂製カバー1枚が布面と面一に収まる。停止前の前方画では見えない。停止後の背面画でだけ、細い長方形の合わせ目と上端の小さなラッチが読める。
- カバー内部：350ml缶1本だけが縦向きに収まる、清潔で暗い金属製スロット。配線、臓器、皮膚、血、傷は見せない。人体の穴ではなく、コメディ用の完成された機械ハッチとして扱う。
- よーたんの経路：クリップAの12.9秒に中央通路の奥から静かに歩いて来る。14.4秒にそば屋の椅子の真後ろ約1mで止まる。クリップBでは同位置から半歩近づき、ギターをストラップで背負ったまま両手で交換作業を行う。
- 登場人物：3人だけ。匿名社員、店員、追加の窓際族を出さない。

## 動作原則

- そば屋：停止前は背筋が垂直で、顔と仮面をモニターへ固定し、両手だけが均一な高速リズムで機械的にタイピングする。停止時はキー入力が一瞬で止まり、頭、肩、肘の力が抜け、腰は椅子に残したまま上体が前へ約25度倒れる。再起動時はこの順序を逆再生せず、頭が上がる→背筋が戻る→両手がキーボードへ揃う→新しい入力としてタイピングを始める。
- 福ちゃん：自然にPC作業をしながら、発話時だけそば屋を見る。驚きは目、眉、上体、手の動きで見せる。クリップAの「ギュン」で右手を右頬の近くへ上げ、クリップBのオチ後に両手を頬へ当てた正典のギュンギュンポーズを完成させる。
- よーたん：原因を既に知っている落ち着いた態度。急がず騒がず、そば屋の身体を押したり揺すったりしない。黒いギターはストラップで背中から右腰にかけて保持し、作業中も床へ置かず、演奏しない。
- カバーC：上端ラッチを押してから、よーたんが背中からまっすぐ外す。外した後は机の右奥へ外面を上にして置く。缶交換後、同じ向きで元の開口へ合わせ、四隅を押して1回のクリックで固定する。
- 消耗缶A：開始時は背面スロット内。`prop_kyokudo_kanso_beer_production.png`と同じ意匠だが、表面の結露がなく少しくすんでいる。5.2〜6.5秒によーたんが右手で垂直のまま引き抜き、机の右奥へ立てて置く。その後は動かさない。
- 新品缶B：開始時はよーたんの左手で背中側に隠し、5.2秒より前は画面に見せない。`prop_kyokudo_kanso_beer_production.png`と同じ意匠で、銀色が明るく、細かな冷たい結露がある。6.7〜8.0秒に左手でスロットへ縦向きに挿入する。AとBを同時に同じ場所へ入れず、接触前に手やスロットを貫通させない。
- コメディ：ロボットらしさは均一な動作、停止姿勢、機械音、缶交換という因果で見せる。変身、火花、爆発、煙、感電、派手な漫画VFXを使わない。

## 30秒の秒区間設計

### クリップA 0.0〜6.7秒：機械のように働くそば屋

- 入口状態：そば屋は画面左寄り、福ちゃんは右寄りの隣席。2人とも正面のモニターへ向き、口を閉じて作業中。
- カメラ：中央通路側から35mm相当の安定した二人ミディアム。2人の顔、上半身、両手、キーボードを同時に読む。背景は浅すぎない被写界深度で一般オフィスと分かる。
- 動作：そば屋は毎秒約6〜7打鍵の規則的なリズムで、両手首を浮かせ、腕と上体をほぼ動かさず黙々とタイプする。福ちゃんは自然な速度でタイプし、0.4秒に手を止め、そば屋へ顔だけを向ける。そば屋は反応せずタイプを継続する。
- 音声：0.4〜6.0秒、福ちゃんが感心半分、不思議そうな明るい男性声で「そば屋最近人が変わったようによく働くなー」と1回だけ発話。6.0〜6.7秒は口を閉じ、そば屋の打鍵音だけ。
- 出口状態：そば屋は入力継続。福ちゃんはそば屋を見ている。机上ジョッキは左奥で静止。

### クリップA 6.7〜8.7秒：緊急停止

- 入口状態：そば屋は高速タイピング中。
- カメラ：6.7秒、キーボードとそば屋の手の50mm相当クローズアップ。7.1秒に同じ軸側の背面3/4ミディアムへ動作マッチで切る。
- 動作：6.85秒、両手の全指がキー上で同時に止まる。6.95秒、手首が沈む。7.1〜7.8秒、頭が垂れ、肩と肘の力が抜け、腰は椅子に残ったまま上体が前へ約25度倒れる。7.8秒以降は完全静止。転倒せず、机に顔を打ち付けない。
- 背面カバー：7.1秒の背面画から、白Tシャツ中央の縦長カバーCの細い合わせ目と上端ラッチが初めて読める。まだ開かない。
- 音声：6.85秒に打鍵音が完全停止。6.9〜7.7秒、短い下降電子音と低いモーター停止音`ピロロ……ウゥン`、7.75秒に小さな電源断音`プツン`。人物は発音しない。BGMなし。
- 出口状態：そば屋は前のめりで無反応。福ちゃんが椅子ごと少し向き直る。

### クリップA 8.7〜12.9秒：福ちゃんの呼びかけ

- カメラ：同じ背面3/4の50mm相当二人ミディアム。そば屋のカバー、停止姿勢、福ちゃんの顔と右手を同時に見せる。発話中は動かさない。
- 動作：8.7〜9.1秒、福ちゃんが目を見開き、右手をキーボードから右頬の近くへ上げる。そば屋には触れず、顔を覗き込む。9.1〜12.5秒、姿勢を保って発話。12.5〜12.9秒、口を閉じて通路奥の足音へ目だけを向ける。
- 音声：9.1〜12.5秒、福ちゃんが心配と困惑の混じった声で「え、そば屋？どうしたギュン？」と1回だけ発話。ほかの声、機械音、音楽を重ねない。
- 出口状態：そば屋は停止したまま。福ちゃんは右手を頬の近くに保ち、通路奥を見る。

### クリップA 12.9〜15.0秒：よーたんが到着する

- カメラ：同じ背面3/4の35mm相当へ少し広げる。前景左に停止したそば屋、前景右に福ちゃん、背景中央の通路によーたん。
- 動作：12.9秒、よーたんが通路奥から通常の歩幅で静かに入る。サングラス越しにそば屋の背中を見て、慌てず2〜3歩進む。14.4秒、そば屋の真後ろ約1mで止まる。新品缶Bは左手で背中側に隠して画面へ見せない。ギターはストラップで背中から右腰に保持。3人とも無言。
- 音声：革靴の静かな足音2〜3回、低いオフィス空調だけ。
- クリップA最終状態：そば屋は画面左で前傾停止、カバーCは閉じたまま。福ちゃんは画面右で振り返り、右手が頬の近く。よーたんは中央奥で停止し、そば屋の背中を見ている。ジョッキは机の左奥。缶は見えない。

### クリップB 0.0〜4.0秒：よーたんが原因を言い当てる

- 入口状態：クリップA最終状態を継続。カメラは同じ中央通路側、同じ背面3/4、同じ昼光。人物の左右、姿勢、衣装、机上物を変えない。
- カメラ：50mm相当の安定した三人ミディアム。そば屋の背面カバー、よーたんの顔、福ちゃんの横顔を同時に読む。発話中は固定。
- 動作：0.0〜0.4秒、よーたんがカバーを見て小さく納得のうなずき。0.4〜2.3秒、落ち着いて発話する。2.3〜2.8秒、福ちゃんがよーたんへ顔を向ける。2.8〜3.5秒、福ちゃんが短く問い返す。3.5〜4.0秒、福ちゃんは口を閉じ、よーたんはそば屋の背後へ半歩近づく。
- 音声：0.4〜2.3秒、よーたんが低く平静な男性声で「あ、切れちゃったか」と1回だけ発話。2.8〜3.5秒、福ちゃんが理解できず「え？」と1回だけ発話。同時発話なし。
- 出口状態：よーたんはそば屋の真後ろ、カバーへ両手が届く距離。新品缶Bは左手で背中側に隠したまま。

### クリップB 4.0〜6.7秒：カバーを外し、消耗缶Aを抜く

- カメラ：そば屋の背中とよーたんの両手を正対に近い70mm相当で見る安定したクローズアップ。カバーC、ラッチ、手、スロット、缶Aの接触を隠さない。福ちゃんは画面右端の中景で見守る。
- 動作：4.0秒、よーたんの右親指が上端ラッチを一度押す。4.15秒にラッチが解除される。4.2〜4.8秒、右手の指でカバーCの上端を掴み、背中からまっすぐ5cm引いて外す。4.8〜5.1秒、カバーCを机の右奥へ外面を上にして平らに置く。5.1〜5.3秒、スロット内に縦向きの消耗缶Aが初めて見える。5.3〜6.1秒、右手で缶A上部を掴み、軸に沿ってまっすぐ引き抜く。6.1〜6.5秒、机の右奥でカバーCの隣へ直立させる。6.5〜6.7秒、右手を離す。
- 接触物理：ラッチ解除前にカバーを動かさない。カバーが外れてから缶Aを見せる。指が背中、カバー、缶を貫通しない。缶Aを落とさず、開けず、飲まず、潰さない。
- 音声：4.15秒に小さな`カチッ`。4.2〜4.8秒に短い樹脂の摺動音`スッ`。5.3〜6.1秒に低い金属スライド音`シュコン`。6.4秒に缶底が机へ触れる小さな`コトッ`。人物は無言。
- 出口状態：カバーCは机へ平置き、缶Aはその隣に直立。背面スロットは空。新品缶Bはまだ画面外。

### クリップB 6.7〜9.9秒：新品缶Bを装填し、カバーを閉める

- カメラ：同じ70mmクローズアップを維持。必要なら6.7秒にわずかに引き、よーたんの左手と空スロットを同時に入れる。カットしない。
- 動作：6.7秒、よーたんの左手が背中側から新品缶Bを1本だけ出す。細かな結露と正面ラベルが一瞬読める。6.7〜7.1秒、缶Bの底を空スロットへ垂直に合わせる。7.1〜8.0秒、左手で軸に沿ってゆっくり奥まで押し込み、8.0秒に底部端子へ着座させる。8.0〜8.3秒、左手を離し、缶Bだけがスロット内へ固定される。8.3〜8.6秒、右手で机上のカバーCを拾う。8.6〜9.3秒、元の向きで開口へ合わせ、四隅を均等に押す。9.3秒、上端ラッチが1回だけ閉じる。9.3〜9.9秒、よーたんが両手を離し、カバーの四辺が白Tシャツ背面と面一であることを確認する。
