# そば屋クローン研究所 — 30秒シナリオ

## 確定事項

- 最後のやめ太郎のセリフはユーザー採用済み：**「指示どおり働くなんて、そば屋さんやない！」**。命令どおりに動くクローンに驚き、普段のそば屋との違いをツッコむ。
- ステージはA4。環境参照は `reference_lab_hologram_adopted.png`。左右に培養ポッド、最奥に大きなたこさんのホログラム。投影装置は目立たせない。
- 筒状の培養ポッド一つにつきそば屋一体。培養液はビール。白い仮面は装着したまま。
- たこさんは黒いローブ、白衣なしの研究者。二人を貴重なサンプルとして回収させる。
- 標準窓際社員＝10 MWの相対尺度。福ちゃん213 MW、やめ太郎5,082 MW、そば屋10,247 MW。
- 基本の流れと、序盤に動き出しそうな気配を作るホラーカメラ演出は採用。以下、最後以外の台詞は現在の推奨案を記載し、全文確定とは扱わない。

## 現在の台詞案

1. やめ太郎「これ、全部そば屋さんのクローン？」
2. 福ちゃん「ギュンギュンどころじゃないわね……」
3. やめ太郎「窓際族、増やしてどうすんねん」
4. たこさん「……五千。そば屋の半分近いな」
5. たこさん「二人とも、実に興味深い」
6. たこさん「そば屋くん。傷つけずに回収したまえ」
7. **やめ太郎「指示どおり働くなんて、そば屋さんやない！」〔採用確定〕**

たこさんは数値に少し興味を示し、捕獲命令も研究助手への普通の指示の温度で話す。「傷つけずに」は検体の品質への配慮。

## 映像構成（30秒／編集目安）

| 尺 | 映像・演出 |
| --- | --- |
| 0〜4秒 | 槽内から泡とガラス越しに二人を見る。ガラスすれすれの横移動で配管の陰から別の白い仮面が現れる。やめ太郎の台詞1 |
| 4〜7秒 | 福ちゃんの肩越しから背後の仮面へピントを送る。槽内の指が僅かに曲がるが二人は気づかない。台詞2 |
| 7〜11秒 | 二人の前をゆっくり後退。鈍い打音に一拍遅れてカメラが振り返る。台詞3。最後は仮面へ寄り、何か起きる寸前に切る |
| 11〜16秒 | たこさん側の監視映像。窓際力をカウントアップ、213→5,082、規格外判定。台詞4。RemotionのUIを重ねる |
| 16〜23秒 | 採用A4の全景を初めて見せ、最奥のホログラムが語りかける。台詞5・6。出口が施錠される |
| 23〜25秒 | アラート。掌の接写、ガラスの亀裂、破砕とともにカメラが引く。そば屋たちがビールとともに飛び出す |
| 25〜30秒 | 二人と逃げる手持ち撮影。指示どおりに襲ってくるそば屋を見て、やめ太郎が確定台詞7を叫ぶ。発話終了後に暗転 |

通常は静かなカメラ移動、異音への反応のみ少し乱す。序盤の動きは覚醒の前兆、本格覚醒・襲撃は命令後。仮面自体を表情変形させず、首・指・身体で不気味さを作る。

秒数は編集目安。最後の採用台詞に約5秒の枠を確保し、自然な発話終端を優先して動作と配分を調整する。音声未生成・未実測のため30秒への厳密な収まりは制作時に確認。研究の最終目的はまだ明かさない。
