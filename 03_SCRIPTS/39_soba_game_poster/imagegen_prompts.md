# 「そばゲーム」映画ポスター ImageGenプロンプト

## 全案共通

- Use case: `ads-marketing`
- Asset type: Japanese movie poster, vertical 2:3, 1024×1536 PNG.
- Primary request: オリジナルのデスゲーム系ジャンル表現による「そばゲーム」。既存作品のロゴ・衣装・セット・商標は模倣しない。
- Input images:
  - Image 1: `02_CHARACTERS/Sobaya.jpg` — そば屋の同一性とデザインを厳守する参照
  - Image 2: `02_CHARACTERS/Yotan.jpg` — よーたんの顔とデザインを厳守する参照
  - Image 3: `02_CHARACTERS/Fukuchan.jpg` — 福ちゃんの顔とデザインを厳守する参照
  - Image 4: `02_CHARACTERS/Tokun.jpg` — とーくんの顔とデザインを厳守する参照
- Scene: 架空の日本企業内にある窓のない工業的ゲーム会場。赤い警告灯と冷たいモニター光。本気のサスペンス演出に、会社員の「デスマーチ」という不条理な笑いを合わせる。
- Cast exactly four:
  - そば屋は大型モニター内だけに登場するゲームマスター。筋肉質、露出肌はすべてニュートラルグレー、白い仮面、黒い丸目、赤い縦模様、短い黒髪、白い半袖Tシャツ、大型ビールジョッキ。
  - よーたんは金髪、サングラス、黒レザーのロック服、ギターを保持。
  - 福ちゃんは中央分けの黒髪、おしゃれな黒いロングコートと白いグラフィックTシャツ、両手を頬の横へ置くギュンギュンポーズ。余計な文字を避けるため名札とストラップ文字は省略。
  - とーくんは少しふくよか、麦わら帽子、サングラス、ミント色のアロハ、木製ウクレレ。首輪が見えるようレイは省略。
- Collar: 会場の3人は、それぞれ首にマットブラックの電子首輪を一つ装着。小さな赤い発光部と機械モジュール。非ゴア、負傷なし。
- Exact visible text:
  1. `そばゲーム`
  2. モニター内だけに `今からみなさんにはデスマーチをしてもらいます`
- No other text: 人名、英字、数字、クレジット、ロゴ、透かし、標識、UIラベル、偽日本語を追加しない。
- Quality: photoreal cinematic composite, accurate anatomy, exactly three physical contestants plus Sobaya on the monitor, readable Japanese typography, unobstructed faces, all required props inside frame, non-gory.

## Variant A — 巨大モニター支配

画面上半分を巨大なCRT風モニターで占め、そば屋の仮面とビールジョッキを左右対称に大写し。下半分によーたん、福ちゃん、とーくんを腰上で横並び。低いカメラ位置、赤黒とシアン光。テロップは画面内の黒帯、タイトルは下部の極太白文字。

## Variant B — 首輪と3人の表情

3人の胸上ポートレートを三角構図にし、首輪と表情を最大のフックにする。福ちゃんを中央最前面、よーたんを左、とーくんを右。背後上部のモニターにそば屋。青鉄色と警告赤。タイトルは下四分の一の蕎麦色。

## Variant C — 監視カメラ俯瞰

円形の工業的ゲームアリーナを高い監視カメラ視点から俯瞰。3人を緊張感ある三角形に配置し、上部の吊り下げモニターにそば屋。白い蛍光灯、炭色の影、赤い警告円。タイトルは下部に大きく水平配置。

## 実行方式

Codex組み込みのImageGenを使用。A/B/Cは同じ4枚の原典画像から別々に生成し、前案を次案の編集元には使用していない。
