## 工程

1. 単体全身参照 `character_fukuchan_stylized_C_sheet.png`。画像確認済み: 全身、リアル成人頭身、柔らかな3D質感、髪の束、名札、両腕と胴の隙間。手は完全な指開き・正面の手のひらにはならず自然な半開き。生成後の手を確認する。
2. Wan 3.0 / 8秒 / 720P / 3:4 / seed 917031 / single task。台詞なし、Wanの微かな室内音のみ。
3. 実動画の向きと姿勢を見て正面・左右側面・背面を抽出。時刻を機械的にそば屋から流用しない。四枚間で拡縮・トリミングしない。
4. Tripo P2-20260801 / quad / face_limit 15000 / detailed PBR / seed 917031で全身を一体生成。
5. 出力GLBの正面・斜め・側面・背面、顔・髪・手・脇・股を確認。今回の対象は新規静的モデルまでで、既存ゲーム配布モデルの差し替えは別工程。
