# 窓際スーパーつらいCM 第5弾 — 土下座レース篇

## 採用内容
大会「窓際スーパーつらい杯・競謝グランプリ」。競謝の読みは「けいしゃ」。競輪場の熱気とスケルトン的な高速滑走。本格スポーツ中継として、不条理な物理を真顔で描く。最終コピー「低姿勢で、ぶっちぎれ。」。

完成された土下座ほど謎の原理で加速するが、制御が難しい。蹴り出し・手で漕ぐ・走行・車輪・ソリ・ジェット・発光は使わない。頭を下げると静止姿勢のまま加速し、上げると減速と方向制御が容易になる。手足の形は保ち、加速・旋回・慣性だけを大胆に非現実化。額がゴールラインを通過した順で着順を決める。

## 人物
- いーさん：新メンバー。アクシデンチュア（世界設定上の架空企業）のトップ営業で窓際族。特技は土下座、競謝の不動の王者。「頭を下げて、数字を上げる男」。一年分の営業目標を達成して窓際で過ごすという背景案を採用。本編では説明台詞を増やさず肩書テロップで紹介する。
- 顔は本スレッドのユーザー添付写真が唯一のidentity source。紺の法被・白シャツ・濃色ズボンを継承。imagegen製の本番シートは本エピソード専用。恒久的な人物写真・声の正典更新は行っていない。
- そば屋：標準シートの白仮面・グレー肌・大型体格を維持。仮面は全登場フレームで装着。ビールに自ら進路変更して失格。走行中は手にジョッキを持たない。
- やめ太郎：最新版標準シートの顔、丸眼鏡、頭部と体格比率、紫シャツ。完全土下座で一時先行するが水平スピンして外側へ膨らむ。
