# よーたん対そば屋 — Seedance 2.5用グラインドハウス殺陣リトライ

## 生成方針

30秒一括生成を行わず、10秒のClip A、B、Cを別々に生成してCapCutで接続する。矢印付きプランニング画像はSeedanceへ入力しない。各クリップへ渡す画像は`input_manifest.md`を正本にする。

作品の狙いは、1970年代日本グラインドハウス剣戟映画を思わせる張り詰めた静止、突然の爆発、横長の対峙、急な寄り引きと、現代実写スタント映画の重量・速度・物理反応。特定映画の人物、衣装、セット、構図、振付、台詞、音楽は複製しない。

## 共通の厳守事項

1. よーたんは金髪、サングラス、黒レザーのロック服。黒い強化ギターのネックを打撃時は両手で持ち、ボディだけを攻撃と防御に使う。
2. そば屋は筋肉質、白い仮面、白い半袖Tシャツ、右手の大型ビールジョッキ1個。
3. よーたん左、そば屋右を基準とし、客席側のアクション軸を越えない。
4. 4基のスピーカーは同じ位置へ固定する。音圧はパワーコード後、4基のコーンからだけ発生する。
5. 実写長編映画の人物、衣服、金属、ガラス、床、壁、照明。クレイ、ゲームCG、プレビズ、プラスチック人形の質感を禁止。
6. 矢印、線、カメラ代理、赤い星、同心円、可視ビーム、漫画的衝撃記号を禁止。
7. 重要接触の前後0.2秒は接触点を中央60%へ置き、モーションブラーを弱める。接触後にカメラ反動を再開する。
8. 必須セリフなし。意味のある会話、技名、ナレーション、字幕を追加しない。

## Clip A — 0.0〜10.0秒

```text
【厳守モード】
入力はキャラクター2枚、完成環境1枚、clip_a_start_production.png、clip_a_end_production.pngだけ。矢印付き画像、前回動画、クレイ絵コンテは入力しない。

【ルック】
1970年代日本グラインドハウス剣戟映画の緊張感と、現代の高予算実写スタント映画の重量感。深い黒、琥珀、クリムゾン、窓外の冷たい東京夜景。フィルム粒子は微細。特定作品の人物、衣装、セット、構図、振付を複製しない。

【0.0〜1.2秒】
横長24mm低角度ワイド。よーたん左、そば屋右。完全に静止し、アンプの低いハム音と呼吸だけ。カメラも止める。

【1.2〜3.5秒】
そば屋が一歩で距離を詰め、右肩と腰の大きな予備動作から大型ジョッキを頭部高さへ一度だけ横薙ぎする。攻撃開始で急に寄り、ジョッキと並走する高速横移動。赤い軌道線を出さない。

【3.5〜5.2秒】
よーたんが床すれすれまで一気にダックし、ジョッキが金髪の上を紙一重で通過する。最接近の前後0.2秒だけ接触点を安定して見せる。人体へ接触しない。

【5.2〜7.8秒】
よーたんは低姿勢の回転を止めず、ギターネックを両手で持ち、黒い強化ボディ側面をそば屋の左脇腹へ一度だけ当てる。接触は実写物理。脇腹と衣服の短い変形、靴の滑り、床埃、短いカメラ反動。赤い星形、光球、線画を出さない。

【7.8〜10.0秒】
そば屋は右へ1.5m滑って踏みとどまり、よーたんは左で低く構える。急なアクションの直後に長めの静止を作る。clip_a_end_production.pngの状態へ一致して終了。

【音声】
ジョッキの重い風切り、靴底、ギターボディの鈍い金属音、短い息。台詞なし。

【禁止】
クレイ、CG人形、矢印、カメラ図、赤バースト、同心円、可視ビーム、左右交換、ギターの刃物化、ジョッキ複製、スピーカー移動。
```

## Clip B — 10.0〜20.0秒

```text
【厳守モード】
入力はキャラクター2枚、完成環境1枚、clip_b_start_production.png、clip_b_end_production.pngだけ。矢印付き画像、前回動画、クレイ絵コンテは入力しない。

【0.0〜2.2秒】
clip_b_start_production.pngから開始。そば屋がジョッキを頭上へ上げ、右足元の床へ底を一度だけ垂直に叩きつける。接触へ真上クラッシュズーム。接触前には床を壊さない。

【2.2〜4.0秒】
接触後、床材が一瞬たわみ、接触点から微細な亀裂と粉塵の低い波が広がる。赤い同心円、光る波、魔法陣は出さない。よーたんは左の低いステージ段差を蹴る。

【4.0〜6.4秒】
低角度へクラッシュチルト。よーたんが空中でネックを両手保持し、ギターボディを頭上から振り下ろす。そば屋はジョッキ側面で受け、右外へ流す。客席側120度以内で追い、接触前後0.2秒だけ安定。

【6.4〜7.8秒】
よーたんは左へ三点着地し、即座にギターを通常演奏位置へ戻す。着地の重さ、革、髪、金属の二次動作を自然に補間。

【7.8〜10.0秒】
右手で一度だけ強烈なパワーコード。直後、固定された4基のスピーカーコーンが大きく振動し、不可視の音圧が発生する。空気屈折、衣服と金髪の圧力反応、床粉塵の移動で表現。ギターからビームや赤い波を出さない。そば屋は右へ押されるが倒れない。clip_b_end_production.pngへ一致。

【音声】
床の低い衝撃、木とコンクリートの共振、空中風切り、硬い受け流し、一発のパワーコード、スピーカーの低音圧。台詞なし。
```

## Clip C — 20.0〜30.0秒

```text
【厳守モード】
入力はキャラクター2枚、完成環境1枚、clip_c_start_production.png、clip_c_end_production.pngだけ。矢印付き画像、前回動画、クレイ絵コンテは入力しない。

【0.0〜2.2秒】
clip_c_start_production.pngから開始。そば屋が右から中央へ低く突進し、音圧と粉塵を身体で押し割る。低い横移動カメラが同速で追う。よーたんは左でネックを両手保持して待つ。

【2.2〜5.2秒】
三手を明確に分ける。第一手、そば屋がジョッキを右肩後方から中央左下へ斜め振り下ろし。第二手、よーたんが強化ギターボディ外周で一度受ける。第三手、よーたんがネックを返してボディでジョッキを横へ押し返す。ワイド→超短い接触クローズアップ→ワイドの三段編集。軸を越えない。

【5.2〜7.2秒】
ジョッキ底とギターボディ補強縁が中央で噛み合う。カメラ、音楽、二人の足をほぼ静止させ、筋肉、革、手、ガラスの圧力だけを見せる。長い緊張を作る。

【7.2〜8.8秒】
同じ接触点の圧力が一度だけ解放される。接触部位の短い変形、床粉塵、微細破片、1〜2フレームの露出変化、短いレンズ振動。星形バースト、火球、同心円、漫画線は出さない。

【8.8〜10.0秒】
よーたんは左、そば屋は右へ各2m滑って分離。左右対称の24mm低角度ワイドへ急後退し、二人が再び構えた強いシルエットで止める。未決着。clip_c_end_production.pngへ一致。

【音声】
重い足音、三つの異なる接触音、押し合い中の低い軋み、圧力解放、滑走。台詞なし。既存映画の音楽を模倣しない。
```

## CapCut接続

- Clip A、B、Cを順番に配置
- 境界は各終了フレームと次開始フレームが一致する位置で2〜4フレームのアクションマッチ
- 既存映画の音楽を使用せず、オリジナルの乾いたドラム、低いベース、単音ギターで構成
- 音圧、接触、無音の間を優先し、常時鳴り続ける音楽で埋めない

## 失敗条件

- クレイ、人形、ゲームCGの質感
- 矢印、線、カメラ代理、赤い星、同心円、ビーム
- 4基のスピーカー以外から音圧が出る
- 30秒を一括生成する
- 明確な編集点がなく、ポーズ間を連続モーフィングする
- よーたんとそば屋の左右交換
- ギターのネックまたはヘッドで殴る
- 特定映画の人物、衣装、セット、振付、ショットをそのまま複製する
