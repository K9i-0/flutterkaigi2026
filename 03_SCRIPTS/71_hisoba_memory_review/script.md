## 発話テンポの優先順位

- 自然な日本語の話速・抑揚・短い間を、シーンの予定時刻より優先する。
- プロンプトから台詞ごとの発話開始・終了秒を削除。Shotの秒数は編集目安として残し、発話に合わせて内部のカット境界を動かせるようにする。
