# そばムート「そばフレア」— Seedance用15秒・一発生成マスタープロンプト

## 制作方式

- 15秒を分割せず、Seedanceで一発生成する。
- 0.0秒からそばムートは完全召喚済み。召喚詠唱、出現、変身は省略する。
- 1本の連続映像内で、地上発進→アニメ的宇宙移動→ジョッキ一気飲み→ゲロ式そばフレア→着弾→戦闘終了まで完結する。
- 場所転換は別クリップへ分けず、速度線、雲、ビーム、着弾光を画面ワイプとして使う不可視カットでつなぐ。

## 厳守方針と優先順位

1. 15秒の一発生成と人物・装備・BGMの連続性。
2. 画像1へ0.0秒を完全一致し、そばムートが味方召喚獣だとUIと水色フィールドで即読みにする。
3. 右下のパーティ名の直上へ`SUMMON そばムート 15.0`の残り召喚時間ゲージ。0.0秒でほぼ満タン、5.0秒で約3分の2、10.0秒で空になり消える。
4. 手持ちは大型透明ガラスジョッキ。添付缶は肩タンク意匠のみ。
5. 発進→飲酒→吐き気→発射→直接着弾→勝利の因果と時刻。
6. 没の屋台、屋根、暖簾、提灯、木造建築、建築オーラを一切出さない。

## シーン地理と動作原則

- 地上：パーティは画面左、味方召喚獣そばムートは中央の水色六角フィールド内、敵たこさんは画面右。敵は金色HP、味方召喚獣は水色フィールドと右下の召喚時間ゲージで明確に区別する。
- 宇宙移動：現実のロケット弾道を禁止。そばムートは直立姿勢のまま、短い溜め→滑らかな急加速→一直線のアニメ的スライド→滑らかな減速で宇宙へ移る。放物線、重力ターン、ロール、ピッチ、多段分離、慣性漂流を行わない。背景だけを速度線、雲、星のストリークへ変える。
- 飲酒：右手の大型ジョッキを一気飲みし、液面を満杯から空へ連続して下げる。缶は出さない。
- 発射：空ジョッキを左手へ持ち替え、右手で腹を押さえ、肩を上げて前屈みになり一度だけえずく。仮面を変形させない。口元最初の50cmだけゲロのように不規則な流体脈動とするが、現実的な吐瀉物を見せず、白金の蕎麦粒子、泡、虹色キラキラ、紺の螺旋で完全に隠す。その先で格好いい直線ビームへ収束する。
- 着弾：ビームは仮面の口穴からたこさん上胸部へ直接接触。接触前にたこさんや床を動かさず、接触点をブルームや煙で隠さない。

## 秒区間別アクション設計

### 0.0〜1.0秒：味方召喚獣として発進

- 0.0秒を画像1へ完全一致。そばムートは完全召喚済み。右下のパーティ名一覧の直上に、細い水色の`SUMMON そばムート 15.0`ゲージ。足元と背後に水色の六角フィールド。敵たこさんは金色HPだけ。
- 0.0〜0.3秒：召喚時間ゲージが減少を開始。左右ジェットの圧力計とノズルが琥珀に点灯。
- 0.3〜1.0秒：両ジェット同時点火。水たまりが外へ押され、味方3人の衣服と敵ローブが揺れる。そばムートは右手の満杯ジョッキを垂直に保つ。

### 1.0〜2.5秒：アニメ的に宇宙へ移動

- 1.0〜2.2秒：現実のロケット軌道ではなく、直立姿勢のまま一直線上を滑らかにスライド上昇。身体を回転させない。カメラは一定距離の斜め背面追従。地上→垂直速度線→雲のストリーク→星の流線を一続きの背景ワイプにする。
- 2.2〜2.5秒：低軌道で滑らかに停止。地球を右下へ置く。召喚時間ゲージは画面右下に残り、約12.5秒相当まで減少。

### 2.5〜5.5秒：ジョッキを一気飲み、吐き気の溜め

- 2.5〜4.5秒：画像4の宇宙ルック。技名`そばフレア`を白金色で表示。右手の大型透明ガラスジョッキを仮面の口穴へ傾け、液面を満杯から空へ下げて飲み切る。
- 4.5〜5.0秒：空ジョッキを右手から左手へ持ち替える。
- 5.0〜5.5秒：右手で腹を強く押さえ、肩を上げ、腰から前屈み。口穴の奥に白金光。召喚時間ゲージは約3分の2。

### 5.5〜8.5秒：ゲロ式そばフレア発射

- 5.5〜5.9秒：画像5の姿勢へ一致。一度だけ強くえずき、口穴前方へ円形ショックレンズ。
- 5.9〜6.8秒：口穴から最初の50cmだけ不規則な白金流体が脈動。ゲロの勢いは読めるが、吐瀉物は白金蕎麦粒子、真珠色の泡、虹色の星形キラキラ、紺の螺旋で完全に隠す。
- 6.8〜8.5秒：噴流が太く格好いい直線ビームへ収束して地球へ伸びる。両肩ジェットが短く逆噴射し反力を相殺。左手の空ジョッキを落とさない。

### 8.5〜10.0秒：ビームで地上へ不可視カット

- カメラがビーム沿いに高速下降。ビーム軸は左上から右下で固定。星空→大気光→雲→地上を白金の連続ワイプで通過し、人物の瞬間移動として見せない。
- 10.0秒直前に召喚時間ゲージが空になり、そばムート本体と水色六角フィールドは白金粒子へ溶けて消える。ビームだけが地上へ到達する。

### 10.0〜12.2秒：たこさんへ着弾、大ダメージ

- 10.0秒を画像6へ一致。ビームがたこさんの上胸部へ直接接触。`99999`と`WEAK`。
- たこさんは人間腕2本を胸前で交差し、下半身触手を濡れた路面へ吸着して防御するが、接触力で右後方へ2m押される。接触後にだけ雨水環、蒸気、擦過痕。
- 11.5〜12.2秒：ビームが細く消え、たこさんは身体構造を維持したまま低く沈み戦闘不能。`99999`が上へ漂って消える。

### 12.2〜15.0秒：戦闘終了ファンファーレ

- 12.2〜13.3秒：敵HPが0。中央に独自UIで`BATTLE CLEAR`、下に`たこさん撃破`。召喚ゲージはすでに消えている。
- 13.3〜15.0秒：着弾後の蒸気を横切る高速パンで画像12の味方正面カメラへ切り返す。とーくん中央前、よーたん左後、やめ太郎右後。とーくんがウクレレ一音、よーたんがギターで応答、やめ太郎が両拳を肩の高さへ小さく上げる。1.7秒で到達できる短い終端ポーズだけとし、長い個別決めポーズ、ジャンプ、ダンス、ソロ演奏は省略する。
