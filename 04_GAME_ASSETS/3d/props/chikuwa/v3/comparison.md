# 目標との比較記録 — 通常ちくわ

目標: `../references/ideal_v2.png` の上段。built-in Imagegenで生成した食品写真風の画像。
比較対象: `chikuwa.glb`。WebGLとBlender Cyclesの両方で同一GLBを表示する。

| 観察点 | v2での不足 | v3での対応 |
| --- | --- | --- |
| 焼き皮の立体 | 色にしわがあるが、輪郭と陰影はほぼ筒 | 色と対応する高さ入力を実メッシュに反映。123,520三角形 |
| 凹凸の大きさ | 平坦に見える | 広い膨らみは形状、細かなしわは弱い法線へ分離。強すぎる粒状の凹凸は抑えた |
| 光沢 | 身と焼き皮が均一 | 焼き皮は滑らか、白い身はやや粗くなる粗さマップ |
| 切り口 | UV由来の筋、滑らかな機械的断面 | 別材質と白い身のUV、穴・断面の不均一さ |
| 比較条件 | 2体の遠近と表示サイズが異なった | 通常版1体、直線姿勢、目標と近い大きさ・角度で開始 |
| 形状の検査 | 色と法線の印象が混ざる | 色・法線・粗さマップを外す表示と斜光、ワイヤーを用意 |

プレビューの静止画はImagegen画像の差し込みではなく、GLBを再インポートしてCyclesでレンダリングしたもの。WebGLとは照明・影の計算が異なるので、静止画の見え方がそのままFlutterゲームで再現されるとは扱わない。

目標との完全な一致を認定したものではなく、採用判断用の候補。現状の白い身の微細な質感、薄い皮の透け感には目標との差が残る。写真にある微細な見え方は、高さ画像だけでは一意に復元できない。

実機負荷、ゲームカメラでの識別、低ポリゴン版への転写は次工程。毒版は通常版の形状採用後に色違いを適用する。
