# 福ちゃん Cスタイル・四面モデル仕上げ

2026-09-17。Wan四面画像から全身一回生成した `../wan_multiview_20260917/` のモデルを仕上げた。リアル頭身・1.70m・全身の体格と衣装を維持。

## 成果物

- `fukuchan_finished.glb`: テクスチャ埋め込み、1メッシュ・9マテリアル区分、約16.6MB。リグ・アニメーションなし。
- `fukuchan_finished.blend`: 編集用シーン。
- `qa/`: 最終GLBを新規シーンへ再読込した全身5方向、顔3方向、名札拡大。
- `comparison_face.png`: 左がTripo出力、右が仕上げ後。同じカメラ・照明。

モデル・生成アトラス・監査画像は元モデルと同じくローカル保持。採用した顔補正入力3枚、プロンプト、再実行コード、検証記録をGit管理する。ゲーム配布モデルは変更していない。

## 修正内容

- 四面由来モデルの正面・左右の顔アルベドを、対応するWanフレームを参照してImagegenで補正。シワを抑えたC案の質感を維持し、頬・顎・首の汚れを低減。深度・向き・肌色マスクで元UVへ投影。
- 粗い元眼球を元の範囲内で再構築し、白目・濃い茶色の虹彩・瞳孔を分離。虹彩は眼球と同じ曲面に沿わせ、斜めから欠ける問題を修正。
- 肌・髪・布の粗さを分離し、顔のノーマル由来の荒れと過剰な光沢を低減。髪は肌境界を残す専用画像へ焼き込み、GLBで再現。
- 名札は正確な「福ちゃん」をヒラギノ角ゴシックW6からメッシュ化。フォントの外部参照なしでGLBに含めた。
- 元眼球を除く元頂点位置が不変であることをスクリプトで検証。追加した名札・眼球も最終1メッシュへ統合。

## 再実行

Blender 5.1.2。リポジトリ直下から `prepare.py` と `prepare_right.py` で元アルベドを取り出せる。採用済み `face_clean_*.png` を保持し、`finish.py`、`review.py` の順にBlenderの `--background --factory-startup --python` で実行する。元のローカル `fukuchan_wholebody.blend` が必要。

`finish_report.json` は形状保持・名札・眼球の記録。`glb_validation.json` は最終ファイルのSHA-256と構造検査。最終GLBを再読み込みし、顔・名札・全身5方向の表示を目視確認済み。

## 残る制約

極端な顔拡大では髪と肌の境界、耳・うなじに元生成形状由来の細かな段差や色境界が残る。ストラップとTシャツの細かな文字・模様は元生成のまま。静止モデルの仕上げであり、表情リグ・動作変形は未検証。
