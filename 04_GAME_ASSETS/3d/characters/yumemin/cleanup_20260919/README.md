# ゆめみん Tripoモデル清掃版

この版には両目の下の開口が残っていたため、最新は `../eye_seams_20260919/yumemin_clean_v2.glb`。同フォルダの修正スクリプトで穴を閉じ、GLB再読込後の境界辺0を検証済み。

元モデルは `../wan_multiview_20260919/` に保持。
本版: `yumemin_clean.glb`。編集用: `yumemin_clean.blend`。

## 修正

- 元FBXから毎回再構築し、身体を重み付き平滑化。耳・鼻・尻尾は弱めに処理。
- 頭頂中央の小突起を周囲の丸みに合わせて整形。
- 目周囲のしわを局所的な曲面で整え、元の位置・サイズを基準に滑らかな浅い楕円体の目を配置。
- 白い後部の色境界を一本の滑らかな境界に再構成。段差状の塗り、焼き込まれた陰影、ノーマルマップの細かなノイズを除去。
- 尻尾の付け根の色分けを整え、全体をマットな材質に統一。
- 色を2048pxのUVテクスチャへベイクし、GLB内へ埋め込み。外部画像に依存しない。

## 検証と再現

`cleanup.py` をBlenderのbackgroundモードで実行する。Tripo APIの再生成・追加課金はない。
書き出したGLBを再読み込みして、正面・斜め・左右・背面・上面・下面の7方向を `qa/` に描画。
身体・左右の目の3メッシュ。未リグ。公式サイトへの公開はまだ行っていない。
変更量は `cleanup_report.json` に記録。モデル全体の寸法は元の任意単位を継承。
