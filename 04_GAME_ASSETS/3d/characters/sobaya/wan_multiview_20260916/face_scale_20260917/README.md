# そば屋・仮面を固定した顔パーツ縮小

2026-09-17。face_refinement_20260917 の本番モデルを基準に、目の中点を中心として顔パーツの正面投影を90%に縮小。

- 仮面外周と共有する頂点、髪・身体を固定。目・鼻・口の周囲の仮面内側のみ滑らかに追従。
- 目、口、額の丸は一様縮小。鼻は周囲との接続部分で変形を減衰。
- 赤模様は投影UVに逆変換を適用し、同じ中心・倍率で縮小。
- 目の黒面を投影奥行き方向に7px（約2.3mm）移動し、縮小後の仮面表面との干渉を解消。
- 鼻の穴なし。仮面の輪郭をfrontへ変形する処理は行わない。

## 測定

顔部分は両目・額の丸・口を囲む範囲。鼻は範囲内。赤模様はこの測定に含めない。

| 仮面に対する割合 | WAN front | 修正前 | 修正後 |
|---|---:|---:|---:|
| 顔部分の幅 | 69.4% | 73.8% | 66.5% |
| 顔部分の高さ | 58.4% | 69.1% | 62.1% |

元の仮面とfrontでは縦横比が異なるため、輪郭と顔パーツ相互の比率を保ったまま幅・高さを同時に完全一致させることはできない。90%は両方向の差を抑える調整。参照顔は約100px幅で、輪郭・髪際の手動計測にも誤差がある。

この縮小版に赤ラインの修正を加えた face_red_edge_20260917 が本番採用版。
