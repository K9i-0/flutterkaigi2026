# CTOおだてつ Tripo原型生成

flutterkaigi2026専用。PR #20の範囲で管理し、mainへマージしない。

- ユーザーの2026-10-14送信指示により1件実行。
- P2-20260801、quad、face_limit=15000、detailed PBR、seed=1014030。
- 4面の入力パスはconfig.json、ハッシュとタスクIDはtask.json。
- leftは画面左向き、rightは画面右向きを割り当て。画像は校正投影ではなく、左向きはImagegenによる推定補完。出力の左右・胸文字・フード・手指を後工程で確認する。
- 入力画像の原寸を維持。モデルにカメラ・ストラップは含めない。
- API応答の期限付きURLとアップロードトークン、生成原型raw/はGit追跡対象外。ダウンロード一覧・SHA-256はdownload_manifest.jsonへ記録。
- これは静的原型の生成。リグ・テクスチャ修正・ゲームへの採用は別工程。

## 結果
生成成功。120 credits消費。FBX（6,515,516 bytes）とTripoプレビューを取得。リグなし原型。全方向の形状・メッシュ監査は未実施。
