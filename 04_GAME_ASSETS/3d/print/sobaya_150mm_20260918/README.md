## モデル検証

ソースの立ち姿を評価済みメッシュとして固定し、台座を追加。UV境界で分割された頂点の結合、開口の補修、面方向補正、0.15mmボクセル結合、簡略化と微小遊離成分の除去を行った。ゲーム用正本は変更していない。

印刷用STLは非多様体エッジ0、本体・小道具・台座の連結成分1。外観を`preview_solid.png`で確認。最小肉厚・指・持ち手・髪の強度とサポート除去は業者審査が必要。現在は見積もり用で、製造承認済みではない。

初回の試作STL（旧ファイル名`solid_quote.stl`、体積30.34cm³）は形状欠落があり却下。JLCの旧$2.76やDMM旧ファイルの解析エラーは今回の比較結果に含めない。正しい見積もりは必ず`base85_v1.stl`を参照する。

