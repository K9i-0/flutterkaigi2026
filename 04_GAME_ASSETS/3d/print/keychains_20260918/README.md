## 再生成

1. Blenderで `tools/build_keychain_quote.py`
2. trimesh/scipy環境で `tools/solidify_keychain_quote.py`
3. Blenderで `tools/render_keychain_quote.py`

入力参照blendは以前の `tools/build_takosan_print_quote.py` と `tools/build_sobaya_print_quote.py` が生成する。
生成バイナリ・プレビューはローカル保持。形状寸法・体積は `report.json`。

見積もりサイト: https://quote.make.dmm.com/
