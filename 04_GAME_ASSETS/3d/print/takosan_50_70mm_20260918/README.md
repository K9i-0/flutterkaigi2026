ソース：`../../characters/takosan/rig_radial_v5_clean/takosan.glb`。
キャラクター本体`TakosanBody`だけを固定し、リグ表示用Icosphereを除外。元データは変更していない。
UV境界の頂点結合、開口補修、面方向補正、0.1mmボクセル結合、簡略化、微小遊離成分除去を実施。非多様体エッジ0、連結成分1。カラー参考・単色両方のプレビューを目視確認した。

STLは中空化なしの見積もり用。触手先端の最小肉厚・強度・サポート除去は未承認で、業者審査と必要な補強が残る。フルカラーは同じSTL形状から素材を指定した概算で、色付きデータを入稿して審査した価格ではない。

## 再生成とファイル

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --python tools/build_takosan_print_quote.py
```

- `takosan_50mm_base45_v1.stl` / `takosan_70mm_base60_v1.stl`：両社に入稿した形状。
- 同名の`_solid.png`：単色の形状プレビュー。
- 同名の`_color_reference.png`：元テクスチャのカラー参考。実際の印刷色保証ではない。
- `report.json`：寸法・体積・検証結果・ファイルハッシュ。

生成バイナリとプレビューはローカル保持。再生成スクリプトと軽量記録をGit管理。
