# 寸劇モーション v1

そば屋v3とやめ太郎nose-v3用の再利用可能な、フレーム直接評価型の演技オーバーレイ。新規の手付け／手続き型アニメーションで、モーションキャプチャではない。

`motions.ts`の`catalog`に基準クリップ、対象キャラ、参考尺を記載。基準クリップをAnimationMixerで評価した後、`applySkitMotion(scene, name, seconds)`を呼ぶ。毎回必ず元の姿勢へリセットしてから評価し、加算を累積させない。Remotionでの使用例はエピソード73。

追加動作: 説明、ジョッキ観察、写生、匂いを嗅ぐ、泡の音を聞く、空の手を確かめる、具現化に集中、得意げな乾杯、ツッコミ、お願い、二度見、相づち。

腕は各モデルの既存骨格長を使ったCCD IK。ジョッキ持ちの手首方向を保持し、仮面・顔・メッシュ・ウェイトは変更しない。手首やジョッキの接触、肩の変形は対象リグと使用カットで個別に確認する。骨名の一致だけで他キャラクターへ流用しない。

この追加は寸劇用。そば屋ハザードの採用GLB・モーション設定は変更しない。

共有TSをエピソード外から読み込むため、利用側に`three`をインストールし、TypeScriptの`paths`とbundlerの`three$` aliasで利用側の同一Three.jsへ解決する。エピソード73の`tsconfig.json` / `remotion.config.ts`に設定例あり。これは独立したGLBクリップではなく、基準クリップへ適用するランタイム演技ライブラリ。

## アニメ回想用・四つん這い（v3追加）

`flashback-motion.ts`の`applyDogLapping(scene,t)`は、そば屋v3を**バインド姿勢へ復元した後**に呼ぶ。既存モーション上へ重ねない。骨長を維持する解析的2ボーンIKで両手・膝を接地させ、骨盤と胸を前傾、頭の小さな上下動で犬のように舐める動作を作る。四肢のpoleで肘・膝の反転を抑制する。仮面は元メッシュのまま維持。舌は呼び出し側で頭の口元へ追従する別小道具として追加する。

適用範囲は今回のそば屋v3のみ。ゲームの標準動作やモデル本体は更新しない。

## ビールの周囲を嗅ぐ（v4追加）

`dogSniffOrbit(t)`のx/z/yawを役者の親groupへ適用し、バインド姿勢へ戻してから`applyDogSniff(scene,t)`を呼ぶ。固定ジョッキの位置はx=.035、z=.17。172フレームで3つの円弧を移動し、各方向で停止して嗅ぐ。手足は斜めの組で交互に運び、接地期間の位置をワールド空間に保持する。舌は表示しない。既存`applyDogLapping(scene,t)`の既定動作は維持。
