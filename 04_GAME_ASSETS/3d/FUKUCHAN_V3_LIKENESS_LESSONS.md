# 福ちゃんv3：実写キャラの本人らしさと浅い顔形状

2026-09-17。実写の福ちゃんを3Dスタイルへ変換し、全身一体で生成・仕上げた実例。**frontの見た目へ近づけるには、テクスチャだけでなく顔の奥行きと照明応答を一緒に調整することが有効だった。** ユーザーは「浅い形状＋陰影を調整でかなり良くなった」と評価し、その方向での仕上げを了承した。顔認識率などで測定した一般則ではなく、この参照画像・モデル・表示環境で得た知見。

## 目標にする顔を固定する

- 人物同一性の基準は正典写真。制作中の具体的な見た目の目標は、ユーザーが選んだ3DスタイルC案から得た [front画像](characters/fukuchan/wan_multiview_20260917/inputs/front.png)。リアルな頭身で、二頭身化しない。
- 「シワ控えめ」はfront作成時点で達成済み。その後は追加のシワ消し・美化・顔の再解釈をせず、frontそのものに忠実にする。一般的に整った顔へ近づけても、本人らしさの改善にはならない。
- 今回は実写を直接3D化する経路の相性が課題となり、先に3Dスタイルへデフォルメ→Wanの回転動画→採用四面→Tripoで全身一体生成、という経路を使った。Tripoが実写全般に不向きだと実証した比較試験ではない。四面の制作原則は [そば屋v3の知見](SOBAYA_V3_LESSONS.md) を併読する。

## どこで改善したか

| 段階 | 得られた改善と残った課題 |
| --- | --- |
| frontの顔パーツ合わせ・色の再投影 | 目・眉・鼻・口の配置と色を近づけた。固定ビューの画像指標が良くても、ユーザー評価では本人感がまだ弱かった。 |
| Imagegenによる髪の塗り修復 | 髪へ混入した肌色を直した。顔中央は保持した。塗りの誤りには効いたが、顔の彫りの深さは残った。 |
| 顔の凹凸を浅くする | 鼻・目周囲・頬・口元の強い立体感を弱めた。正面の横幅・高さを保ち、前後方向だけ調整した。 |
| 肌・眼の照明応答を調整 | テクスチャに含まれる濃淡へ、深い形状の陰影が重なる見え方を抑制。形状と組み合わせた段階でユーザーが改善を評価した。 |
| frontの再投影と明るさの仕上げ | 承認済み形状を固定し、肌の白浮き・髪の黒つぶれを抑えた。首の汚れは後工程で局所補修した。 |

作業上の解釈として、入力画像にはすでに鼻・頬・目元の陰影があるため、生成モデルの強い凹凸と通常の照明が重なると、frontとは違う深い顔立ちに見えやすい。**本人らしさを失ったまま彫りやPBRの立体感だけを増やさない。** ただし「平面に貼ればよい」という結論ではなく、斜め・側面に必要な丸みを残す。

## 再利用できる調整手順

1. front、未調整、形状のみ、形状＋材質の比較を用意する。同じカメラ・顔サイズ・照明・露出で見て、正面のパーツ配置の差と陰影の差を分ける。判断は実際の配信先のレンダラーでも行う。
2. 髪が肌色になるなど明らかな塗りの誤りは、Imagegenの修正画像を部位マスクと深度で既存UVへ戻す。顔全体やUVアトラス全体を再生成して、採用した本人の顔を置換しない。
3. 顔の奥行きだけを弱い候補から比較する。平板へ押しつぶさず、丸みのある基準面へ滑らかに寄せる。毎回同じ未調整モデルから作り、変形を累積させない。
4. UV境界の同位置頂点は同じ変位に揃える。変更した顔の法線を再計算し、口の内側も追従させる。顔以外の身体・服・髪、UV、画像はこの段階では保持する。
5. 肌・眼の拡散応答を弱め、参照色を保つ成分を加えて、二重の陰影を抑える。形状を浅くする調整と材質調整は別々にも比較する。白浮きが出たら両者の比率だけでなく全体の明るさを調整する。
6. 採用形状を固定してから、frontの肌・眉・瞳・唇の色を可視領域へ再投影し、境界をなじませる。髪の修復や側面の画素を巻き込まない。
7. 最終GLBを再読込して正面・斜め左右・横顔・全身を確認する。無照明の色と通常照明の表示を見比べる。固定ビューの輝度相関は補助指標で、本人らしさの合格判定に置き換えない。

## 限界と後工程への引き継ぎ

自己発光成分は暗いゲーム内で肌を明るく見せる。サイトの明るい照明で採用した係数を、暗所・逆光・別のトーンマッピングへ無検証で流用しない。今回のfrontの顔は約100pxで、拡大しても細部の正解は増えない。横顔や耳・髪際の粗さ、顔トポロジーの制約は別途残る。

形状の浅さを承認した後は、その形状をリグ・口パクの基準にする。口パク追加のために深い元形状へ戻さない。口の内側・開口時の貫通・閉口時の本人らしさも確認する。

2026-09-17時点の工程を混同しないこと：

- 静的な本人らしさの基準：[likeness_finish](characters/fukuchan/likeness_finish_20260917/README.md)。その後、[rig_v3](characters/fukuchan/rig_v3_20260917/README.md)で首補修・54骨・20動作を追加。
- 公式サイト：[web_v3](characters/fukuchan/web_v3_20260917/README.md)。リグ版の画像を可逆WebPへ変換した配信版。形状・動作と全画像の画素を保持する。
- 別セッションで追加・採用されたゲームの口パク：[本編採用版](hazard_adopted/v3_preview_20260917/README.md)。`SpeechOpen` / `SpeechNarrow`、歯なし、最大開口5.4mm、音量連動。元20動作とゲーム用3エイリアスを含む。通常起動で口パクの必須チェックを省くフラグは不要。公式サイトの口パク追加まで済んだという意味ではない。

今後の最新採用先はゲームの [manifest](hazard_adopted/manifest.json) と各配信symlinkを確認する。上記は今回の制作経緯の記録で、過去段階のREADMEにある「未リグ」「本番未反映」を現在の状態と取り違えない。
