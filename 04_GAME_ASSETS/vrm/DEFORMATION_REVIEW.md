# ダンス停止時の肩・腕の変形検証

肩・腕の軸回りのねじれ制限と、肩ウェイトの弱い局所平滑化を採用した。顔・体格・メッシュの頂点位置・表情・関節の初期位置は保持する。今回の対象はVRM確認ページとVRMAで、ゲーム共通GLBは変更していない。

## 切り分け

修正前のモデルとモーションを入力に、2人 × 3停止時刻 × 8条件の48枚を同じカメラ・光源で比較した。チャールストン0秒、ボディロール2.37秒と0.84秒。各条件の前に全ボーン行列とウェイトを復元し、親から順に評価する。条件間の骨格の残留状態で見た目が変わらないようにした。変形方式以外の条件を変えない画像比較であり、人体としての自然さの評価は目視。

| 候補 | 観察・判断 |
| --- | --- |
| VRMA変換の不一致 | 変換前ベイクとの位置・回転を全クリップ30 Hzで照合。大きな変換誤差ではない |
| Dual Quaternion / Preserve Volume | 多少の輪郭差はあるが、筋肉の向きは直らない。この条件の第一選択にはしない |
| ウェイト平滑化のみ（5回） | 小さな折れを減らすが、軸回りの不自然な肉の向きは残る |
| 腕のねじれをすべて除去 | そば屋のボディロールでは改善する箇所があるが、チャールストンの袖・肩の張り方が悪くなる箇所もある |
| 鎖骨のねじれ除去のみ | 肩周辺に効くが、上腕・前腕の形状までは改善しきれない |
| 関節位置の局所摂動 | 肩周辺を外側25 mm・下20 mmへ動かした場合に相当する変形行列の摂動を比較。良好な形状にはならず、軌道も変わるため不採用。完全な関節再配置・再バインドの検証ではなく、関節位置が解剖学的に最適という証明でもない |
| ねじれ制限＋弱い平滑化（3回） | 手首・肘・肩の軌道を保ちながら、過度な肉の回転を抑える。採用 |
| ねじれ制限＋強い平滑化（15回） | 3回に比べ一貫した優位がなく、袖の折れを増やす箇所があるため不採用 |

追加の探索では、鎖骨ウェイトを上腕へ直接移す方法、肘の曲げ平面だけから上腕の向きを再構成する方法も試したが、採用版より安定した改善は見られなかった。これらは予備実験で、上記48枚の同条件比較には含めない。

「スキニングの変形崩れ」は、骨格の動きに対して表面の肉・服が不自然に潰れる、膨らむ、ねじれる現象を指す説明として適切。ウェイトは各頂点がどの骨にどれだけ追従するかを決める。[BlenderのArmature Modifier仕様](https://docs.blender.org/manual/en/latest/modeling/modifiers/deform/armature.html)も参照。

## 採用した補正

- モデル：肩周辺を3回平滑化。UVの継ぎ目で重複した頂点も隣接関係に含め、4ウェイト以内で正規化。変更はそば屋1,675頂点、福ちゃん587頂点。
- モーション：体幹に対する初期姿勢からの方向補正を基準に、鎖骨10°・上腕45°・前腕60°のねじれ上限を設ける。これは2モデル用の調整値で、人体の医学的な可動域ではない。クォータニオンの符号を揃え、短い回転経路で制限する。
- ダンス3種のみに適用。待機・歩行・ダッシュは修正前とトラック値を比較する。
- 専用ツイスト補助骨や独自シェーダーは追加していない。標準VRM/VRMAの適用経路を維持。

## 検証

モデル生成時、形状・面・表情用頂点・バインド骨行列のSHA-256が前後で一致することをassertする。スキンメッシュのウェイト数・正規化も検査する。結果は `characters/deformation.json`。

VRM公式スキーマ・glTFエラー0、Three-VRMのロード、福ちゃんの口パクを検査。12 VRMAの公式スキーマ・glTFエラー0と、計956時刻の骨格比較を検査。位置誤差の最大は約0.0015 mm、回転誤差は約0.11°。これは変換がベイクを再現する検査で、表面形状の自然さそのものを保証するものではない。

視覚確認は2人 × ダンス3種 × 6時刻 × 左右の斜め視点の72枚。確認ページでも停止・シーク、実変形骨のハイライト、回転軸、元の姿勢、修正前後の切り替えを確認する。袖・脇の小さな折れやそば屋の元の筋肉の強調は残る。接地・衣服シミュレーション・任意の外部モーション全般は今回の合否対象に含めない。

## 再現

モデルとVRMAの再生成は各フォルダのREADMEを参照。比較用ベースラインも再生成してから実行する。

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup --python tools/probe_dance_deformation.py -- baseline dual_quaternion smooth_weights swing_only clavicle_twist pivot_offset adopted strong_weights
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup --python tools/review_dance_deformation.py
node tools/validate_humanoid_vrm.mjs
node tools/validate_vrm_motions.mjs
```

比較画像・レンダーログは `.local/dance_deformation/`、72枚のレビューはその `final-review/`。画像はローカル生成物として保持し、軽量な比較条件・画像パスは `deformation_experiments.json` に記録する。
