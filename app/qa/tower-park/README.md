- `night-angle.jpg`: 同じ状態から30度旋回、1秒進行。タワーの脚・展望台・公園の回り込みを確認。

- 低層化したビルに合わせて縦看板の高さを調整。鉄骨の寸法と当たり判定は変更なし。
- Dart MCPで再ビルド・起動、カメラ変更後のhot reload、Marionetteの拡張で状態設定。キャプチャはsimctlを使用。最終GLBとアプリ内GLBのSHA256一致を確認。
- 静的解析に問題なし、25テスト合格、最終起動で実行時エラーなし。GLB監査は画像の上限、幾何量の上限、333m相当の先端位置、ビルより高いこと、公園メッシュを検査。
